## 어드민 — 무엇을 어디서 바꾸나

| 하고 싶은 것 | 메뉴 | 반영 |
|---|---|---|
| 배너 문구·순서·노출 | 콘텐츠·고객소통 > **배너 관리** | 저장 즉시 홈 롤링에 반영. 노출 OFF 는 숨김이지 삭제가 아니다 |
| 새 공지·이벤트·꿀팁 | **게시판 관리** > 탭 > 새 글 | 소비자 게시판·🔔 알림에 즉시. 이벤트는 기간을 넣으면 진행중/종료 칩 |
| 질문에 답변 | 게시판 관리 > 질문/답변 > 답변 | 소비자 상세에 "담당자 답변" 카드. 미답변 수가 사이드바 배지 |
| 글 고정·숨김 | 게시판 관리 > 고정 / 편집(상태 숨김) | 숨김은 목록에서만 빠진다(숨김 ≠ 삭제) |
| 불편접수 처리 | **불편접수** 인박스 | 접수 → 처리중 → 완료. 답변 등록 시 자동 완료. 24시간 넘게 접수 상태면 경고 |
| 포인트 정책·플로팅 패널 문구 | **혜택·이벤트 설정** | 소비자 혜택 허브·플로팅 패널이 즉시 새 값 사용. 이력에 버전 기록 |

모든 변경은 권한·감사 로그에 남는다(배너 등록/수정/삭제 · 게시글 등록/수정/삭제 · 답변 등록 · 불편접수 처리 · 혜택 설정 변경).

## 배너 종류

| 종류 | 생김새 | 필드 |
|---|---|---|
| 컷아웃형(`mobi`) | 배경색 위에 배경 제거 이미지(인물·오브제) + 글. `side` 로 이미지 좌/우 | image · side · tone |
| 장면형(`scene`) | 21:9 장면 이미지를 통째로 깔고 빈 쪽에 글. `side` 로 피사체 좌/우, 글 뒤에 톤 맞춘 옅은 스크림 | image · side · tone |
| 뉴스형(`news`) | 이미지 대신 신문 1면 카드(DOM — 글자가 안 흐려진다) + 오른쪽 글 | news{kicker·vol·date·headline·big} |

`tone: dark` 는 노랑·연두·라벤더처럼 밝은 배경용 잉크 글씨. 어드민 배경 프리셋(파랑·노랑·연두·라벤더)을 누르면 톤이 같이 맞춰진다.
설명(desc)의 줄 앞에 `- ` 를 붙이면 불릿 목록으로 그려진다(랜딩페이지2).

## 로고

정식 로고는 `public/assets/brand/logo-moduon-src.png`(흰 배경 원본) 한 장만 두면 된다. 빌드(prebuild)의
`scripts/logo-transparent.mjs` 가 흰 배경을 투명화·여백 트림해 `logo-moduon.png`(헤더·푸터·로그인·어드민)를 만들고,
마크(위쪽 'M')만 정사각으로 잘라 `logo-mark.png`(파비콘·파트너몰 헤더)를 만든다. 로고를 바꾸려면 원본만 교체.

## 이미지 에셋

배포 시 `scripts/fetch-assets.mjs` 가 내려받아 `public/assets/` 에 둔다(자체 호스팅, 외부 URL 을 화면에 걸지 않는다).

| 파일 | 용도 | 생성 |
|---|---|---|
| `tile-{phone,rental,internet,car,package,benefit}.png` | 아이콘 행·햄버거 그리드 | GPT Image 2 · 유리질 3D · 배경 제거. 아정당과 다른 세트 |
| `mobi-agent.png` | 배너 1 인물 · 플로팅 패널 | 〃 · 3:2 · 배경 제거 |
| `banner-{support,car,home}.png` | 롤링 배너 2·3·(4) 장면 | 〃 · 21:9 · 2k. 왼쪽 55% 는 텍스트용 빈 그라디언트 |
| `ill-ai.png` · `ill-thinking.png` | 지원금 카드 ②·③ | 〃 · 배경 제거 |
| `banner-{mobi,benefit,subscribe,finder}.png` | 히어로 롤링 배너 1~4 장면(현재 노출) | 〃 · 21:9 · 2k · 한 세트 |
| `banner-piggy.png` · `banner-target.png` | 컷아웃형 예비 오브제(저금통·과녁) | 〃 · 배경 제거 |

이 컨테이너는 CDN 이 막혀 로컬에서는 이미지가 비어 보인다. 모든 `<img>` 는 로드 실패 시
자리를 비우거나(배너·일러스트) 첫 글자 원형으로 대체(아이콘)하므로 레이아웃은 무너지지 않는다.
아이콘을 손볼 땐 톤이 어긋나지 않게 6개를 한 세트로 다시 뽑는다.

## 새 배너를 넣는 절차

1. 21:9 장면 이미지를 만들고(왼쪽 55% 비우기) `fetch-assets.mjs` 에 `banner-xxx.png` 로 등록.
2. 어드민 > 배너 관리 > 새 배너: 종류 `장면형`, 이미지 `/assets/banner-xxx.png`, 문구·CTA 입력, 노출 ON.
3. 순서는 ↑↓. 홈에서 즉시 확인.

인물형(`모비형`)은 파란 그라디언트 위에 인물 컷아웃을 얹는 방식이라 이미지 하나(배경 제거)만 있으면 된다.
