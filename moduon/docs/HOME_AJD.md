| 장면형(`scene`) | 21:9 장면 이미지를 통째로 깔고 빈 쪽에 글. `side` 로 피사체 좌/우, 글 뒤에 톤 맞춘 옅은 스크림 | image · side · tone |

## 에셋 공급 경로와 안전장치

이미지는 레포에 없고 **빌드 때 `scripts/fetch-assets.mjs` 가 내려받는다**(`public/assets/`).
외부 CDN 에 의존하므로 원본이 사라지면 그대로 404 가 된다 — 실제로 한 번 당했다.

| 장치 | 무엇을 막나 |
|---|---|
| `fetch-assets.mjs` 의 `CRITICAL` + `ASSETS_STRICT` | 홈 필수 에셋이 빠진 채로 **배포되는 것**. Vercel(`VERCEL` 환경변수)에서는 빌드를 세운다. `ASSETS_STRICT=0` 으로 끌 수 있다 |
| `scripts/qa-assets-check.cjs` | 코드가 가리키는 `/assets/…` 를 **아무도 공급하지 않는 것**(다운로드 목록에도 없고 커밋되지도 않은 경로). 확장자 오타까지 잡는다 |
| 히어로 장식 레이어 + 컷아웃·뉴스형 | 그래도 이미지가 없을 때 화면이 **빈 판으로 보이는 것** |

**영구 해결은 자체 호스팅이다.** CDN 이 닿는 곳에서 한 번 받아 커밋하면 끝난다(PNG 는 gitignore 대상이 아니다):

```
npm run fetch-assets
git add public/assets && git commit -m "chore(moduon): 브랜드 에셋 자체 호스팅"
```

## 홈 칸(밴드) 구조 — 2026-09-22

섹션을 배경색으로 나눈다. 화면 폭 전체를 덮는 3칸이라 레이아웃의 크림 배경은 홈에서 보이지 않는다
(다른 소비자 페이지의 톤은 건드리지 않았다).

순서는 **주장 → 근거 → 신뢰 → 전환**이다. 근거·신뢰보다 전환 요청이 먼저 오면
아직 믿지 않는 사람이 요청을 먼저 받는다(2026-09-22 검수에서 바로잡았다).

| 칸 | 배경 | 담는 것 | 역할 |
|---|---|---|---|
| 1 | 흰색 | 롤링 배너 · 지급 티커 · 1차 동선 아이콘 6종 | 진입 |
| 2 | `zone` (#F4F6FB) | 모두온 혜택(지원금 152만원+) 3카드 · 실질 부담 비교표 | 주장 + 근거 |
| 3 | 흰색 | 신뢰 지표 · 후기 · 초록 CTA 밴드(바로 상담하기 분기 내장) | 신뢰 + 전환 |

**전환 요청은 마지막 칸에서 한 번만 한다.** 예전에는 2칸의 "바로 상담하기"와 3칸의 초록 밴드
"전문컨설턴트 상담하기" 가 같은 요청을 두 번 했다. 지금은 초록 밴드 하나에 문구와 분기 버튼을
같이 담는다 — 홈 스모크가 2칸에 전환 요청이 없고 `cta-split` 이 마지막 칸에 하나뿐인지 검사한다.

- 칸을 나누는 색은 `zone` 토큰이다(`band` 는 이미 파란 브랜드 색이라 이름이 겹친다).
- 흰 칸 위의 흰 박스는 묻히므로 `.surface-soft`(흰 → #F6F8FC 세로 그라데이션 + 헤어라인)를 입힌다.
  아이콘 원형 받침·신뢰 지표 바·실질부담 카드·지원금 3카드가 이 유틸을 쓴다.
- 헤더도 1칸과 이어지게 흰색이다. 푸터는 크림으로 남겨 마지막 구역을 구분한다.
- 홈 스모크가 `main > section` 3개의 계산된 배경색이 실제로 번갈아 다른지 검사한다.

## 휴대폰 동선 — 견적 계산기는 사업자 도구다

개인 고객의 휴대폰 종착지는 **온라인 구매(`/phone/shop`)** 다. 휴대폰 견적 계산기(`/calculator/phone`)는
R/B 가 붙는 사업자 도구이므로 소비자 동선에서 뺐다. 라우트는 살아 있다(숨김 ≠ 삭제).

| 어디 | 바뀐 목적지 |
|---|---|
| 모비 챗봇 휴대폰 답변 버튼 | `/phone/shop` |
| 모비 챗봇 빠른 칩 | `/phone/shop` |
| 휴대폰 메가메뉴 | 계산기 항목 제거(온라인 구매·알뜰폰만) |
| 진단 위저드(휴대폰) 결과 | `/phone/shop` |
| 휴대폰 카테고리 하단 링크 | `/phone/shop` |
| 데모 로그인 — 개인회원 | `/phone/shop` (사업자회원은 계산기 유지) |
| **마이오피스 사이드바** | **`/calculator/phone` — 사업자 R/B 진입로(수당 설계 아래)** |
| 계산기 탭 | 휴대폰 탭은 사업자에게만 노출(현재 보고 있는 탭이면 유지) |

홈 스모크가 홈에 `/calculator/phone` 링크가 없는지, 렌탈 스모크가 비로그인 탭에 휴대폰이 없는지 검사한다.

### 진단 위저드 → 온라인구매 인수인계

`/onboard/phone` 3문항의 답은 `?cur=…&join=…&usage=…&from=onboard` 로 넘어간다.
**`cur` 이름이 중요하다** — 온라인구매 화면이 읽는 파라미터가 그것이다. `carrier` 로 보내면
통신사 칩이 하나도 안 켜진 빈 화면이 떠서 3문항 답이 통째로 버려진다(2026-09-22 검수에서 발견).
위저드와 온라인구매가 `PHONE_CARRIERS` 한 배열을 같이 쓰므로 키는 그대로 통한다.
온보딩 스모크가 도착 URL 과 **실제로 선택된 칩 개수**까지 본다 — 도착만 보면 이 버그를 못 잡는다.
