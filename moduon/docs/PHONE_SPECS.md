## 출고가 교정 (2026-09-28)

설명을 넣으려고 공식 자료를 보다가 출고가 오류를 발견해 바로잡았다.

| 기종 | 예전 값 | 제조사 국내 출고가 | 문제 |
|---|---|---|---|
| 폴드8 256GB | 2,577,300 | **2,278,100** | 폴드8 **울트라** 256GB 값이 들어가 있었음 |
| 폴드8 512GB | 2,745,600 | **2,531,100** | |
| 폴드8 1TB | 3,152,600 | 3,152,600 | 같음 |
| 플립8 256 / 512GB | 1,485,000 / 1,628,000 | **1,683,000 / 1,936,000** | 전작(플립7) 값 |
| S26 울트라 256 / 512GB / 1TB | 1,826,000 / 1,969,000 / 2,255,000 | **1,797,400 / 2,050,400 / 2,545,400** | 추정값 |
| S26 256 / 512GB | 1,155,000 / 1,298,000 | **1,254,000 / 1,507,000** | 전작(S25) 값 |
| 아이폰 17 프로 256 / 512GB / 1TB | 1,750,000 / 2,050,000 / 2,350,000 | **1,790,000 / 2,090,000 / 2,390,000** | 4만 원 낮게 들어가 있었음 |

가격표(KT K1) 기종은 할부원금이 가격표 값이라 **월 납부금은 그대로**다.
바뀌는 것은 화면의 '출고가'와 '가격표 반영 할인'(= 출고가 − 판매가)이다.
예를 들어 폴드8 256GB 의 할인은 1,177,300 에서 878,100 이 됐다. 예전 값은 할인을 30만 원 부풀려 보여 줬다.

**주의**: S26 시리즈는 10월 출고가 인상 보도가 있다. 공식 인상이 발표되면 `phones.js` 와 데이터 검사 ⑤ 의 기준표를 같이 고친다.
