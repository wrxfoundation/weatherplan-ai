# 차량 이미지 연동 (제휴사 에이씨렌트카)

## 지금 상태

차량 카드·상세는 **SVG 실루엣**으로 나온다. 매핑을 채운 차종만 사진으로 바뀌고,
나머지는 그대로 실루엣이라 화면이 깨지지 않는다.

## 왜 핫링크(`<img src="https://acrentcar.com/...">`)를 쓰지 않나

같은 그룹사라 이미지 사용 권한은 문제가 아니다. 문제는 **운영 안정성**이다.

- 우리 트래픽을 제휴사 서버 대역폭이 감당하게 된다 — 우리 방문자가 늘수록 그쪽 비용이 는다
- 그쪽이 경로를 바꾸거나 잠깐 죽으면 **우리 상품 목록이 통째로 빈다**. 우리 배포와 무관하게, 예고 없이
- Referer 차단·CORS 로 조용히 깨지는 사고가 잦다. 브라우저 콘솔에만 남아 한참 뒤에 발견된다

받아서 우리 도메인에서 서빙하면 셋 다 사라진다. 그래서 빌드 시점에 내려받아 자체 호스팅한다.

## 붙이는 법

### 1. 매핑표를 채운다 — `src/lib/cars.js`

```js
export const PARTNER_IMAGES = {
  palisade: '00000000461_detail_1',   // 우리 차종 id : 제휴사 이미지 경로
  grandeur: '00000000462_detail_1',
  // ...
}
```

우리 차종 id 는 같은 파일 `CAR_MODELS` 의 `id` 다 (`palisade`, `grandeur`, `ioniq5` …).
제휴사 경로는 이미지 URL에서 `https://acrentcar.com/data/car/` 뒤의 부분이다.

### 2. 받는다

```bash
npm run build     # prebuild 에서 자동 실행
# 또는 단독으로
node scripts/fetch-car-images.mjs
```

`public/assets/cars/{차종id}.jpg` 로 저장된다. 이미 있으면 건너뛰므로 재실행이 안전하다.
실패한 건은 경고만 남기고 그 차종만 SVG 로 표시된다 — **빌드가 멈추지 않는다.**

### 3. 배포

평소대로 `npm run deploy`. 받아둔 이미지가 산출물에 포함돼 우리 도메인에서 서빙된다.

## 매핑표를 손으로 만들지 않으려면

제휴사에 **차량 목록 + 이미지 경로**를 CSV/JSON 한 장으로 요청하는 편이 빠르다.
그쪽 DB에는 이미 `차량ID · 제조사 · 모델명 · 이미지경로` 가 있을 것이다. 받으면
모델명으로 우리 `CAR_MODELS` 와 자동 매칭해 `PARTNER_IMAGES` 를 생성할 수 있다.

크롤링으로 이 표를 역산하는 것보다 정확하고, 제휴사가 차를 추가할 때마다
다시 훑을 필요도 없다.

## 주의

- 이 컨테이너(개발 세션)는 egress 정책으로 `acrentcar.com` 에 접근할 수 없다.
  다운로드 스크립트는 **로컬에서** 실행해야 한다.
- 스모크가 화면에 제휴사 도메인이 직접 걸리지 않는지 검사한다(핫링크 회귀 방지).
