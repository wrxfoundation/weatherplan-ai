# 모두온 운영 전환 노트 — 선행 서비스 4종의 시행착오 요약

> kcare(시니어 케어) · axion(영업 콘솔+Supabase 이관) · pickai(AI 진단) · dcmap(부지 인텔리전스)
> 4개 고도화 코드베이스에서 추출한 실전 교훈. 코드에 이미 반영된 항목은 ✅, 실서비스 전환 시 적용할 항목은 ⏳.

## 1. 데모 → Supabase 전환 설계 (axion)

- ⏳ **킬스위치 먼저**: `MODUON_ENV.MODE='demo'` 값 하나로 언제든 데모(localStorage) 모드로 강제 복귀. Supabase를 붙이기 *전에* 넣어야 의미가 있다.
- ⏳ **쌍둥이 스토어 어댑터**: `store.jsx`와 공개 API가 100% 동일한 `store-supabase.jsx`를 따로 만들어 파일 교체만으로 전환. UI의 동기 호출은 "메모리 라이브 캐시 + Realtime 에코 + 낙관적 갱신"으로 흡수. snake_case↔camelCase 변환은 함수 하나에 격리.
- ⏳ **롤백 런북을 스키마와 같은 날 작성**: 롤백 트리거를 사전에 못박는다 — ①리드 중복 배정 ②정산 이중 지급 ③타 파트너 리드 조회 가능(RLS 누수) ④건수·합계 불일치. teardown SQL(`99_rollback.sql`) 없이 스키마를 만들지 않는다.
- ⏳ **원본 store.jsx는 삭제 금지** — 즉시 복귀 경로. 금전 계산은 레거시 병행 Shadow Run(오차 0 확인) 후에만 컷오버.

## 2. DB 스키마 원칙 (axion · pickai)

- ⏳ RLS는 `security definer` 헬퍼(`app.role()` 등)로 캡슐화 — 본사=전체 / 파트너=자기 리드 / 소비자=본인. 화면이 아니라 DB가 권한을 강제한다.
- ⏳ **정산은 잔액 컬럼이 아니라 원장(ledger, delta 행)** — 분쟁·복구가 가능해진다. 가용액은 항상 파생 계산(기준액 − 보류 − 지급).
- ✅/⏳ **idempotency**: 프런트 중복 제출 가드는 반영(10분 내 동일 연락처·카테고리). DB에는 `idempotency_key unique`로 한 번 더 막는다.
- ⏳ 상태별 타임스탬프 분리(`requested_at/approved_at/paid_at`) + `approved_by` — 단일 status 컬럼만 두면 이력이 소실된다.
- ⏳ **전체 로드 금지**: 리드 1,000건 전에 keyset 페이징(튜플 커서, offset 금지)과 사전집계 컬럼(야간 배치)을 적용.
- ⏳ 진단·정산 로직에 `engine` 버전 컬럼 — 로직을 고칠 때 과거 데이터가 오염되지 않는다.

## 3. 리드·정산의 정직성 (dcmap · kcare)

- ⏳ **접수 성공은 실제 전달이 확인됐을 때만** 표시. 웹훅 미설정/실패면 `{ok:false, reason}`을 정직하게 돌려주고 대표번호·내용복사 폴백 UI를 띄운다. "허공에 사라진 리드"가 최악의 사고다.
- ✅ 상태 전이는 전이 테이블(`LEAD_TRANSITIONS`)만 경유 — 불법 전이는 스토어가 무시.
- ⏳ 내보내기 파일에는 화면에 보이는 것만 담는다 — 숨긴 컬럼(개인정보)은 파일에도 미포함. 누가·언제·몇 건 내보냈는지 기록.
- ✅ 정산 CSV에 "실연동 전 검증용 — 실제 이체 아님" 경고행 + BOM/CRLF(한글 엑셀).
- ⏳ 정산명세서에 SHA-256 지문 + 대조 페이지 — 위변조 분쟁 즉시 차단 (Web Crypto, 서버 불필요).

## 4. AI 운영 (전 서비스 공통)

- ✅ 정적 시스템 프롬프트만 캐시(`cache_control`), 동적 값은 user 블록 — 1바이트만 바뀌어도 캐시 전체 무효.
- ✅ 퍼블릭 AI 엔드포인트에 입력 검증(타입·개수·길이) + IP 레이트리밋 — 비용 폭탄 방지.
- ✅ 일시적 네트워크 실패는 캐시하지 않는다 — 고착되면 세션 내내 폴백에 갇힌다. (키 미설정 503만 확정 폴백)
- ⏳ task별 모델 티어링: FAQ·단순 분류는 Haiku급, 견적 해설·리포트는 상위 모델.
- ⏳ LLM에는 **실제 후보 풀(상품·파트너 DB)만 넘겨 랭킹**시킨다 — 없는 상품·업체 창작을 서버 화이트리스트로 차단하고, 출력 점수는 0~100 클램프.
- ⏳ 한국어는 토큰 효율이 낮다 — `max_tokens` 여유 확보 + JSON 응답은 부분 회수 파서(잘린 원문을 화면에 내보내지 않기).
- ✅ 답변에 근거 한 줄("근거 — 모두온 요금표…") — 상담 신뢰의 핵심.

## 5. 프런트 실전 함정 (dcmap · kcare)

- URL 파라미터 파싱은 `Number(null)===0` 함정 — 항상 `num(v, default)` 가드. ✅ 계산기 프리필에 반영.
- `backdrop-filter`는 자식 `position:fixed`의 기준점을 바꾼다 — 오버레이·툴팁은 포털로 body에.
- ✅ Tailwind 내장 유틸과 충돌하는 클래스명 금지(`collapse` → `.smooth-open`).
- ✅ iOS: 입력 폰트 16px 미만이면 포커스 시 자동 확대(`@supports` 가드), 홀로 선 소형 링크는 `.tap`으로 44px 확보.
- 고정 버튼에 `backdrop-blur` 금지 — 저사양 기기에서 스크롤마다 재합성.
- 외부 API 동시 발사는 429를 부른다 — 계단식 지연 발사(stagger).
