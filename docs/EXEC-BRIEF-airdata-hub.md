## 1. 결론

백서가 설계한 공기질 데이터 생태계(측정 → 보상 → 판매)에서 **아직 없는 것은 "파는 곳"뿐입니다.** 살 사람은 이미 명확합니다 — 가전 제조사(R&D·마케팅), 스마트홈 플랫폼, 지자체, 건설·인테리어, 그리고 AI 에이전트. 이들이 데이터를 발견·평가·구매하는 **커머스 플랫폼 + AI 컨시어지(wellbian AI)** 구축을 제안합니다. 기존 weatherplan-ai 팀·스택을 재사용해 초기 투자를 최소화합니다.

**왜 지금인가** ① 수요자와 단가가 백서에 이미 정의됨 ② 침투율(실외→실내 오염 유입률) 등 케이웨더만 만들 수 있는 데이터 ③ AI 에이전트가 스스로 결제(x402)하는 M2M 데이터 경제의 국내 선점 기회.

## 2. 생태계에서의 위치

```
수집 (DePIN 측정망) → 검증·정산 (XRPL: NFT·머클루트·토큰) → [ 판매 접점 = 이번 제안 ]
        백서 Step 1~4                  백서 Step 5~6                포털·콘솔·AI 에이전트
```

## 3. 무엇을 만드나 — 3개의 판매 표면

| 표면 | 고객 | 핵심 |
|---|---|---|
| 데이터 포털·콘솔 | 사람 (기업 실무자) | 커버리지 맵 → 무료 체험 → 크레딧 결제 → API/CSV |
| **wellbian AI 컨시어지** | 사람 (비개발자 포함) | 대화로 질의·견적·리포트 구매 — 구매 마찰 제거 |
| M2M 스토어프런트 | **AI 에이전트** | 가입 없이 x402 프로토콜로 자율 결제 (3~5초) |

## 4. 수익 모델 (백서 3대 수익원의 상품화)

| 상품 | 참고 단가 | 방식 |
|---|---|---|
| 코호트 통계 API | 호출당 0.002 RLUSD | 선불 크레딧 (고빈도) |
| 타겟팅 도달 질의 + 캠페인 | 질의당 0.05 RLUSD + 리드당 수수료 | 크레딧 + 후정산 |
| AI 인사이트 리포트 | 건당 0.5 RLUSD | x402 건당 (저빈도·고단가) |
| 침투율 데이터셋 (R3) | 프리미엄 (미정) | 구독 애드온 |

결제는 3경로: **원화 PG·세금계산서**(법인·지자체 조달 대응) / 선불 크레딧 / x402 온체인. 정가는 채널 불문 동일(일물일가).

## 5. 유통 전략 — 하이브리드 (핵심 의사결정 포인트)

전량 AI 에이전트 유통 시대는 시간이 걸립니다. 초기 매출은 **사람(영업·파트너 대행사)이 닫는 계약**에서 나오고, 플랫폼은 그 딜의 견적→개통→정산을 100% 처리합니다(수기 0). 자동화 채널은 지표 트리거 기반으로 점진 확대합니다.

| 채널 믹스 목표 (가정, %) | C1 영업 주도 | C2 셀프서브+AI | C3 M2M |
|---|---|---|---|
| R1 (베타) | **70** | 25 | 5 |
| R2 (GA) | 55 | 35 | 10 |
| R3 | 45 | 35 | **20** |

## 7. 성공 지표와 절대 가드레일

- **North Star**: 월 순 데이터 매출. 참고: 백서상 쿠폰 상환 개방 임계 = 월 B2B 매출 5,000만원.
- PoC 기준: x402 결제 성공률 ≥ 99%, 가입→첫 유료 질의 전환 ≥ 40%(베타), 리포트 재구매율 ≥ 30%.
- **절대 가드레일: 프라이버시 위반 응답 0건.** 개인·가구 명단은 어떤 고객에게도, 어떤 가격에도 제공하지 않음(플랫폼이 광고 발송 대행, 광고주는 집계·리드만) — 백서가 "생태계의 생명선"으로 규정.

## 8. 리스크 Top 4

| 리스크 | 대응 |
|---|---|
| 프라이버시 사고 | k-익명성·차분 방어를 API 구조로 강제 + 전 질의 감사 로그 (UX·영업·AI 모든 경로 동일) |
| 초기 커버리지 부족 | 수도권 집중 (백서 시뮬: 전국 균등 커버리지는 토큰 경제에 독), "데이터 대기" 정직성 UX |
| 채널 컨플릭트 | 일물일가 + 공개 볼륨 할인 규칙만 허용, 할인 임계 초과 시 승인 워크플로 |
| M2M 성장 지연 | C1·C2 매출이 방어선 — C3는 트리거 기반 투자(옵션 가치)로 관리 |

## 9. 의사결정 요청 (The Ask)

1. **R0 착수 승인** — 기존 weatherplan-ai 팀·인프라 재사용, 신규 채용 없이 시작 가능
2. **법무 검토 착수** — 개인정보보호법(가명·익명정보)·위치정보법·가상자산 규제 (R1 출시 게이트)
3. **디자인 파트너 3사 발굴 지원** — 가전 제조사 우선, 영업 리소스 배정
4. **브랜드·도메인 확정** — "AirData Hub"는 가칭 (PRD OI-1/OI-2)
