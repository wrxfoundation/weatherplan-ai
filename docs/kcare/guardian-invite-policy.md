# 보호자 가입·초대 정책 (결정 초안 · 2026-07-30)

## 가입 구조
- **주 보호자** = 계약·결제·법적 동의의 단일 주체. 온보딩(가입 신청·결제권한 선택·약관/영상
  동의)을 수행한다. 가구당 1명, 연락 담당과 일치.
- **부 보호자** = 주 보호자의 초대로 참여. 가구당 보호자 합계 최대 5명.

## 초대 흐름
1. 주 보호자가 마이 → 가족 구성원에서 **초대 링크 발급** (7일 유효 · 1회용)
2. 부 보호자는 링크로 가입 — 입력은 이름·관계·연락처만. **결제수단 불필요**
3. 참여 즉시 주 보호자에게 알림. 링크 소지 = 사전 승인으로 간주(별도 승인 단계 없음)
4. 구성원 제거·링크 무효화는 주 보호자만

## 화면·권한 원칙 — "정보는 같게, 권한만 다르게"
형제 공동 관리 원칙("결과는 모두에게 동시 전달")에 따라 조회 범위는 동일하다.
가족 내부에 정보 비대칭을 만들지 않는다.

|---|---|---|
| 상태·리포트·일정·티커 조회 | ○ | ○ (동일) |

## 데이터 모델 (서버 구현 시)
`GuardianMembership { householdId, userId, role: 'primary'|'secondary', invitedBy,
joinedAt, removedAt }` · `InviteLink { householdId, token, expiresAt(7d), usedAt }`
- 서버 제약: primary는 가구당 1명 · 결제/설정 API는 role='primary'만 허용 (UI 검증 아님)
- primary 이양: 탈퇴·유고 시 지정 이양 절차 필요 (미결 — 약관 항목)

## 데모 구현
- 헤더 역할 배지 탭 → 주/부 전환 시연 (state.demo.guardianRole)
- 마이: 가족 구성원 카드(구성원 목록·초대 링크 발급) · 부 보호자는 조회만
- 해주세요: 부 보호자는 승인 대신 알림 · 캘린더: 수정 버튼 숨김 · 마이: 설정/옵션 잠금
