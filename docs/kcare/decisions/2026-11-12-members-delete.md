# 2026-11-12 — 관제 계정 · 권한 [삭제] · "각자 가입했는데 한 사람으로 보인다"

현장에서 온 세 가지다.

1. 어르신 화면의 안내 "이 센터의 기록(약 · 일정 · 부탁 · 마음사서함)은 테스트마마 님 기준으로 함께 씁니다…"가 무슨 뜻인가.
2. 가입 코드를 '바꾸기' 해서 각자 다르게 가입했는데도 한 사람으로 인식된다. 이게 맞나.
3. 관제 계정 · 권한 화면의 `정지` 옆에 `삭제` 단추.

## 1 · 2. 왜 한 사람으로 보이나 — 지금 구조

- 베타는 **관제 센터 하나 = 가족 한 곳의 기록**이다 (`lib/centers.js` — 관제 1 · 2 · 3센터가 가구 기록 `HH-C1` · `HH-C2` · `HH-C3` 을 하나씩 쓴다).
- 가입 코드는 "어느 센터에 가입하나"만 정한다. **코드 바꾸기는 그 센터의 옛 코드를 막는 일**이고 새 공간을 만들지 않는다.
  새 코드로 가입한 사람도 같은 센터 회원이 되어 같은 기록을 본다.
- 한 센터에 어르신 회원이 여럿이면 화면의 '어르신'은 **먼저 가입한 어르신**이다 (`lib/people.js` `elders[0]`).
  관제 1센터는 테스트마마(10-08 09:34 가입)가 기준이라, 테스트파파1 · 테스트마마3 · 테스트파파10 으로 들어와도
  테스트마마의 약 · 일정 · 부탁 · 마음사서함이 보인다. 안내 문구는 이 사실을 알리는 말이었다.
- 그래서 **지금 구조에서는 맞는 동작**이다. 따로 써 보려면 관제 2센터 · 3센터(`ops2` · `ops3`)의 코드로 가입해야 하고, 따로 쓰는 공간은 세 곳까지다.

이번에 고친 것은 안내뿐이다.

| 어디 | 바뀐 것 |
|---|---|
| 어르신 화면 (두 번째 어르신으로 들어왔을 때) | "지금은 시험 운영이라 한 센터에서 어르신 한 분의 기록만 씁니다. 이 센터는 ○○ 님 기록이라, 여기 보이는 약 · 일정 · 부탁 · 마음사서함은 ○○ 님 것입니다. 따로 써 보시려면 다른 관제 센터의 가입 코드로 가입해 주세요." |
| 관제 계정 · 권한 | 어르신 회원이 둘 이상이면 목록 위에 안내 (전에는 두 번째 어르신을 승인하는 확인 창에만 있었다) |

### 정해야 하는 것 — 어르신(가구)마다 기록 나누기

실제 판매에서는 어르신마다 기록이 따로 있어야 한다. 지금 구조로는 고객을 세 가구까지만 받을 수 있다. **정식 판매 전에 필요한 일**이고 작지 않다.

- 가입할 때 가구를 만든다 — 어르신(또는 계약한 보호자)이 가입하면 새 가구가 생기고, 가족은 그 가구의 초대 링크로 들어온다 (초대 링크는 이미 있다).
- 관제 · 컨시어지 화면은 지금 '가구 하나'를 보는 구조다 — 가구 목록에서 골라 들어가거나, 여러 가구의 '지금 처리할 일'을 모아 보는 화면이 필요하다.
- 요금제 지정(11-10) · 담당 컨시어지 · 상담 신청 → 가구 만들기까지 이어 붙여야 한다.
- 지금 쌓인 센터 기록을 어느 가구로 옮길지 (연습 기록이면 버려도 되는지) 정해야 한다.

## 3. [삭제] — 정한 것

| 정한 것 | 내용 | 이유 |
|---|---|---|
| 누가 | 센터 관리자(`ops1~3`)만. 승인된 관제 회원에게는 단추가 보이지 않고 서버도 거절한다 | 되돌릴 수 없는 일이다. 정지는 관제 회원도 한다 |
| 무엇을 지우나 | 계정 줄만. 그 회원이 남긴 가구 기록 · 음성 · 활동 기록은 그대로 | 기록은 가구의 것이고 증명이다 |
| 남기는 것 | `권한 변경 기록`(지운 사람 · 지워진 계정의 이름과 역할) · 관제 감사로그 "계정 삭제 — 이름 (아이디) · 역할" | 계정 줄이 없어지므로 이름을 기록에 같이 적는다 |
| 지울 수 없는 것 | 자기 계정 · 센터 관리자 계정 · 다른 센터 회원 · 승인 대기(거절 먼저) | 승인 대기는 거절이 이미 있다 |
| 로그인해 있던 사람 | 15초 안에 막히고 "아이디를 찾을 수 없습니다" | 정지와 같은 방식 |
| 같은 아이디 | 다시 가입할 수 있다 | 연습 계정을 정리하고 다시 쓰려는 요청이다 |
| 확인 | 한 번 묻는다 — 무엇이 남고 사라지는지 줄마다. 기준 어르신이면 "지우면 △△ 님 이름으로 보입니다" | 10-18 원칙(지울 때 한 번 묻는다) · 기준 어르신을 지우면 화면의 어르신 이름이 바뀐다 |
| 색 | 빨강을 쓰지 않는다 (단추는 회색 테두리, 확인은 호박색) | 빨강은 위험 신호 전용 |
