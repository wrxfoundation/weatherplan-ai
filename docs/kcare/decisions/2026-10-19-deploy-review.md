## 바로 고친 것

### 결제 — 가장 급했던 것

- **결제 금액은 서버가 정한다.** 결제 주소의 금액을 100으로 바꾸면 9만 원짜리 해주세요가 100원에 '결제 완료'됐다.
  이제 해주세요는 서버에 저장된 요청 요금, 스토어는 카탈로그 합계, 가입비는 확정 가격표 값으로 서버가 서명한다.
  서명에 결제 종류 · 요청 번호까지 넣어 '싼 결제로 비싼 요청 결제 완료' 바꿔치기도 막았다.
  데모(로그인 없음)는 기록이 그 브라우저에만 있어, 금액이 요청 요금과 다르면 앱이 확정하지 않고 환불 대기로 돌린다.
- **결제 완료가 '결제 없음'으로 읽히던 것.** 토스는 결제 상태를 대문자(DONE)로 주는데 앱은 소문자만 봐서, 같은 요청을 두 번 결제할 수 있었고
  취소해도 환불 대기가 생기지 않았다. 기록할 때 맞추고, 이미 저장된 옛 기록도 불러올 때 맞춘다.
- 이미 결제한 요청 · 결제 단계가 아닌 요청은 결제를 시작하지 않는다(서버가 거절). 결제창에 다녀오는 사이 요청이 취소 · 변경됐으면
  토스 승인을 부르지 않는다(돈을 받고 환불하는 것보다 안 받는 것이 맞다).
- 결제 결과 화면을 새로고침하면 이미 결제된 것을 '결제 실패 · 청구되지 않음'으로 보였다 → '이미 처리된 결제' · '입금 대기'를 구분한다.
- **결제 · 결제수단 등록 · 정보 동의 · 스토어 결제는 주 보호자만** (초대 정책 문서 그대로). 부 보호자의 '주 보호자에게 결제 부탁'은
  요청에 남아 주 보호자 화면에 보인다(전에는 버튼 글자만 바뀌고 새로고침하면 사라졌다).
- 다음 결제일 계산(1월 31일 가입 → '3월 3일'로 넘치던 것 → 그 달 말일), 영수증 링크는 토스 https 주소만 연다.
- 관제 해주세요 관리에 그 요청의 결제를 모두 보인다(두 번 결제 · 금액이 다른 결제의 환불 대기가 가려지지 않게). '환불 완료'는 한 번 묻는다.

### 기록이 틀리거나 사라지던 것

- **복약 체크가 날짜 없이 쌓여** 다음 날에도 '다 드심'으로 보였다(어르신 알람도 안 뜸) → 한국 날짜로 기록하고, 어르신 · 보호자 · 관제가 같은 값을 읽는다.

- **'테스트 가구 기록 비우기'가 모든 역할에게 보였다**(가구 전체의 요청 · 결제 · 리포트 · SOS가 지워진다) → 관제 계정에게만. 서버도 다른 계정의 비우기를 받지 않는다.
- **머리의 '주 보호자' 칩을 누르면 가구 전체의 주 · 부 보호자가 바뀌었다** → 로그인한 가구는 계정으로 정하고, 칩은 데모에서만 바꾼다.
- 늦게 도착한 화면의 값이 새 기록을 덮던 것 — 지난 SOS 종료가 그 사이 새로 눌린 SOS를 끄던 것, 반려된 리포트에 지난 '발송'이 덮이던 것,
  승인된 방문의 인원이 정책 아래로 줄던 것.

### SOS

- **관제 배너의 '알림 해제'가 진행 중인 급파 · 119 기록까지 지웠다**(컨시어지의 수락 배너가 사라지고 SOS 센터는 끝없이 기다림) → 버튼을 없앴다.

- **'급파 지시'가 SOS 센터에 '긴급출동 불가'로 보이는 사람에게 '1.2km · 6분 · 2인'을 박아 보냈다** → 출동 가능한 사람 목록에서 고르고 한 번 묻는다.
  배너의 119 연계도 사건 기록에 남는다. 세 화면(컨시어지 관리 · 지도 · SOS 센터)의 출동 가능 여부를 같은 값으로 맞췄다.
- 보호자: SOS가 홈 탭에서만 보였다 → 어느 탭에서든 맨 위에. 끝난 SOS는 어떻게 끝났는지 12시간 동안 보인다.
- 어르신: SOS를 보낸 뒤 화면을 닫으면 상태가 없어졌고, 관제가 끝낸 뒤에도 '곧 전화드립니다'로 돌아갔다 → 진행 중 · 끝남이 화면에 남고,
  **'잘못 눌렀어요'**로 관제에 알린다(앱에서 SOS를 끄지는 않는다 — 관제가 확인하고 종료). `/elder?sos=1` 주소를 새로고침하면 SOS가 다시 가던 것도 막았다.

- 테스트 가구 어르신에게 예시 신호(심박 132 · 위험) · 예시 동의 · 장기요양 등급 · 예시 거리가 붙던 것 → 실제 기록만.
- **실제로 아무것도 가지 않던 '보냄' 버튼** — 방문 중간 알림은 이제 보호자 홈 방문 카드에 실제로 뜨고, SOS의 '보호자 알림'은
  '보호자 연락함(기록)'으로, 워치가 없는 가구에서는 '워치 통화'를 감췄다. 보호자 SOS 음성 안내 문구도 실제로 가는 곳(어르신 앱)으로 고쳤다.

### 로그인 · 기기

- 로그아웃해도 이 기기에 가구 기록 사본(전화번호 · 주소)이 남았다 → 로그아웃할 때 지운다. 서버에 아직 못 보낸 기록은 남기고(다시 로그인하면 이어서 보낸다) 먼저 알린다.
- '로그인이 만료됐어요'의 로그인 링크가 테스트 가구도 '가입한 아이디' 탭으로 보냈다 → '베타 테스트 계정' 탭으로.

### 빨강 정리 (빨강은 SOS · 낙상 전용)

- 컨시어지 화면의 '긴급확인'(관제가 맡긴 무수집 확인) · 방문 '반려' · 녹화 중 표시 · 캘린더의 병원동행 색, 안전 점검의 '아니요', 가입 화면의 '(필수)' · 심사 결과 '제한'이
  빨강이었다 → 해주세요 '긴급'과 같은 금색 · 호박색으로. 어르신 · 보호자 · 컨시어지 화면의 빨강은 SOS · 낙상 · 위험 날씨만 남았다.
