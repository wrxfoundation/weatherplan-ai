# K-CARE 실무자 미팅 회의 내용 (2026-07 · 카카오톡 스레드 원문 정리)

참석/발언: 이성준, 서우 광석

## A. 실무자 미팅 요약 (원 회의 10개 항목)

1. **환자 병력 기반 맞춤형 날씨 정보** — 병력을 반영해 중요한 웨더 요소를 먼저 표시.
   예: 갑상선 환자 = 온도 변화 취약 → 고온/추위 예방 우선 표기. 호흡기 환자 = 습도/미세먼지 우선.
2. **캘린더 추가** (알람 스케줄, 병원 스케줄 등) — 보호자·사용자·컨시어저 공동 접근.
   마이 탭 안에 배치, 지정 기간 내 알람은 팝업 표기, 클릭 시 달력 열림.
3. **양방향 "해주세요" 기능** — 보호자→컨시어저, 컨시어저→보호자 요청 가능.
4. **관제실 24시간 운영 / 119 신고까지만 기본 서비스** — 보호자 부재 상황을 계약서에 명시.
   임시보호자 역할 범위 명시. 긴급상황 초동 대응 서비스·야간 출동 서비스(외주)는 별도.
5. **기본 서비스 = 워치 + 약상자** (비상약·상비약·기타 물품) — 월 1회 방문 시 소진률 기록 → 새 키트 교체.
   연 4회 컨시어지(병원)/픽업 서비스. 가입비 12만~15만원 미정(25% 수수료). 구독료 1급지 57,000원, 2급지 미정.
6. **사용자 기능** — SOS 버튼 위치 변경(최상단 중간 또는 오른쪽 상단).
   장바구니: 부모가 담고 보호자가 결제 / 양쪽 모두 결제 가능 여부는 가입 시 선택, 결정된 방식으로 표시.
7. **컨시어저 기능** — 쇼핑탭(구매대행: 장바구니에 담고 요청 버튼 → 보호자에게 알람).
   공유 캘린더(병원 다음 예약을 컨시어저가 미리 등록 → 스케줄 공유).
   당일 스케줄에 고객 출발지–도착지 표기. 매달 방문 시 약 채우기 → 새 키트 교체(기존 키트 사진 촬영, 소진량 기록). 연 12회 방문.
   방문 시 가정 청결 상태·고객 우울감·감정 언어 등을 건강 데이터로 수집, 리포트 작성.
   가정 진입 시 바디캠 사용(신뢰 확보). 차량 이동·병원 내방 시 바디캠 미사용. 구글 글라스 사용 가능(보호자 동시 시청).
   영상 보관 후 추후 확인 가능, 한 달 후 자동 삭제 수준.
   리포트 누적 기록 표시: 본인 작성 리포트는 전부, 타인 작성 리포트는 공유된 부분만.
   비밀 내용 표기 관리 또는 보호자 열람 범위 설정. 재택 방문 서비스 이름 짓기. 영상 메뉴 포함.
8. **병원 검색 기능** — MOU 체결 병원 찾기. 진료 과목마다 최소 1곳.
9. **신규 등록·판매 프로세스 = 옵션 판매** — 접수, 결제요청. 보험 → 보험회사 연계 = 입점 수수료.
10. **언더라이팅** — 오지산간 제외 / 지역 나누기 / 차량 진입 어려운 곳 제외.
    1급지 57,000원 / 2급지 범위 선정. 시작점은 강남.

## B. 이성준 상세 검토 코멘트

### B-0. 총론
- 현재 목업은 향후 나아갈 모든 것을 총망라한 상태 → **다음 미팅에서 1차 개발·2차 개발·3차 개발로 나누어 포함 기능 정리** 필요.
- (서우 광석 동의: "초기에는 각 영역별 정해서 1차 릴리즈 빠르게")

### B-1. 환자 병력 기반 맞춤형 날씨정보 — 평가: 조건부 반영
- 컨시어저·보호자·어르신이 **직접 설정**하도록 하는 것이 바람직.
- 이유: 건강정보가 데이터로 쌓여 전산이 자동 반영한다는 인상을 주면 민감정보 이슈로 규제 빌미 제공 가능.

### B-2. 보호자·사용자·컨시어저 공유 캘린더
- 공유 대상 일정: 병원 예약 / 복약 알림 / 컨시어지 방문 / 약상자 교체 / 건강검진 / 보호자 방문 / 상품 배송 / 추가 요청사항 / 다음 진료 예정일
- 권한 구분:
  | 역할 | 권한 |
  |---|---|
  | 보호자 | 조회·등록·수정·결제 |
  | 사용자 | 조회·알림확인·간단등록 |
  | 컨시어저 | 담당 고객 일정 조회·업무 관련 일정 등록 |
  | 관리자 | 전체 조회·조정·감사기록 |
- 컨시어저가 병원에서 다음 예약일을 등록하면 보호자·사용자 캘린더에 즉시 공유.
- 마이탭 깊숙이 숨기기보다 **홈 화면에 "다음 일정: 8월 5일 오전 10시, 내과 진료" 정도만 표시**, 클릭 시 달력 열림.

### B-3. 양방향 "해주세요" 기능 — 업무형 요청 시스템으로 설계
- 보호자→컨시어저 예시: 약 구매 / 병원 예약 확인 / 집 상태 확인 / 물품 전달 / 다음 방문 때 확인
- 컨시어저→보호자 예시: 결제 필요 / 약 부족 / 병원 예약 확인 필요 / 추가 동행 필요 / 집안 안전조치 필요
- **필수 상태값**: 요청됨 / 확인됨 / 결제대기 / 처리중 / 완료 / 취소 / 처리불가 / 관리자 확인필요
- 요청별 첨부: 사진, 금액, 희망일, 긴급도, 담당자, 완료증빙

### B-4. 기본상품 구조
- 가입비: 120,000원 또는 150,000원 (미정, 제안 받음)
- 월 구독료: 1급지 57,000원 / 2급지 별도 산정
- 기본 제공: 갤럭시 워치 / 생활안심 약상자 또는 케어키트 / 웨어러블 기반 건강정보 모니터링 / 보호자 알림 / 공유 캘린더 / 월 1회 재택 케어방문 / 연 4회 병원동행 또는 픽업 / 상비약·생활물품 구매지원 / 월간 케어리포트 / 긴급신호 접수 및 119 신고지원

### B-5. SOS 버튼
- 하단 메뉴보다 **항상 보이는 위치**. 권장: 화면 오른쪽 상단 고정 또는 하단 중앙 플로팅.
- 오작동 방지: **2초 길게 누르기 → 누른 후 5초 취소 가능 → 미취소 시 자동 접수**.

### B-6. 장바구니 (부모가 담고 보호자가 결제)
- K-CARE의 실질적 추가매출 수단.
- 가입 시 결제권한 선택: 사용자만 / 보호자만 / 양쪽 모두 / 일정 금액 이하 사용자·초과 보호자 승인.
- 권장 기본값: **5만원 이하 사용자 직접 결제, 5만원 초과 보호자 승인** (한도설정 기능).

### B-7. 컨시어저 앱 기능
- **7.1 쇼핑탭 흐름**: 물품 확인 → 상품/요청 등록 → 예상금액 표시 → 보호자 승인 요청 → 결제 → 구매 → 배송 또는 다음 방문 전달 → 완료사진 업로드
- **7.2 당일 출발지·도착지**: 현재 출발지 / 고객 주소 / 병원 주소 / 예상 이동시간 / 주차정보 / 환자 승하차 위치 / 휠체어 진입 가능 여부 / 다음 일정까지 여유시간.
  개인정보 보호: **고객 상세 주소는 담당 확정 이후에만 표시**.
- **7.3 약상자 교체·소진량 기록** — 명칭: **"K-CARE 안심케어박스"** (더 좋은 명칭 건의 받음).
  기본 품목: 체온계 / 밴드 / 거즈 / 소독용품 / 마스크 / 손소독제 / 냉찜질팩 / 비상연락카드 / 복약체크표 (+ 진통제·파스 등 상비약).
  상비약은 **고객 요청에 따라 약국에서 구매한 것을 보관하거나, 고객 소유 의약품의 수량만 확인하는 구조가 안전**.
  방문 기록: 기존 키트 전체사진 / 품목별 잔여량 / 유효기간 / 개봉 여부 / 보충 필요 여부 / 보호자 승인 / 새 키트 전달사진.
- **7.4(=코멘트의 "7") 가정환경·정서 상태 리포트** — 해석을 절제한 **관찰 중심 기록**.
  월 1회 방문 시 워치로 확인 불가한 정보 수집: 집안 정리 상태 / 냄새·환기 / 식품 보관상태 / 낙상 위험물 / 조명 / 냉난방 상태 / 의복 상태 / 대화 반응 / 식사 여부 / 외로움 호소 / 수면 호소 / 반복되는 불안 표현.
  컨시어저가 우울증·치매·정신질환·자살위험을 **진단하게 해서는 안 됨**.
  좋은 예: "지난 방문보다 대화량이 감소했고, '아무것도 하기 싫다'는 말을 세 차례 함." (판단보다 관찰 사실·직접 발언 기록)

### B-8. 원격진료 탭 + 방문 영상 기능 (컨시어지 탭)
- **① 원격상담 모드**: 고객/보호자가 요청한 경우에만 영상 연결. 실시간 송출만, 기본 저장 없음. 녹화는 별도 추가 동의 시에만. 상담 종료와 동시에 연결 종료.
- **② 방문기록 모드**: "서비스 품질관리 및 분쟁 예방을 위한 방문기록 영상" 목적. 가입 시 별도 동의(약관 추가): 촬영 목적 / 촬영 범위 / 촬영되지 않는 공간 / 열람 가능한 사람 / 보관기간 / 삭제절차.
  촬영 범위 제한: 항상 녹화가 아니라 **필요 순간 위주** — 방문 시작(현관 진입·본인 확인·서비스 시작) → 서비스 수행(필요 시) → 서비스 종료(결과·종료 확인). 활동 직전 간편 버튼으로 촬영.
  촬영 불가 장소(내부 규정): 욕실·화장실·탈의공간·침실.
  촬영 가능 공간: 거실 / 현관 / 주방 / 병원 이동 / 약상자 점검 / 생활환경 확인.
- **③ 긴급상황 모드**: 낙상·응급상황 등에서 관제센터·의료진과 일시적 영상 공유. 사건 종료 후 일반 영상 삭제, 필요한 경우만 별도 보존.
- **영상 보관** (서버 용량 부담 → 상의 필요): 일반 방문 = 일정 기간(예: 수 주) 보관 후 자동 삭제 / 사고·민원 = 사건 종료 시까지 별도 보존 / 법적 분쟁 = 관련 법령·내부 규정에 따른 별도 보관.
- **감사(Audit) 기록화**: 영상 + 위치·시간·업무기록 자동 묶음.
  예: 09:58 도착(GPS) → 10:00 영상 시작 → 10:18 약상자 점검(사진 자동첨부) → 10:22 생활환경 체크 → 10:31 영상 종료 → 10:32 퇴실.
  GPS·시간·체크리스트·사진·리포트가 하나의 감사 기록으로 연결.

### B-9. 서비스 명칭
- 월 가정용 상비약 구매대행·방문 서비스 명칭: **"K-CARE 안심방문"**

### B-10. 지역 구분과 가입심사
- "언더라이팅"은 보험업 용어 → 명칭: **"서비스 가능지역 및 이용적합성 심사"**
- 심사 항목: 주소 / 서비스 거점과 거리 / 차량 진입 / 엘리베이터 / 주차 / 산간·도서 여부 / 야간 접근성 / 휠체어 이동 / 보호자 유무 / 1인 또는 2인 필요 여부 / 병원 이동거리 / 안전위험
- 지역 구분:
  - **1급지**: 강남 거점 기준 일정 거리 이내, 대중교통·차량 접근 원활, 컨시어저 공급 가능 → 월 57,000원
  - **2급지**: 이동시간 증가, 주차·접근 제약, 인력 배치비 상승 → 월 구독료 또는 출동비 추가
  - **서비스 제한지역**: 차량 진입 불가, 도서산간, 상시 인력 배치 불가능, 야간 안전확보 어려움
