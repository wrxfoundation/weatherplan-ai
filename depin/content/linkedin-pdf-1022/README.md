# 링크드인 문서 게시물용 PDF — 연재 1 · 2 · 3편 세로판 (2026-10-22)

서우 「링크드인에 올리니 뭉개지는데 링크드인 한계인가」 → 점검.

## 원인 — 대부분 링크드인 쪽이다
- 링크드인 공식 도움말(Share photos): 사진 비율은 **3:1 ~ 4:5(가로:세로)** 까지, 그보다 길면 가운데를 기준으로 잘라 맞춘다 · 업로드 5MB · 권장 폭 1080px.
  우리 세로판은 **9:16**(4:5 보다 훨씬 길다) → 피드에서 줄여 보이고, 링크드인이 다시 압축하면서 작은 글씨(설명 · 각주)가 뭉개진다.
- 우리 파일은 문제없다: `*-9x16.jpg` 1080×1920(약 0.4MB) · `@2x.jpg` 2160×3840(약 1MB, JPEG 92) — 5MB 한도 안. 큰 파일을 올려도 링크드인이 줄이는 건 같다.

## 해법 셋
1. **문서(PDF) 게시물** — 이 폴더. 승인된 @2x 그림(2160×3840)을 다시 압축하지 않고 한 쪽 PDF 에 담았다(`convert … -quality 100 -density 192`, 쪽 크기 1080×1920 기준). 문서 게시물은 피드에서 크게 보이고 전체 화면으로 열 수 있다. 화면에서 실제로 얼마나 선명한지는 올려서 확인.
   - HTML 을 바로 PDF 로 찍는 방법은 쓰지 않았다 — 인쇄 모드에서 표 모서리 무지갯빛 테두리(마스크)와 유리 흐림(backdrop-filter)이 깨진다.
2. **4:5 판(1080×1350)** — 이미지 게시물로 올릴 거면 링크드인 비율 한도 안의 판이 가장 덜 뭉개진다. 내용을 줄이거나 두 장으로 나눠야 해서 새 배치가 필요(요청 시).
3. **9:16 은 X · 인스타 스토리 · 릴스 · 카톡 공유용**으로 쓴다.
