## UTM 명명 규칙 — KOL 에게 링크를 줄 때

**번호 코드(`kol1` · `kol2` …)를 `utm_source` 에 쓰지 않는다.** 내부 설정 단계에서만 쓰고,
실제로 나가는 링크는 **채널명**으로 바꾼다.

| | 번호 코드 | 채널명 |
|---|---|---|
| KOL 이 자기 링크를 볼 때 | 우리 내부 서열로 읽힌다 | 자기 채널이 보인다 |
| 반년 뒤 리포트 | 대조표 없이는 아무도 못 읽는다 | 그대로 읽힌다 |
| 정산 문서 | "kol1 이 몇 명" — 쓸 수 없다 | 채널명이 그대로 근거 |

**규칙**

- `utm_source` = **채널명, 소문자 영문, 공백·특수문자 없음.** 한 번 정하면 캠페인 끝까지 고정.

  리포트를 직접 보므로 무관하다.
- `utm_campaign` = `prereg0907` (전 채널 공통).
- `utm_content` = 게시 매체별로 가른다 (`x` · `tg` · `yt` · `blog`).

**전달 방식** — **완성된 링크를 통째로 준다.** 파라미터를 직접 붙이라고 하면 반드시 틀린다.
