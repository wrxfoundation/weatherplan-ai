# WLBN Reply Console

케이웨더 실내 공기질 DePIN(WELLBIAN) X 채널 운영 도구.
단일 HTML 파일 — `wlbn-reply-console.html`을 브라우저에서 열면 바로 동작합니다 (서버·API 불필요).

## 기능

1. **화제 트윗 파인더** — X 검색 연산자(`min_faves` 등)로 지금 붙을 만한 대형 트윗 탐색.
   API·스크래핑 없이 웹 검색 링크만 사용하므로 약관 안전.
2. **타깃 로스터** — 유형별(크립토·RWA / AI·테크 / 뉴스 / XRP 생태계 / 헬스·환경 / DePIN)
   계정 목록. 계정별 앵글 메모, 프로필·인기 트윗 바로가기, 로스터 전체 인기 트윗 통합 검색.
   추가·삭제는 브라우저(localStorage)에 저장.
3. **리플라이 컴포저** — 계정 유형별 앵글 템플릿, 공인 팩트(내러티브 문서 수치) 삽입,
   금지표현 실시간 검사(수익 약속·선점 조장·커버리지 과장·파트너 실명·미확정 일정 등),
   280자 카운터, X 웹 인텐트로 답글 작성창 프리필.

## 원칙

- **자동 게시 없음** — 인텐트는 답글창을 열어줄 뿐, 게시는 항상 사람이 Post를 눌러야 합니다.
- 금지표현 규칙의 출처는 depin 프로젝트 `docs/03-message.md`(메시지·금지 표현)와
  `docs/00-status.md`(확정/미확정 구분)입니다. 문서가 갱신되면 HTML 상단의
  `LINT`/`TEMPLATES`/`FACTS` 배열을 함께 갱신하세요.
- 파트너 실명·판매 일정 경고는 확정 시점(8/22 공표 범위, 8/26 파트너 협의, 9/4 판매일)
  이후 해당 규칙을 제거하면 됩니다.

# WLBN Node Econ Lab (노드 경제성 시뮬레이터)

`wlbn-node-econ-simulator.html` — 구매자 관점의 노드 경제성 시뮬레이터. **내부 설계·검증용 (대외 공유 금지).**

## 모델 (백서 FAQ 구조 반영)

- **분배 공식**: 내 월 보상 = 월 예산 × 내 품질점수 ÷ (참여 노드 × 평균 품질) — 정해진 예산을
  나누는 구조 (발행형 아님). 노드↑ 몫↓, 매출↑ 예산↑.
- **재원**: 시드 예산(공고 전 운영 재원, 지속 개월 설정) + 기업 선예치 × 노드 분배율.
  "먼저 들어오고, 그다음에 나눕니다."
- **품질 4요소**: 가동·연속성 / 데이터 정합성 / 이웃 일치 / 교정 최신성 → 평균 = Q.
  자격선 미달 시 보상 0. 방치 노드(Q 0.65) 비교선 고정 표시.
- **공간 단위**: 노드 1대 = 서로 다른 공간 1곳 기준 (같은 공간 중복분 무보상).
- 출력: 월 순수익 · 누적(구매가 회수 시점) · 재원 구성(시드→기업 자립 교차). 전 항목 RLUSD
  기준, 토큰 시세 미반영. 모든 수치는 조정 가능한 가정값 — 백서 확정치 아님.

## 대외 전환 시 (FAQ가 약속한 "백서 계산기" 공개판)

제거: 회수 시점 KPI · "순수익" 표현 · 시나리오 프리셋. 유지: 분배 공식 구조와
"노드가 늘면 몫이 줄고, 매출이 늘면 예산이 커집니다" 문구. (금지표현: 수익 약속·회수기간·월수익)
