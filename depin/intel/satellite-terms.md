# 위성 · 발사 · 스타링크 용어 — 쉬운 풀이 (2026-10-07, 서우 「위성을 이해해야 하니 용어를 쉽게」)

스타링크 · 스페이스X 견적(RFQ) 대화에서 나오는 말을 한 줄씩 푼다. 수량 · 자금 · 일정 같은 우리 계획은 넣지 않는다(상장사 미공개 정보).
숫자는 공개 자료 기준이고, 비교용 어림이다.

## 위성의 크기와 몸

| 용어 | 쉬운 말 |
|---|---|
| 큐브샛 (CubeSat) | 10cm 정육면체(1U, 약 1~2kg)를 쌓아 만드는 규격 위성. 3U 는 식빵 한 덩이 크기 — 플래닛 · 스파이어의 초기 위성이 이 급 |
| 초소형 · 마이크로 위성 | 대략 10~100kg 급. 큐브샛보다 크고, 웬만한 관측 장비를 싣는다. 케이웨더 견적의 「micro weather satellite」가 이 급 |
| 버스 (bus) | 위성의 몸통 — 전기(태양전지 · 배터리) · 자세 제어 · 통신 · 추진기. 같은 몸통에 장비만 바꿔 얹으면 양산이 쉬워진다 |
| 탑재체 (payload) | 위성이 실제로 하는 일을 하는 장비. 기상 위성이면 관측 센서 — 성능과 값을 가르는 핵심 |

## 날씨를 재는 장비

| 용어 | 쉬운 말 |
|---|---|
| GNSS-RO (전파 엇갈림 측정) | GPS 같은 항법 위성의 신호가 대기를 비스듬히 지나며 휘는 정도로 높이별 온도 · 습도를 잰다. 장비가 작아 큐브샛에도 실린다(스파이어) |
| 마이크로파 사운더 | 대기가 내는 마이크로파를 받아 높이별 온도 · 수증기를 잰다. 구름 속도 본다(투모로우.io) |
| 강수 레이더 | 전파를 쏘아 비 · 눈을 직접 잰다. 크고 비싸다(투모로우.io 1세대의 Ka 밴드 레이더) |
| 대기질 분광기 | 빛의 색(스펙트럼)으로 이산화질소 · 오존 같은 물질을 잰다. 정지궤도의 천리안 2B 호 GEMS 가 이 장비 |

## 궤도와 운영

| 용어 | 쉬운 말 |
|---|---|
| 저궤도 (LEO) | 지상 수백 km(대개 400~600km). 지구를 하루 15바퀴쯤 돈다. 한 곳을 계속 보지 못하고 지나가므로 여러 기가 필요하다 |
| 정지궤도 (GEO) | 약 36,000km. 지구 자전과 같이 돌아 한 지역을 계속 본다(천리안). 한 기가 크고 비싸다 |
| 태양동기궤도 (SSO) | 매일 같은 현지 시각에 같은 곳 위를 지나는 저궤도. 관측 위성이 많이 쓰고, 스페이스X 트랜스포터 합승도 이 궤도로 간다 |
| 군집위성 (constellation) | 여러 기를 나눠 띄워 함께 운영하는 것. 많을수록 같은 곳을 자주 본다 |
| 재방문 주기 (revisit) | 같은 곳을 다시 보기까지 걸리는 시간. 위성 수를 늘리는 이유가 이 시간을 줄이는 것 |
| 수명 · 재발사 | 저궤도는 희박한 공기에 끌려 고도가 조금씩 떨어진다 — 낮을수록 빨리(400km 안팎은 몇 달~몇 년). 배터리 같은 부품 수명도 있다. 다 되면 대기권에서 타 없어진다 → 숫자를 유지하려면 계속 새로 쏜다. 「누적 발사」와 「지금 운영 중」이 다른 이유(스파이어 누적 200기+ · 운영 75기+) |

## 발사

| 용어 | 쉬운 말 |
|---|---|
| 라이드셰어 (rideshare) | 로켓 한 대에 여러 회사 위성을 같이 싣는 합승. 싸지만 출발일 · 궤도는 로켓이 정한다. 스페이스X 는 무게로 판다(2026년 50kg 약 35만 달러 · kg 당 약 7,000달러) |
| 전용 발사 (dedicated launch) | 로켓 한 대를 통째로 빌린다. 원하는 궤도 · 시점으로 가지만 비싸다. 많은 수를 한꺼번에 올릴 때 검토한다 |
| 발사 영업 (Commercial Sales) | 스페이스X 안에서 발사를 파는 팀. 스타링크(인터넷)와 다른 조직 — Joel 이 「DTC 와 Rideshare 는 다른 팀」이라고 한 이유 |
| 패스파인더 (시험기) | 본 사업 전에 1~3기를 먼저 띄워 검증하는 것. 「1단계」의 보통 모습(스페이스코인 CTC-0 · 투모로우.io 1호기) |

## 땅과 허가

| 용어 | 쉬운 말 |
|---|---|
| 지상국 (ground station) | 위성과 데이터를 주고받는 큰 안테나 기지. 저궤도 위성은 머리 위를 지날 때 몇 분씩만 통신하므로 여러 곳에 두거나 빌려 쓴다 |
| 주파수 · ITU 신청 | 위성이 쓰는 전파 대역을 국제전기통신연합(ITU)에 신청하고 다른 위성과 간섭이 없게 조정하는 절차. 시간이 걸린다 |
| 위성 등록 · 발사 허가 | 위성을 띄우는 나라의 절차. 국내 위성이면 국내 등록이 따로 있다 |

## 비용 말

| 용어 | 쉬운 말 |
|---|---|
| 개발비 (NRE) | 처음 한 번 드는 설계 · 시험 비용. 1호기가 비싼 이유 |
| 양산 단가 | 같은 위성을 여러 대 찍어낼 때 한 대 값. 많이 만들수록 내려간다 |
| 운영비 | 지상국 · 관제 인력 · 데이터 처리 · 보험. 위성이 떠 있는 동안 계속 든다 |

## 스타링크 견적에 나온 말

| 용어 | 쉬운 말 |
|---|---|
| D2C (Direct to Cell) | 위성이 하늘의 기지국이 되어 일반 LTE 모뎀 · 휴대폰과 바로 통신한다. 통신사와 제휴한 나라에서만 된다(한국 통신사 파트너는 9/28 확인 범위에서 없음 · 일본은 KDDI) |
| 평판 단말 (Flat High Performance) | 스타링크 인터넷을 받는 납작한 안테나. 레이더 기지처럼 데이터가 많은 곳에 단다 |
| 기업 요금 (enterprise data plan) | 회사용 데이터 요금제 — 우선 처리 · 지원이 붙는다 |
| 백홀 (backhaul) | 현장 데이터를 본사 서버로 실어 나르는 큰 회선 |
| 재판매사 (리셀러) | 한국에선 스타링크를 허가받은 국내 사업자를 거쳐 산다(9/28 조사 — SK텔링크 · KT SAT 등) |

## 사례 — 스파이어 글로벌 (Spire Global, NYSE: SPIR) · 10/7 서우 「스파이어 사례도」

| 때 | 일 |
|---|---|
| 2012 | 킥스타터(크라우드펀딩)로 시작한 스타트업(NanoSatisfi → 2015 Spire) |
| 2014 · 2015 | 첫 시험 위성(Lemur-1) · 첫 양산형 LEMUR-2(인도 PSLV 로 발사) |
| 2021-08 | 미국 해양대기청(NOAA) 상업 기상 데이터 구매 — 당시 최대 물량(하루 3,000 개 관측, 위성군 능력은 하루 1만 개+) |
| 2021 | 스팩(NavSight) 합병으로 뉴욕증권거래소 상장 · 기업가치 16억 달러 |
| 2023-12 | 유럽 기상위성기구(EUMETSAT) 다년 계약(2024~2026 · 수백만 유로) |
| 2024 | 매출 인식 · 내부통제 문제로 과거 재무제표 재작성 · 분기 보고 지연으로 거래소 경고(2024-08) |
| 2024-11 → 2025-04 | 선박 데이터(AIS) 사업을 Kpler 에 약 2.41억 달러에 매각(상대가 미뤄 소송 뒤 마무리) → 빚 전부 상환 |
| 2025 | 매출 7,160만 달러(선박 사업 빼면 44% 성장) · 4분기 순손실 2,510만 달러 |
| 2026 | 매출 7,500만~8,500만 달러 전망 · 조정 EBITDA 손익분기 2026년 4분기~2027년 1분기 목표 · 「남의 위성을 대신 만들어 운영」(Space Services — 딜로이트 8기 등) 확대 |

- **위성**: LEMUR = 3U 큐브샛(식빵 크기)에 날씨(GNSS-RO) · 선박(AIS) · 항공기(ADS-B) 수신기를 함께 싣는 다목적 위성. 누적 200기+ 발사 · 2026년 말 운영 75기+ 예상 ·
  위성 공장(미국 · 유럽) · 지상국 · 관제를 직접 한다.
- **날씨 데이터의 큰 손님은 정부 기상청**(NOAA · EUMETSAT) — 높이별 온도 · 습도 · 기압 자료를 예보 모델에 넣는다.
- **읽을 거리**: ① 위성 수가 매출을 정하지 않는다(200기+ 를 쏘고도 매출 7천만 달러대 · 아직 적자) ② 위성 하나에 매출원 여럿(다목적) ③ 숫자를 유지하려면 계속 새로 쏜다
  ④ 직접 만들지 않고 맡기는 길(제작 · 관제 위탁, 남의 위성에 우리 장비만 얹는 「탑재체 호스팅」)도 있다 ⑤ 위성 사업은 장기 계약 · 리스가 얽혀 매출 인식이 까다롭다 —
  상장사는 계약 구조 · 회계 처리를 처음부터 회계법인과.
