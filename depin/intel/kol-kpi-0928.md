  **도달률** = TG · YT 30일 중앙 조회 ÷ 구독자(X 는 평균 조회 ÷ 팔로워) · 추세 = 7일 평균 ÷ 30일 평균 − 1.

  ④ 리스크 없음. ①~④ = 1차 / ③ 미달 = 예비(활동 재확인) / P3 인데 ②③ = 예비(2차 충원) / ② 미달 = 런칭 홍보용 / ④ = 보류.

## 5. 배운 것

1. **도달률이 구독자 수보다 유입을 잘 맞췄다(표본 작음).** Catalyze 22곳(`kol-channels.md` §8 GA 9/15~26)과 겹치는 5곳:
   T.A Crypto 도달 12.5% → 5세션 · 개인적인 DYOR 10.0% → 4 · 코인소년 6.6% → 2 · 꿀찾는 양말 5.5% → 0 · 크립토 부엉이 2.5% → 0 —
   **도달률 순서 = 유입 순서.** 구독자가 가장 많은 코인소년(15.6K)은 3위. 반례: 22곳 밖 HONEYBAG(코인한나의 Honeybag 으로 추정, P4 · 도달 3.2%)
   10세션. **표본 6개이고 세션은 결제가 아니다** → 「판매 성과」 탭을 코드별 결제 완료 건수로 채워 검증한다.
2. **8/25 원본 시트 수치는 쓰지 않는다.** X 「팔로워」 칸은 실측의 중앙값 14%(74만 계정이 8.6천으로 적힘 — 다른 지표가 섞인 것으로 보임),
   TG 평균 조회는 실측 대비 들쭉날쭉(중앙값 0.67배, 30%는 과대 · 6곳은 1.5배+), 일부는 TG+YT 구독 합산. → **제안 직전 재측정.**
3. **TwitterScore 는 도달을 맞추지 전환은 못 맞춘다.** 점수와 평균 조회 순위상관 0.69(45개). 그러나 S(270) @Trader_XO 는 ER 0.48% 로 런칭용,
   D(1) @midrizzy1 은 P1 인데 포렉스 · 라이프스타일 오디언스. 점수는 보조, 선정은 ER · 도달률.
4. **숫자를 부풀리는 패턴 다섯** — 답글 품앗이(ER 과대) · 화이트리스트 기브어웨이(ER 과대) · 바이럴 1건(평균 과대 → 중앙값) ·
   과다 게시(하루 14~29건 → 스폰서 글이 묻힘, 게시 고정 조건 필요) · 저빈도(30일 2~6건 → 표본 부족). 비공개 TG 는 측정 불가.
5. **한국 KOL 라운드는 텔레그램 게임이다.** 한국 X 는 전부 P4 이하, 한국 YT 는 65% 비활동. 1차 한국 8 중 7이 TG.
6. **「노출용」과 「판매용」을 나눈다.** 도달은 큰데 반응이 약한 채널은 10/3 같은 노출 시점에만(게시 단가 · 일정 · 표기), 판매는 반응 채널로.
