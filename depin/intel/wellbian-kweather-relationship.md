# 웰비안 × 케이웨더 관계 구조 (정립 문서)

**목적**: 반복 참조되는 핵심 구조라 business-directions.md에서 분리해 별도 정립. 8/24 내부 회의록
(발화자1의 구조 설명 + 전체 논의)과 기존 축적분을 종합. 법무 확정 전 초안 — 8/27 명문화 회의에서
공식화되면 이 문서를 갱신.

## 한 줄 정의

**케이웨더가 만들고, 웰비안랩스(싱가포르)가 판다.** 웰비안은 케이웨더의 자회사가 아니라 —
케이웨더의 측정기·기술 라이선스를 정상가로 구매하는 **별개의 독립 해외 법인**이며, 이 프로젝트의
Web3·DePIN·토큰 보상 사업 전체를 실질적으로 운영하는 주체다.

| | 케이웨더 (KWeather) | 웰비안랩스 (Wellbian Labs) |
|---|---|---|
| 소재 | 대한민국, 코스닥 상장(090100) | 싱가포르 |

| 이 프로젝트에서 역할 | 제조·수출·데이터 활용·재판매 영업대행 | 플랫폼 운영·토큰 발행·보상 분배·판매 |
| 소유 관계 | 웰비안의 모회사·지분 관계 아님 | 케이웨더로부터 **구매하는** 독립 거래 상대방 |

## 왜 분리했는가 (회의록 원문 근거)

법적 책임 회피가 아니라 **세무·개인정보 처리 문제**가 1차 이유로 명시됨:

> "보상을 받는 사람들이 개인정보를 저희가 취급하는 데 있어서 너무 복잡해지기 쉬운 구조여서,
> 보통 이게 법적인 문제보다는 **세금 이슈** 때문에 해외에서 발행을 하고... 해외에서는 위탁 형태로
> 제공해 줌으로써 법적인 측면에서는 책임이 없습니다." (발화자1, 회의 00:00~01:00)

케이웨더(국내 상장사)가 직접 토큰 보상을 지급하면, 보상받는 개인들의 신원·소득 정보를 국내
세법상 케이웨더가 신고 의무자로서 취급해야 하는 구조가 됨 — 대량의 개인 크립토 지갑 보유자 정보를
상장사가 직접 다루는 리스크. 이를 피하기 위해 싱가포르에 별도 법인(웰비안랩스)을 세우고, **그
법인이 케이웨더의 제품·노하우·특허 라이선스를 정상 비용을 지불하고 사들여** 운영하는 구조로 분리.

## 각자의 역할

**케이웨더가 하는 일:**
1. **제조·수출** — ARC-600DA(내부 코드 "600DA") 측정기를 만들어 웰비안랩스에 수출 판매 (연 25,000대
   목표 — 미달 시 회사 적자 우려가 명시적으로 언급됨). 수출 실적 자체가 상장사 주가에도 의미 있는
   지표라는 언급.
2. **데이터 사용자** — 웰비안랩스 플랫폼에 모인 데이터를 케이웨더도 내부적으로 활용(자사 지수 보정 등).
3. **데이터 재판매 영업대행** — 웰비안랩스가 모은 데이터를 케이웨더가 외부 고객사에 영업·판매하고
   이익을 웰비안랩스와 쉐어. (케이웨더의 기존 B2B 영업망·고객 관계를 그대로 활용하는 구조)

**웰비안랩스가 하는 일:**
1. **Web3 플랫폼 운영** — 노드 등록, 데이터 수집, 검증, 보상 지급을 처리하는 자체 AWS 기반 플랫폼
   (기존 케이웨더의 에어365 플랫폼과는 별도로 신규 구축 — API도 별개).
2. **판매·정산** — 웰비안 DEX/판매 페이지에서 소비자에게 기기를 RLUSD로 판매(원가 대비 약 2배
   가격대 — 국내 웹2 버전 44만원 대비 웹3 버전 목표 약 80~90만원 선). 수취는 RLUSD, 소비자에게는
   웰비안 토큰(재스왑으로 XRP 등 전환 가능)으로 보상 지급.
3. **기업 데이터 공고** — 데이터 수요 기업이 노드 수·기간을 지정해 선입금하면, 해당 조건에 맞는
   노드들에게 추가 보상을 지급하고 데이터를 넘기는 구조(백서 기존 개념, 오늘 회의에서 UI 요건으로
   구체화 — 회원가입 시 "공간 유형" 선택 필드 필요 등).

## 자금·재화·데이터 흐름 (요약)

```
케이웨더 (제조)
  │  기기 수출 (정상가, 마진 포함)
  ▼
웰비안랩스 (싱가포르)
  │  RLUSD로 소비자에게 판매 (원가 대비 ~2배)
  ▼
소비자 (노드 운영자)
  │  공기질 데이터 제공
  ▼
웰비안랩스 플랫폼 (AWS)
  │  ① 웰비안 토큰으로 보상 지급 (재스왑 자유)
  │  ② 데이터 축적
  ▼
케이웨더 (내부 사용 + 외부 재판매 영업대행)
  │  재판매 수익 일부 환류
  ▼
웰비안랩스 ↔ 케이웨더 (이익 쉐어)
```

## 웹2 vs 웹3 — 같은 하드웨어, 다른 브랜드·판로

같은 물리 제품(측정 기능 동일)을 **두 개의 완전히 다른 사업 트랙**으로 판매:

| | 웹2 (기존) | 웹3 (신규) |
|---|---|---|
| 브랜드 | 케이웨더 / 에어365 | 웰비안 (Wellbian) |
| 판매 주체 | 케이웨더 (국내) | 웰비안랩스 (해외, RLUSD) |
| 가격 | 44만원(부가세 포함) | 약 80~90만원대 (RLUSD 표기) |
| 보상 기능 | 없음 | 토큰 보상 있음 |
| 하우징 | 케이웨더 로고 인쇄 | 웰비안 로고 인쇄 (사출틀은 공용, 인쇄만 교체) |
| 펌웨어 | 기존 유지 | 별도 버전 (토큰 보상 UI 포함) |
| 패키징 | 국문판 / **영문판(수출용) 별도** | 웰비안판 별도 |
| 언어 | 국영문 혼용 | 국영문 혼용 (8/24 회의에서 "영어 전용" 방침 번복 — 아래 참고) |

**총 3개 패키징 버전**(케이웨더 국문·케이웨더 영문·웰비안), **펌웨어 2버전**, **하우징 2버전**으로
확정(8/24 회의) — 껍데기(사출)는 공용 재고 활용, 인쇄만 버전별로 분리.
