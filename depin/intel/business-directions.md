## 기술 대비 (수정안·인프라 → 우리 UX)

| 기능 | 우리에게 의미 | 트리거 |
|---|---|---|
| **Sponsor** (지지 ~11%) | 수수료·예치금 대납 → 크립토 무경험 구매자 온보딩 마찰 제거. 활성화 시 구매 UX 재설계 가치 | 지지율 80%×2주 — 주간 스캔으로 추적 |
| **Batch** (~43%) | 결제+NFT 라이선스 발급+영수 원자화 ("전부 실행 or 전부 취소") | 동상 |
| **Confidential Transfer** (~14%) | 기업 데이터 구매 금액 비공개 + 검증 가능 — 데이터 공고 정산에 적합 | 동상 |
| **Permission Delegation** (~20%) | 기관 운영 권한 분리 — 수요처 기업 온보딩 시 요구 가능 | 동상 |
| **t54 (에이전트 결제)** | AI 에이전트가 센서 데이터를 reading 단위로 구매하는 미래 — 잠재 정산 파트너 | 데이터 공고 가동 후 접촉 |
