# 태풍 키우기 — 날씨 미니게임 ④ (v0.1, 2026-10-08)

서우 10/8 요청: 「태풍을 키우는 게임 어때? Three.js 혹은 유니티 엔진으로 실감나게 웹모바일게임」 → 「만들어봐」.
레퍼런스는 웹페이지를 굴러다니며 커지는 괴혼식 브라우저 게임(@measure_plan)이다. **메커닉(작은 것을 삼켜 커지기)만 가져왔고**, 화면 · 연출 · 코드는 새로 만들었다.

- 기존 ② 「태풍의 눈」(`../storm-eye/`)은 기압계를 놓아 **태풍의 길을 바꾸는** 예보 게임이다. 이번 게임에서는 **내가 태풍이 되어 자란다**.
- 화면은 three.js(r160, jsDelivr)로 그린 **정지궤도 위성 시점**이다. 셰이더로 그리는 구름이라 Measured Room v0.13 의 「고무인형」 문제(단순 도형 물체)가 없다.
- 파일은 HTML 하나다(`src/` 에서 빌드). 공식 공개 전이라 `noindex` 를 붙였다.

## 한 판

1. **출발.** 북서태평양 따뜻한 바다(138~158°E, 8~13.5°N 중 무작위)에서 열대요란(1005 hPa, 구름 반경 약 55 km)으로 시작한다.
2. **삼키기.** 내 구름 반경의 0.62배보다 작은 구름만 삼킨다. 구름은 내 몸집에 맞춰 주변에 생긴다. 작을 때는 적운 · 뇌우, 커지면 구름 무리 · 다른 열대요란이 나온다.
   - 삼킬 때마다 몸집(R² += 0.4·s²)과 **수증기**가 는다. 수증기는 시간이 지나면 줄어든다(반감기 약 15시간).
   - 2.6시간 안에 또 삼키면 콤보가 붙어 수증기가 더 붙는다.
   - 큰 구름에 부딪히면 서로 밀려나고 강도가 조금 깎인다. 근처의 큰 구름은 주황 점선으로 표시한다.
3. **자라기.** 강도는 바다가 허락하는 상한(잠재 강도)까지만 큰다. 오르는 속도는 수증기에 달렸다.
   - 잠재 강도 = (해수온 − 26.0℃) ÷ 3.6 이다. 여기에 적도 효과(2.5~6.5°N 에서 0→1), 바람 시어, 육지 비율을 곱해 깎는다.
   - 상한보다 강하면 빠르게 약해진다. 육지 위에서는 더 빠르다.
4. **움직이기.** 이동 = 내 조작 + 지향류다.
   - 지향류: 아열대 고기압 능 남쪽은 북서진, 북쪽은 북동진이다. 능의 서쪽 끝(118~136°E)에서 전향한다. 능의 위도는 판마다 · 시간마다 출렁인다.
   - **강해질수록 지향류가 세게 끌고 가고 내 조작은 약해진다**(조작 1 → 0.5, 흐름 1.4 → 2.8배). 강한 태풍은 결국 전향해 북쪽 찬 바다 · 제트기류로 밀려간다. 이것이 한 판의 끝을 만든다.
5. **끝.** 셋 중 하나로 끝난다.
   - 9일(게임 시간 216시간, 실시간 약 3분 36초)을 다 산다.
   - 24시간 뒤 강도가 거의 0이 된다(육지 6시간 넘게 머물렀으면 「육지에서 힘을 잃음」, 아니면 「바다에서 흩어짐」).
   - 멈춤 카드에서 끝낸다.

시간 압축: 실시간 1초 = 게임 1시간이다. 이동 속도는 놀이 감각에 맞췄고 실제 태풍(시속 20 km 안팎)보다 훨씬 빠르다.

## 점수 — ACE(누적 사이클론 에너지)

- 실제 기상학 지표다. 최대풍속 35 kt 이상일 때 6시간마다 (최대풍속 kt)² × 10⁻⁴ 를 더한다(여기서는 시간 단위로 나눠 연속으로 쌓는다).
- **바다 위에서만 쌓는다.** 육지를 덮쳐서 얻는 점수는 없다. 상륙하면 빠르게 약해지므로 점수에도 손해다.
- 별: ★ ACE 6 · ★★ 16 · ★★★ 30.

강도 표기:
- 최대풍속 = 10 + 60·I m/s, 중심기압 = 1008 − 110·I hPa (I = 0~1)
- 단계: 열대요란 → 열대저압부 → 태풍 약(17 m/s) · 중(25) · 강(33) · 매우 강(44) · 초강력(54). 「태풍의 눈」과 같은 다섯 단계다.
- 눈은 I > 0.42(약 35 m/s)에서 생긴다.

| 차가운 꼬리 | 태풍 아래 0.5° 격자가 0.32·I² ℃/h 씩 식는다(최대 4℃). 72시간 시상수로 회복한다. 한자리에 머물수록 깊어진다 |
| 바람 시어 | 제트기류 띠(34°N ± 출렁임, 대륙 쪽은 더 남쪽)와, 서쪽으로 흘러가는 상층 저기압(TUTT) 셋. 시어 S 는 잠재 강도를 (1 − 0.75·S) 로 깎고, 화면에서는 구름을 바람 아래쪽으로 밀어 비대칭으로 만든다 |

| 구름 생성 | 대류 잠재력 = 해수온(26.0~29.2℃) × (1 − 0.8·시어) × 적도 효과 × 몬순골 가중. 육지 위는 거의 없다 |

## 화면

**층.** 바닥부터 다섯 겹이다.
1. 바다 · 육지 셰이더: 짙은 남색 바다, 대륙붕, 위도 · 건조 지대 색, 노이즈 기복 그늘, 따뜻한 바다 위 무역풍 적운
2. 구름 그림자(해를 남서쪽에 두고 북동쪽으로 드리움)
3. 삼킬 구름: 인스턴싱 260개. 적운 · 뇌우(모루구름) · 구름 무리 · 열대요란(나선) 네 가지
4. 내 태풍: 로그 나선 + 이음매 없는 노이즈를 두 위상으로 섞어 감김이 끝없이 조여드는 것을 막았다. 중심 구름 덩어리 · 팔 사이 안개 · 눈 · 눈벽 · 상층 유출 권운 · 시어 비대칭 · 상륙 붕괴
5. 제트기류 권운 줄무늬와 상층 저기압 소용돌이

**화면 셋**(오른쪽 위 · V 키):
- 위성: 눈으로 보는 구름이다.
- 적외: 구름 꼭대기 온도를 방송 위성사진 같은 강조 색표로 보여 준다. 해안선 · 5° 경위선이 붙는다.
- 수온: 해수면 온도 색, 26.5℃ 선(흰색), 1℃ 등온선을 보여 준다. 지나온 차가운 꼬리가 보인다.

**카메라.** 몸집이 커질수록 멀어진다(가로 폭 = 2·(3.6R + 1.8)°, 최대 60°). 위에서 16° 기울여 내려다본다. 넓게 볼 때(15° 이상)는 도시 이름 14곳을 띄운다. 이름 표시만 하고 피해 판정은 없다.

**조작.**
- 휴대폰: 화면을 누른 채 가고 싶은 쪽으로 민다. 태풍에서 손가락까지 방향으로 가고, 70 px 이상이면 최대 속도다.
- 키보드: 방향키 / WASD, V 화면 바꾸기, P · Esc 멈춤.
- 주황 화살표 = 내 조작, 하늘색 화살표 = 큰 흐름이다.

**알림.** 단계 상승, 눈 생김, 상륙, 큰 구름, 차가운 바다(26.5℃ 미만), 바람 시어, 차가운 꼬리, 적도, 큰 흐름 안내가 뜬다. 같은 경고는 게임 시간 22~30시간에 한 번만 뜬다.

**결과 카드.** 별, ACE, 최저 기압, 최고 단계, 최대풍속, 삼킨 구름, 최대 반경, 지나온 길 지도(하루 점 · 단계 색)를 보여 준다. 결과 복사가 되고, 이 기기 최고 ACE 는 localStorage 에 남는다.

**느린 기기.** 2초 평균 프레임이 28 ms 를 넘으면 픽셀 비율을 1.75 에서 0.35 씩 1 까지 낮춘다. WebGL 이 없으면 안내 문구만 띄운다.

## 대외 규칙

- 토큰 · 경품 · 베팅은 없다. 점수(ACE · 별)만 있다.
- 실제 태풍 이름 · 실제 관측 데이터는 쓰지 않는다. 해수온 · 흐름 · 시어는 모두 내부 모형이다. 「교육용으로 단순화한 모형 날씨이며 실제 예보가 아닙니다」는 시작 · 결과 카드와 플레이 화면 바닥에 고정한다.
- **피해를 점수로 만들지 않는다.** 도시는 이름만 띄우고, 상륙은 「약해진다」로만 다룬다(10/8 판단: 날씨 회사가 「도시를 덮쳐 점수」를 만들면 논란).
- 바닥글은 「날씨 미니게임 · 프로토타입」이다. 브랜드(케이웨더 / Weather Plan AI / wellbian)는 서우가 고르기 전까지 붙이지 않는다.

## 빌드 · 점검

```
cd depin/site/typhoon-grow/src
node build.js                  # → ../index.html  (--artifact <파일> 로 아티팩트용도)
node tune.js [판 수] [봇]        # 균형: idle · rand · greedy
node geo.js <land-50m.json>      # 해안선 coast.json 다시 만들기(world-atlas 원본은 저장소에 넣지 않음)
```

**검증.** 로컬 Playwright, swiftshader WebGL 환경에서 확인했다.
- 화면: 1280×800, 390×844 · 시작 카드(태풍을 옆/위로 비켜 둠) · 플레이 초반 · 중반(매우 강 · 초강력) · 화면 셋
- 실행: 자동 조종으로 9일 완주 → 결과 카드(지나온 길 지도)
- 콘솔 오류 0. 구글 폰트는 샌드박스에서 막혀 대체 글꼴로 찍혔다.
