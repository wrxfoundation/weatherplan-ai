# 태풍의 눈 — 날씨 미니게임 ② (v0.1, 2026-09-25)

서우 9/25 요청: 웹에서 링크로 바로 실행되는, 날씨·기상이변 게임이며 재미가 먼저인 것. 세 가지 안을 「2 1 3 순으로」 → ② 태풍의 눈부터 만들었다.
파일은 HTML 하나다. 외부 라이브러리 없이 자체 WebGL 셰이더와 2D 캔버스로 그린다.

- 아티팩트(비공개): https://claude.ai/artifact/NF62s9PvKCrGy2Yr3dRH5Y — 다른 사람에게 보이려면 서우가 Share 메뉴에서 공유한다.
- 저장소 사본: `index.html`(`src/` 에서 빌드, 공식 공개 전 `noindex`).

## 한 판의 흐름

1. 레벨마다 가상 태풍(T-01~T-05) 하나가 남쪽 바다에서 출발한다. 지도 범위는 동아시아(116~139.5°E, 17~42°N, 메르카토르)이고 도시는 17곳이다.
2. 도구 세 가지를 지도에 끌어다 놓는다. 놓는 즉시 중심 예보, 앙상블 30개, 도시별 강풍 반경 진입 확률이 다시 계산된다.
   - 고기압: 시계 방향 흐름으로 태풍을 밀어낸다.
   - 저기압: 반시계 방향으로 태풍을 끌어당기고, 태풍이 닿으면 흡수된다.
   - 관측소: 반경 안의 예보 선들을 한데 모은다.
3. 출발하면 앙상블 30개 중 하나가 실제 진로가 된다. 화면의 확률이 그대로 결과 확률이다.
4. 별은 피해 도시 수로 정한다: 0곳 ★★★, 1곳 ★★, 2곳 ★. T-03 은 1곳 이하여야 통과다.

## 대외 규칙

- 토큰·경품·베팅은 없다. 점수(별)만 있고, 저장은 그 기기의 localStorage 뿐이다(9/24 시뮬레이터 도박법 선과 같다).
- 실제 태풍 이름은 쓰지 않는다(가상 코드 T-01~05). 「교육용 모형 날씨이며 실제 예보가 아닙니다」 문구는 고정이다.
- 외부 데이터·오라클은 호출하지 않는다. 예보와 해수면 온도는 모두 내부 모형이다.
- 지도는 Natural Earth 50m 해안선(퍼블릭 도메인, world-atlas 경유)이다.
- 도시는 나라를 가리지 않고 모두 지킨다(서울·평양·상하이·타이베이·오사카·아파리 등). 한 나라로 떠넘기는 해법은 아래 상륙 규칙이 막는다.

## 모형 (`src/sim.js`)

**지향류.** 저위도에서는 북서진하고 24~32.5°N 에서 전향해 중위도에서 북동진한다. 레벨마다 `flow` 로 바꿀 수 있고, T-04·T-05 는 전향을 늦춘다.

**기압계.** 가우시안 영향권 안에서 밀기/당기기와 회전 성분을 더한다.
- 고기압: A 0.28, R 5°
- 저기압: A 0.25, R 6.5°, 1.4° 안에 들면 흡수된다.
- 놓은 기압계는 60h 부터 약해져 100h 에 사라진다. 그 뒤 태풍은 배경 흐름을 따르므로 가둬 두기 편법이 먹히지 않는다.
- 고정 북태평양 고기압은 끝까지 유지된다.

**강도 I(0~1).**
- 해수면 온도 26.4℃ 를 기준으로 커지거나 약해진다(위도 경도 + 쿠로시오 난류 띠).
- 육지 위에서는 시간당 0.035 씩 줄고, 35°N 이북에서는 추가로 약해진다.
- 표시값: 중심기압 1008−88I hPa, 최대풍속 17+45I m/s, 강풍 반경 0.5+1.1I°. 등급은 약·중·강·매우 강·초강력이다.

**피해 판정.**
- 강도 0.15 이상인 태풍의 강풍 반경 안에 든 도시가 피해를 입는다.
- 상륙 규칙: 강한 태풍이 육지에 닿으면 가장 가까운 도시가 피해를 입는다. 도시 사이 빈 해안으로 빼돌리는 해법을 막는다.
- 적도 쪽 가장자리는 벽이다. 남쪽으로 밀어 지도 밖으로 빼는 편법을 막는다.

**앙상블 30.** 멤버마다 일정한 속도 편향과 느린 흔들림을 넣어 오차가 시간에 따라 커지게 했다. 잡음 0.035 일 때 평균 이탈은 24/48/72h 에 ≈ 0.4/1.0/2.0° 다. 관측소 반경 안에서는 멤버를 중심 예보 쪽으로 당긴다(자료 동화 비유).

## 화면

**층.** 바닥부터 네 겹이다.
1. 바탕: 해수면 온도 색, 경위선, 26℃ 등온선, 육지
2. 예보: 강풍 반경 띠, 앙상블, 중심 예보
3. WebGL 태풍: 로그 나선과 fbm, 눈·눈벽, 반시계 회전
4. 위층: 도시, 기압계, 관측소, 실제 진로

WebGL 을 쓸 수 없는 기기에서는 2D 로 대신 그린다.

**조작.**
- 칩을 지도로 끌어다 놓거나, 칩을 탭한 뒤 지도를 탭한다.
- 놓은 도구는 끌어서 옮긴다. 한 번 누르면 ✕ 가 나오고, ✕ 를 누르면 거둔다.
- 키보드: 칩에서 Enter → 방향키로 0.5° 씩(Shift 는 1.5°) 옮김 → Delete 로 거둠.

**모바일.** 지도 바로 아래에 도구와 출발 버튼이 온다. 결과 카드는 지도를 가리지 않도록 패널 맨 위에 둔다. 레벨을 열면 제목과 힌트가 토스트로 뜬다.

## 빌드·점검

```
cd depin/site/storm-eye/src
node build.js                  # → ../index.html  (--artifact <파일> 로 아티팩트용도)
node tune.js [레벨] [시도 수]    # 레벨 균형: 도구 없을 때 진로·무작위 ★★★·해 골짜기 폭
node scan.js <레벨> H|L|S        # 도구 하나의 해 영역 지도(0.5° 격자)
node opt.js <레벨>               # 언덕 오르기로 최선 배치 찾기
```

`coast.json`·`mask.json` 은 `geo.js` 로 다시 만든다. world-atlas 패키지의 `land-50m.json` 을 같은 폴더에 두고 실행하면 된다(원본은 저장소에 넣지 않음).

**검증.** 로컬 Playwright, swiftshader WebGL 환경에서 확인했다.
- 화면: 1280×900, 390×844, WebGL 끈 2D 대체
- 조작: 칩 끌어 놓기(실제 포인터 이벤트), 탭 배치, 키보드 배치·이동·삭제
- 실행: T-01 ★★★(동쪽 이탈), T-03 관측소 ★★★(서쪽 이탈), T-04 무배치 실패 카드
- 콘솔 오류 0. 구글 폰트 인증서 오류는 샌드박스 프록시 때문이다.
