## 공개 범위 — 비밀번호 없음(9/29 서우 지시)

주소를 아는 누구나 연다(`noindex` 로 검색에는 안 잡힌다). 그래서 근거 문구는 **대외 금지 규칙에 걸리지 않게** 쓴다 —
업비트 트랙 · 리플 채널 · 보험 레인 · 멀티체인 조건 · 미팅 일정 · 1촌 여부 · 파트너 클레임(디센트 · 타임레버리지) · Eri 미팅 내용은
공개 가능한 표현으로 바꾸거나 뺐다(`XS_WHY` · `XS_PE_DROP` · `PMARK`). 「수첩」 칩(우리 판정 기록에 있는 사람)도 끈다.
자세한 내부 근거는 docx(`reports/XRP SEOUL 2026 연사 프로필.md`)와 intel 문서에 그대로 있다.

다시 잠그려면 `EVENT_PASS='…'` 를 주고 빌드한다(PBKDF2 → AES-GCM, 브라우저 WebCrypto 로 연다 · 비밀번호는 저장소 · 로그 밖).

## 배포

`www/` 폴더 통째(Vercel 드롭 — 예: 새 프로젝트 `wellbian-event-week`). `vercel.json` = `noindex` · `no-store`.
전달 zip 은 `www/` 안 두 파일(index.html · vercel.json)을 루트에 둔다.

## 갱신

```bash
# 판정 · 소속 · 세션 → tools/build.py (ORG · PMARK · PNOTE · SMARK · XS_*)
# XRP SEOUL 설명 · 결 근거 → 저장소 루트 reports/XRP SEOUL 2026 연사 프로필.md
python3 depin/site/event-week/tools/build.py                         # → www/index.html (비밀번호 없음)
EVENT_PASS='…' python3 depin/site/event-week/tools/build.py          # 다시 잠글 때만
python3 depin/site/event-week/tools/build.py --plain /tmp/x.html     # 다른 경로로 출력
```

빌드는 이름이 어긋나면 멈춘다(ORG · SMARK · XS_* · RANK · KO · KBW_DESC 가 아젠다 · md 에 없거나, 표시된 사람에 순위가 없으면 assert).
