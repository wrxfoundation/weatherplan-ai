## 공개 범위 — 비밀번호 없음(9/29 서우 지시)

주소를 아는 누구나 연다(`noindex` 로 검색에는 안 잡힌다). 그래서 근거 · 인물 문구는 **대외 금지 규칙에 걸리지 않게** 쓴다 —
업비트 트랙 · 리플 채널 · 보험 레인 · 멀티체인 조건 · 미팅 일정 · 1촌 여부 · 파트너 클레임(디센트 · 타임레버리지) · Eri 미팅 내용은
공개 가능한 표현으로 바꾸거나 뺐다(`XS_WHY` · `XS_PE_DROP` · `PMARK` · `FIT`). 「수첩」 칩(우리 판정 기록에 있는 사람)도 끈다.
자세한 내부 근거는 docx(`reports/XRP SEOUL 2026 연사 프로필.md`)와 intel 문서에 그대로 있다.

**마지막 관문(`PUBLIC_BAN` · `prof_gate`)**: 비밀번호 없는 빌드는 데이터 + 템플릿에 금지 구절(위 규칙 · 날씨 × x402 · 예측시장 × 우리 이름 ·
「국내 최대/1위」 · 자회사 · WLBN 코인 · 서우 등)이 하나라도 있거나 인물 상세 본문에 성별 대명사가 있으면 **파일을 쓰지 않고 멈춘다**.
제3자의 공개 경력(「재보험 언더라이터 출신」)은 막지 않는다.

다시 잠그려면 `EVENT_PASS='…'` 를 주고 빌드한다(PBKDF2 → AES-GCM, 브라우저 WebCrypto 로 연다 · 비밀번호는 저장소 · 로그 밖).

## 배포

`www/` 폴더 통째(Vercel 드롭 — 예: 새 프로젝트 `wellbian-event-week`). `vercel.json` = `noindex` · `no-store`.
전달 zip 은 `www/` 안(index.html · vercel.json · fonts/)을 루트에 둔다. 한 파일짜리 html 은 서체를 CDN 에서 받는다.

## 갱신

```bash
# 판정 · 소속 · 세션 → tools/build.py (ORG · PMARK · PNOTE · SMARK · XS_* · TIERS · FIT · KBW_DESC)
# XRP SEOUL 설명 · 결 근거 → 저장소 루트 reports/XRP SEOUL 2026 연사 프로필.md
# 인물 상세 → tools/profiles.json (사람마다 key · summary · now · career · edu · also · base · org · record · views · talk · sources · check)
python3 depin/site/event-week/tools/build.py                         # → www/index.html (비밀번호 없음 · 공개 관문 통과해야 씀)
EVENT_PASS='…' python3 depin/site/event-week/tools/build.py          # 다시 잠글 때만
python3 depin/site/event-week/tools/build.py --plain /tmp/x.html     # 다른 경로로 출력
```

빌드는 이름이 어긋나면 멈춘다(ORG · SMARK · XS_* · RANK · KO · KBW_DESC · profiles · FIT 가 아젠다 · md 에 없거나, 표시된 사람에 순위가 없으면 assert).
