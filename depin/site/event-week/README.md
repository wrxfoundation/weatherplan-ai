## 공개 범위 — 비밀번호 없음(9/29 서우 지시)

자세한 내부 근거는 docx(`reports/XRP SEOUL 2026 연사 프로필.md`)와 intel 문서에 그대로 있다.

# 시간대별 칸 한 줄 → tools/build.py BRIEF (없으면 순위 근거 → 근거, 리플 · 우리는 없음)
# 국내 묶음 → tools/build.py TIERS 「kr」 + KR_FIELD(분야) — 할 일은 현장 한 칸
# 관련자에서 뺄 사람 → tools/build.py NOT_TARGET (표시 · 순위 · 할 일 · 상세 없이 표 맨 끝)
python3 depin/site/event-week/tools/build.py                         # → www/index.html (비밀번호 없음 · 공개 관문 통과해야 씀)
