# 태풍 속으로 — 날씨 미니게임 ⑤ (v0.1, 2026-10-09)

서우 10/9 「태풍 안으로 들어가 보기 게임 같은 건 어때?」 → 「만들어봐」.
관측기를 몰고 눈벽을 뚫어 태풍의 눈 한가운데에 낙하 관측기(드롭존데)를 떨어뜨린다. 가장 낮은 기압을 정확히 잴수록 점수가 높다.
실제로 허리케인 헌터(미 공군 · 해양대기청)가 대서양 허리케인에서 하는 일을 옮겼다.

- ④ 「태풍 키우기」(`../typhoon-grow/`)는 위에서 내려다보며 태풍이 되는 게임이다. 이 게임은 그 안으로 들어가는 1인칭 게임이다.
- 「측정한 값이 기록으로 남는다」가 핵심 행동이다. 결과 카드에 측정 기록의 SHA-256 지문을 보여 준다(데모 — 어디에도 올리지 않음).
- 아티팩트(비공개): https://claude.ai/artifact/2bqLn3vJi2pz97g4mwRkmX — 다른 사람에게 보이려면 서우가 Share 메뉴에서 공유한다.
- three.js(r160, jsDelivr) · 파일 하나(`src/` 에서 빌드) · 웹 오디오 · 공식 공개 전이라 `noindex`.

## 한 판 (실시간 약 1분 반~2분 반)

1. **고르기.** 가상 태풍 셋: 강(960 hPa · 최대풍 반경 34 km) · 매우 강(935 · 25 km) · 초강력(908 · 17 km).
2. **바깥 나선 띠.** 눈에서 4.4 × 최대풍 반경(60~130 km) 떨어진 곳에서 대략 중심을 향해 출발한다. 비구름 덩어리 · 빗줄기 · 바다의 바람 줄무늬가 보인다.
3. **눈벽.** 하얗게 시야가 사라지고, 흔들림 · 번개 · 천둥이 가장 세다. 기체 부하가 가장 많이 쌓인다.
4. **눈.** 갑자기 고요해지고 위로 하늘이 뚫린다. 위로 갈수록 바깥으로 벌어지는 구름 벽(「경기장」)과 아래 낮은 구름 · 바다가 보인다.
5. **투하.** 낙하 관측기 2개. 떨어지는 4.5초 동안 바람에 떠밀린 자리의 지상 기압을 잰다. 둘 중 더 낮은 값이 측정값이다.
6. **끝.** 둘 다 착수하면 「관측 완료」. 기체 부하 100% · 연료(4분) · 태풍에서 멀어짐 · 멈춤에서 돌아가기로도 끝난다.

**조작.** 휴대폰은 화면을 좌우로 끈다(110 px 이면 최대 선회). 키보드는 ← → / A D, Space 투하, P 멈춤.
**계기.** 기수 방위 · 비행 고도 바람(세기 + 기수 기준 방향 화살표) · 외삽 지상 기압 · 대지 속도 · 기체 부하 · 남은 관측기 · 연료 · 레이더(기수 위, 반경 40~70 km).

## 모형 (`src/sim.js`)

| 요소 | 식 |
|---|---|
| 기압 | Holland(1980): p(r) = pc + Δp · exp(−(Rm/r)^B), B = 1.6, 바깥 1010 hPa |
| 최대풍 | Atkinson–Holliday 근사 지상 3.447 · Δp^0.644 m/s, 비행 고도 = 지상 ÷ 0.9 |
| 바람 | Rm 안은 (r/Rm)^1.25 로 줄고, 밖은 정규화 Holland 형. 반시계 회전 · 바깥은 18° 안으로 감겨 듦 · 진행 속도 6 m/s 의 0.55배를 더함 → 진행 방향 오른쪽이 셈 |
| 눈 | 반경 0.78 Rm(비행 고도) |
| 눈벽 난류 · 비 | 1.05 Rm 에 폭 0.32 Rm 가우시안 × (오른쪽 앞 0.72~1.0) × 얼룩 |
| 나선 띠 | 2 · (θ + 1.35 ln(r/Rm)) 두 팔, 1.7~10 Rm |
| 기체 부하 | 초당 8.5 · max(0, 난류 − 0.22)^1.5 % |
| 낙하 관측기 | 떨어지는 실제 270초 동안 비행 고도 바람의 0.8 → 0.55배로 떠밀림. 착수 지점 기압 ± 0.3 hPa |
| 비행 | 대기속도 100 m/s, 시간 압축 9배, 최대 선회 14°/s |

**별**: 눈에 들어갔으면 ★ · 측정 오차 2 hPa 이하 ★★ · 0.6 hPa 이하 + 기체 부하 60% 이하 ★★★. 부하 100% 면 별 0.

## 균형 (봇 40판 × 태풍 셋, `node src/tune.js 40 0.3`)

봇은 중심 위치를 알고 날며, 비행 고도 바람이 최대풍의 30% 아래로 잦아들면 투하한다.

| 태풍 | 봇 | 기체 부하 p10 / 50 / 90 | 시간 중앙값 | 별 0/1/2/3 |
|---|---|---|---|---|
| 강 | 곧장 | 4.7 / 26.3 / 56.7% | 129 s | 0/0/3/37 |
| 강 | 약한 쪽으로 돌아 진입 | 5.0 / 14.6 / 62.4% | 141 s | 0/0/5/35 |
| 매우 강 | 바람 보정 | 9.1 / 30.8 / 74.8% | 120 s | 0/0/6/34 |
| 매우 강 | 약한 쪽으로 돌아 진입 | 7.6 / 19.8 / 73.3% | 121 s | 0/0/8/32 |
| 초강력 | 바람 보정 | 10.3 / 30.1 / 76.4% | 87 s | 0/0/9/31 |

- 진입 방향이 부하를 가른다(약한 쪽 진입이 중앙값 10%p 안팎 낮다).
- 봇은 중심을 알아서 오차가 거의 0 이다. 사람은 레이더의 맑은 구멍과 바람 · 기압 계기로 중심을 찾아야 하므로 더 어렵다.
- 바람 30% 대신 45% 에서 일찍 투하하면 오차가 0.5~0.8 hPa 로 커져 ★★ 가 늘어난다.

## 화면

- **하늘**: 눈 안에서만 파란 하늘 · 해. 밖에서는 안개색.
- **바다**: 바람 방향으로 늘어선 거품 줄무늬, 바람이 셀수록 많아진다.
- **구름 밑면**: 고도 5.2 km. 눈 위에는 구멍이 있다.
- **눈벽 「경기장」**: 선반 회전체(200분할), 버텍스 노이즈로 울퉁불퉁하게 했다. 위가 해에 밝고 아래 비 내리는 쪽은 어둡다. 천천히 돈다.
- **눈 바닥**: 1 km 층적운.
- **바깥 비구름 덩어리**: 나선 띠에서 고른 90개, 카메라를 향한 세로 판.
- **안개**: 시정이 비에 따라 0.35~24 km, 눈 안은 55 km.
- **빗줄기**: 선분 600개, 카메라 주변에서 계속 다시 생긴다.
- **창 물방울 · 조종석 창틀**: 2D 캔버스.
- **번개**: 화면 섬광 + 지연된 천둥.
- **흔들림**: 난류만큼. 「흔들림 줄이기」를 켜면 1/4.
- **소리**: 바람(대역 필터 노이즈) · 빗소리(고역 노이즈) · 엔진(톱니파 셋) · 천둥. 이륙을 누를 때 켜진다(브라우저 자동 재생 규칙).
- **결과 카드**: 별 · 잰 기압 / 실제 기압 · 오차 · 착수 지점 — 중심 거리 · 최대 비행 고도 바람 · 부하 · 경로 지도(레이더 위 경로 · 투하 → 착수 · 실제 중심 십자) · 측정 기록 지문 · 결과 복사.

## 대외 규칙

- 토큰 · 경품 · 베팅 0, 점수(별)만.
- 가상 태풍이다. 실제 태풍 이름 · 관측값은 쓰지 않는다. 「교육용으로 단순화한 모형 날씨이며 실제 예보가 아닙니다」를 시작 · 결과 카드와 플레이 화면에 고정한다(휴대폰 플레이 화면에서는 계기와 겹쳐 숨김).
- 기체 부하 100% 는 「기체 점검을 위해 돌아왔습니다」로만 다룬다. 사고 · 추락 연출은 없다.
- 지문은 데모 — 원장에 올리지 않는다는 문구를 함께 띄운다. 브랜드는 서우가 고르기 전까지 붙이지 않는다(바닥글 「날씨 미니게임」).

## 주소 해시

|---|---|
| `#play=1` | 바로 이륙(소리는 사용자가 누른 뒤에만) |

| `#seed=5` | 판 고정 |
| `#auto=1&speed=12` | 자동 조종 · 배속(점검용) |
| `#noise=lo` | 노이즈 텍스처 128² |
