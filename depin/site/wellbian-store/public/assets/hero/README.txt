히어로 배경 — 여기를 덮어쓰세요
============================================================

8/29부터 히어로 배경은 "루프 영상"입니다.

  hero-loop.mp4           ← 영상. 이 파일만 덮어쓰면 배경이 바뀝니다.
  hero-loop-poster.webp   ← 정지컷(선택). 영상이 뜨기 전 0.5초와
                             "모션 줄이기" 설정에서 이게 보입니다.

  정지컷을 안 바꿔도 동작은 합니다. 다만 영상 첫 화면과 장면이 다르면
  로딩 순간에 한 번 바뀌는 게 보입니다. 맞추려면 영상 첫 프레임을 캡처해 넣으세요.


교체 순서
------------------------------------------------------------
  1. 배포 zip 압축 해제
  2. public/assets/hero/hero-loop.mp4 를 새 영상으로 덮어쓰기
     (파일명은 반드시 hero-loop.mp4 그대로)
  3. 다시 압축 → Vercel 배포

  코드는 손댈 필요가 없습니다.


힉스필드 영상을 그대로 넣으면 안 됩니다 (중요)
------------------------------------------------------------
힉스필드 원본은 HEVC(H.265) 코덱입니다. 사파리는 열지만
크롬·파이어폭스는 대체로 열지 못해 화면이 정지컷에서 멈춥니다.
반드시 H.264 로 변환해서 넣으세요.

  hero-loop.mp4    H.264(avc1) · 오디오 없음 · 1920x1080 · 3MB 내외

  용량을 1MB 아래로 조이지 마세요. 홀로그램 등고선이 뭉개집니다.
  힉스필드 다운로드 자체가 2~3MB라 그대로 넣어도 됩니다.

  증상: 사파리에서는 잘 도는데 크롬에서 배경이 정지 사진처럼 멈춰 있다
       → 코덱이 HEVC 라는 뜻입니다.

  무료 변환 (cloudconvert.com 등):
    - 출력 mp4 → 비디오 코덱 H.264, 오디오 없음(remove audio)
    - 해상도 1920x1080 유지, 목표 용량 1MB 전후

  포스터는 영상 첫 프레임을 캡처해 squoosh.app 에서
  WebP · Quality 84 · Width 1920 으로 저장하세요 (150KB 내외).


루프 이음매
------------------------------------------------------------
영상은 끝나면 곧바로 처음으로 돌아갑니다.
첫 프레임과 끝 프레임이 다르면 몇 초마다 화면이 툭 끊깁니다.

  현재 파일은 끝 20프레임을 첫 20프레임에 겹쳐(크로스페이드)
  이음매를 없앤 4.21초짜리입니다.

  새 영상을 그냥 넣으면 이 처리가 빠집니다 — 끊김이 보이면
  같은 처리가 필요하다는 뜻이니 알려주세요.


구도 주의
------------------------------------------------------------
히어로는 왼쪽 약 45%를 어두운 스크림이 덮고 그 위에 흰 글씨가 올라갑니다.

  +--------------------------------------------------+
  |  [어두운 스크림 + 흰 글씨]   |   제품 · 홀로그램  |
  |   <- 왼쪽 45%                |   <- 오른쪽        |
  +--------------------------------------------------+

  - 기기와 홀로그램은 화면 "오른쪽"에 두세요.
  - 모바일에서는 가로 65% 지점을 기준으로 잘립니다.
    (기기가 그 근처에 있어야 화면에 남습니다)
