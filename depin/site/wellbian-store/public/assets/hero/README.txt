히어로 배경 이미지 — 여기를 덮어쓰세요
============================================================

  hero-bg.webp   ← 이 파일이 랜딩 히어로 배경입니다.
                    같은 이름으로 덮어쓰면 바로 반영됩니다.
                    코드는 손댈 필요 없습니다.

지금 들어 있는 건 현재 운영 중인 이미지입니다.
교체 전에 배포해도 화면이 비지 않습니다.


작업 순서
------------------------------------------------------------
  1. 배포 zip 압축 해제
  2. public/assets/hero/hero-bg.webp 를 새 이미지로 덮어쓰기
     (파일명은 반드시 hero-bg.webp 그대로)
  3. 다시 압축 → Vercel 배포


권장 규격
------------------------------------------------------------
  형식    WebP
  해상도  1920 x 1080 (16:9)
  용량    400KB 이하 (최대 800KB)
          ※ 현재 파일은 2000x1125 / 427KB

  힉스필드 원본 PNG(3840x2160, 12MB 내외)를 그대로 넣지 마세요.
  초기 로딩이 느려지고 Vercel 대역폭도 낭비됩니다.

  무료 변환 (squoosh.app):
    1) squoosh.app 접속 후 이미지 드래그
    2) 우측 포맷 = WebP, Quality 72 전후
    3) Resize 체크 → Width 1920
    4) Download → 파일명을 hero-bg.webp 로 바꿔 덮어쓰기


구도 주의 (중요)
------------------------------------------------------------
히어로는 배경을 오른쪽 기준으로 자르고(background-position: right center),
왼쪽 약 45%는 어두운 스크림이 덮여 그 위에 흰 글씨가 올라갑니다.

  +--------------------------------------------------+
  |  [어두운 스크림 + 흰 글씨]   |   제품 · 피사체    |
  |   <- 왼쪽 45%                |   <- 오른쪽        |
  +--------------------------------------------------+

  - 제품이나 보여줄 피사체는 이미지 "오른쪽"에 두세요.
  - 왼쪽에 중요한 게 있으면 글씨에 가려집니다.
  - 모바일에서는 위쪽 30% 지점 기준으로 잘립니다.


JPG/PNG로 넣고 싶다면
------------------------------------------------------------
확장자만 바꿔서는 안 됩니다. 코드 한 줄을 같이 고쳐야 합니다.

  components/Landing.tsx 에서
    const HERO_BGS = ["/assets/hero/hero-bg.webp"];
  를
    const HERO_BGS = ["/assets/hero/hero-bg.jpg"];
  로 바꾸고, 파일도 hero-bg.jpg 로 넣으세요.

  (WebP가 같은 화질에서 30~50% 가볍기 때문에 WebP를 권장합니다.)
