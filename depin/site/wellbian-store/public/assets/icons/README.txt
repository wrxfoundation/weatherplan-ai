아이콘 PNG 넣는 곳
============================================================

지금은 코드 안에 그린 SVG 아이콘이 쓰이고 있습니다.
프롬프트로 생성한 PNG로 바꾸려면 여기에 파일을 넣고 코드에서 한 줄만 주석 해제하면 됩니다.

프롬프트는  depin/content/icon-prompt.md  에 있습니다.


1) 이 폴더에 넣을 파일명
------------------------------------------------------------
  4단계 카드
    measure.png   ① 측정   (측정기 + 화면)
    verify.png    ② 검증   (방패 + 체크)
    reward.png    ③ 보상   (토큰 스택)
    use.png       ④ 활용   (막대 차트)

  선순환 칩
    data.png      검증된 데이터   (슬래브 3장)
    flow.png      기업이 구매     (타일 + 밖으로 나가는 화살표)
    coins.png     대금이 보상 재원 (동전 스택)
    nodes.png     측정망 확대     (연결된 구 4개)


2) 코드에서 켜기
------------------------------------------------------------
  components/GlassIcons.tsx 맨 위의 ICON_PNG 에서
  바꾼 아이콘 줄의 주석(//)만 지우면 됩니다.

    const ICON_PNG: Partial<Record<IconKey, string>> = {
      measure: "/assets/icons/measure.png",     <- 이렇게
      // verify: "/assets/icons/verify.png",
      ...
    };

  적어두지 않은 아이콘은 기존 SVG가 그대로 쓰입니다.
  일부만 바꿔도 되고, 섞여 있어도 화면은 깨지지 않습니다.

  ※ 파일만 넣고 주석을 안 지우면 아무 일도 일어나지 않습니다.
    반대로 주석을 지웠는데 파일이 없으면 그 자리가 빕니다.
    (없는 파일을 매번 요청하는 낭비를 막으려 자동 감지를 넣지 않았습니다.)


3) 규격
------------------------------------------------------------
  형식    PNG, 투명 배경 권장
  크기    512 x 512
  용량    장당 120KB 이하
  여백    사방 8% 정도 비울 것 (카드 안에서 잘리지 않게)

  투명 배경으로 못 뽑으면 흰 배경도 괜찮습니다.
  카드 배경이 밝아서 크게 티가 나지 않습니다.


4) 주의
------------------------------------------------------------
  아이콘 안에 글자를 넣지 마세요.
  특히 동전에 통화 기호(원, 달러)를 넣으면 안 됩니다 —
  보상은 현금이 아니고 지급량과 가치가 보장되지 않아 오인 소지가 있습니다.
