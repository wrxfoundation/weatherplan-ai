# Measured Room — 집 하나의 공기 시뮬레이션 (v0.11.3, 2026-09-03)

서우 제안: "실내 공간에 디바이스로 공기 측정하는 것을 시뮬레이션하는 VR 월드". 단일 HTML, 외부 라이브러리 없음 —
거실·침실·주방 세 공간, 상황(요리·창문·밤)마다 바뀌는 **실사 장면(사진 + 5초 앰비언트 영상 루프, 기기는 장면 속에 렌더링)** 위에
자체 WebGL 셰이더로 먼지(PM2.5)·김(조리)·뿌연 막과 광원 산란(CO₂·연기)·필름 그레인을 얹고, 기기 화면은 2D 캔버스를 원근으로 합성한다.
PM2.5·CO₂가 변하면서 5분마다 기록 하나가 쌓인다.

- 용도: 10/3 부스 화면(터치), 랜딩 데모, 키노트 클립 소재. 캡션은 항상 "개념 시뮬레이션 · concept render".
- 규칙: 화면에 공기질 등급 라벨 없음(곡선·숫자만) · 토큰·코인 아이콘 없음 · "보상은 테스트 중" 고정 문구 · 실물 사진 대체 아님 · 공식 공개 전 `noindex`.

## v0.10.2 — 무엇이 바뀌었나 (서우 9/3 아침: "창문 열기·닫기 화면 전환이 안 된다")

v0.10 에서 "낮·밤 조명만" 을 **사진을 방마다 낮·밤 두 장으로 줄이는 것**으로 읽은 게 과해석이었다. 서우의 뜻은 "조명(낮/밤)은 모드로만 바뀌게" 이고, 창문·조리에 따라 사진은 바뀌어야 한다.

| 요청 | 반영 |

| 거실 | 창문 열기/닫기 · 야간 모드 | 저녁(기본) / 저녁+창 / 밤 / 밤+창 | 저녁 네 식구 숨으로 CO₂ ↑ → ≈1,150~1,190 에서 정체, 모두 잠들면 ≈630 까지 ↓, 창 열면 바로 ↓. 사람 몸 VOCs ≈280 · 걸어 다니면 PM10 ≈31. 주방 연기가 조금 넘어온다 |

세 공간이 같은 시계를 쓴다(기본 ×5: 1초 = 5분, 조리·창 열림 중엔 0.3배, 버튼으로 ×1·×10·×20). 방마다 시간대별 사람 수가 다르다(`WHO` 시간표). 기록은 공간마다 5분에 하나, 아래 띠는 지금 공간, 숫자는 지금 공간 / 집 전체.

장면을 바로 열려면 해시: `#space=kitchen&cook=1` · `#space=bedroom&night=1` · `#space=living&window=1` (부스 QR·링크용).

## Vercel 배포 (정적 사이트, 빌드 없음)

```
cd measured-room
vercel --prod
```
- 첫 실행에서 프로젝트 이름은 `wellbian-measured-room`, 프레임워크는 Other, 빌드 명령·출력 디렉터리는 비워 둔다(루트의 index.html 을 그대로 서빙).
- **자산 파일을 따로 넣지 않아도 된다.** 사진 10장(≈1MB)과 영상 루프 10편(≈7MB, 보이는 것만 순서대로 받음)은 힉스필드 CDN(CORS `*`, 1년 캐시)에서 바로 불러온다. 데이터 절약 모드·모션 줄이기 설정에서는 영상 없이 사진만.
- 오래 쓸 배포(공식 공개·부스 오프라인)라면 `sh fetch-assets.sh` 로 `assets/` 에 받아 두면 그쪽을 먼저 쓴다(자세한 것은 `assets/README.md`).
- 외부 의존: Google Fonts 뿐(막히면 시스템 글꼴로 대체). 장면 사진·영상은 힉스필드 CDN(CORS `*`)에서 바로 불러오고, `sh fetch-assets.sh` 로 `assets/` 에 받아 두면 그쪽을 먼저 쓴다.

## 자산 좌표를 손보고 싶을 때

`index.html` 의 `SPACES` 에 공간마다 사진 안 비율 좌표가 있다: `device`(기기 발 중심 u,v 와 실측 척도 `cmFrac`), `SPRITE.screen`(컷아웃 안 화면 네 모서리 — 왼쪽 위부터 시계 방향, 자동 검출),
`pan`·`hood`(김이 나오는 곳과 빨려 들어가는 곳), `window`(바람 시작점), `focus`(모바일에서 장면을 어느 쪽 중심으로 자를지).
`SCENES` 에는 장면마다 광원이 있다: `kind: "beam"` 은 창(`at` 에서 `to` 방향 빛살), `"lamp"` 는 램프(`at` 둘레 `r`), `on` 은 세기, `col` 은 색.
사진을 새로 만들면 이 숫자만 맞추면 된다. 영상은 사진과 같은 구도여야 한다(첫 프레임 = 사진).
