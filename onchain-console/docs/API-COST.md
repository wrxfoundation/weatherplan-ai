# API 운영비 — 온체인 콘솔 · 커뮤니티 대시보드

라이브 전환 시 실제로 돈이 나가는 항목과, 무료로 끝나는 항목을 분리했습니다.
환율 1,350원/$ 기준, 월 단위입니다.

## 요약

| 구분 | 항목 | 월 비용 |
|---|---|---|
| **무료** | 텔레그램 Bot API · MTProto, XRPL 퍼블릭 노드, CARTO 지도 타일, GA4, 네이버 데이터랩, 구글 서치콘솔 | 0원 |
| **사용량 과금** | Claude API (AI 챗봇 + 주간 리포트 + 검색어 분류) | 약 1.0만 ~ 2.3만원 |
| **고정 구독** | Vercel / Supabase / Resend — 무료 티어로 시작 가능 | 0원 (성장 시 각 $20~25) |
| **유일한 큰 변수** | X(트위터) API 읽기 | $200/월~ (Basic) — **보류 권장** |

**결론: 지금 설계대로면 실질 운영비는 Claude API 사용량뿐이고, 월 2만원 안쪽입니다.**
X API만 유일하게 자릿수가 다르므로, 팔로워·노출은 당분간 수동 입력으로 두는 것을 권합니다.

## 1. 무료 API (비용 0원, 호출 한도만 존재)

| API | 용도 | 제한 |
|---|---|---|
| 텔레그램 Bot API | 구독자 수, 가입·이탈 이벤트, 유입원 분해, 대화방 메시지 | 초당 ~30콜. 5분 폴링이므로 여유 |
| 텔레그램 MTProto(TDLib) | 게시물 조회수, 채널 통계 | 무료. 운영자 계정 세션 필요 |
| XRPL 퍼블릭 클러스터 | 원장 조회(잔고·거래·홀더) | 무료. 부하 커지면 자체 노드(서버비만) |
| CARTO 지도 타일 | M4 노드 맵 배경 | 무료(어트리뷰션 표기 조건) — **이미 적용됨** |
| GA4 | 링크트리·랜딩 UTM 클릭 집계 | 무료 |

지도 타일은 **사용자 브라우저가 CARTO CDN에서 직접 받아오는 구조**라 우리 서버 트래픽·키·요금이 아예 발생하지 않습니다.

## 2. Claude API — 유일한 사용량 과금 (핵심)

### 모델 단가 (per 1M tokens)

| 모델 | 입력 | 출력 |
|---|---|---|
| Claude Opus 5 | $5 | $25 |
| Claude Sonnet 5 | $3 (~2026-08-31 프로모 $2) | $15 (프로모 $10) |
| Claude Haiku 4.5 | $1 | $5 |

### 절감 수단 (설계에 반영할 것)

1. **프롬프트 캐싱** — 고정 시스템 프롬프트(콘솔 지표 정의·산식·용어)를 캐시 블록으로 두면
   **캐시 읽기는 입력 단가의 약 1/10**. 쓰기는 1.25배(5분 TTL)/2배(1시간 TTL)이므로
   **2~3회 요청부터 무조건 이득**. 챗봇은 같은 프롬프트를 반복하므로 효과가 가장 큽니다.
   ※ 기존 `pages/api/claude.js`와 동일 원칙 — 캐시 블록에 날짜·프로필 등 **동적 값 인터폴레이션 금지**.
2. **배치 API** — 즉시 응답이 필요 없는 작업(검색어 분류, 주간 리포트 초안)은 **50% 할인**.
3. **모델 분리** — 분류·요약은 Haiku 4.5, 판단이 필요한 리포트만 Opus 5.

### 월 비용 추정 (보수적 가정)

| 작업 | 가정 | 모델 | 월 비용 |
|---|---|---|---|
| wellbian AI 챗봇 | 월 1,500턴 (담당자·내부 데모)<br>캐시 6,000 + 신규입력 500 + 출력 400 tok/턴 | Haiku 4.5 | 약 **$4.7** |
| " (품질 우선 시) | 동일 | Sonnet 5 | 약 **$14** |
| 주간 운영 리포트 | 주 1회 · 입력 15,000 / 출력 3,000 tok | Opus 5 | 약 **$0.7** |
| 검색어·문의 분류 | 월 3,000건 · 배치 50% 할인 적용 | Haiku 4.5 | 약 **$2.0** |
| **합계** | | | **$7.4 ~ $17 (약 1.0만~2.3만원)** |

> 캐싱을 쓰지 않으면 챗봇 비용만 3~4배로 뜁니다. 라이브 전환 시 첫 응답의
> `usage.cache_read_input_tokens`가 0이 아닌지 반드시 확인하세요.

## 3. X(트위터) API — 유일하게 비싼 항목

- 무료 티어는 **사실상 쓰기 전용**이라 팔로워·노출·참여 지표를 읽을 수 없습니다.
- 읽기가 필요하면 유료 티어(Basic $200/월 수준)로 올라가야 하고, 이는 나머지 전체 운영비보다 큽니다.
- **권장**: 초기에는 X 지표를 대시보드의 「데이터 연동 현황」에서 **수동**으로 표시(현재 설계 그대로).
  채널이 커져 X 유입이 의사결정을 좌우하는 단계가 되면 그때 유료 전환을 검토합니다.

현재 콘솔은 **정적 프론트엔드 + 데모 데이터**라 셋 다 아직 필요 없습니다.

## 5. 비용 관리 원칙

- Claude API 키는 서버(Edge Function/API Route)에만 두고 프론트에 노출하지 않습니다 — 키 유출은 곧 청구서입니다.
- 챗봇에 **일일 호출 상한**과 세션당 턴 제한을 걸어 비정상 사용 시 비용이 튀지 않게 합니다.
- 콘솔 사용자가 소수(운영 담당자)이므로 공개 노출이 없는 한 비용은 위 추정 범위를 벗어나지 않습니다.
  `/community` 등 전 페이지에 `noindex`가 걸려 있는 것도 이 목적에 부합합니다.
