# DECISIONS

## 2026-08-13 · react-router-dom 추가
- PRD §2 스택 목록 외 라이브러리. 9개 모듈 + 5개 설정 화면 라우팅에 표준 라우터가 필요해 추가.
- 대안(자체 해시 라우터)은 NavLink 활성 상태·중첩 라우트 재구현 비용이 더 큼.

## 2026-08-13 · 디자인 토큰을 라이트 테마로 교체
- PRD §9는 데모 HTML의 다크 토큰을 계승하나, 이후 전달된 확정 시안(대시보드·M1·M2·M3)이 라이트 테마.
- 시안이 최신 의사결정이므로 시안 팔레트로 토큰 재정의(navy #3E6FE0 · amber #E0A63E 등 브랜드 색은 유지).
- 서체는 Pretendard Variable 단일, 수치는 tabular-nums. 크기·굵기 위계는 tailwind.config.js fontSize 토큰으로 고정.

## 2026-08-13 · 사이드바 모듈 명칭
- PRD §5의 모듈명(M1 지표 대시보드 등)과 시안 사이드바 명칭(M1 활성 지갑, M3 결제/정산 등)이 상이.
- 확정 시안의 명칭·정보구조를 따름. 모듈 번호 체계는 동일하게 유지.
