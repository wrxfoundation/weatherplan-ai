## 2026-08-13 · M4~M8 시안의 사업 정합성 교정 (레이아웃 유지, 내용 교정)
시안 5장(M4~M8)의 레이아웃·그래픽은 그대로 구현하되, KWeather 사업 실체와 어긋나는
데모 내용은 다음과 같이 교정했다:
- **M4** 타사 DePIN 네트워크(IoTeX·Helium·Akash·Filecoin) → 자사 공기질 측정기 네트워크.
  보상 단위 KW → RLUSD. '네트워크별 분포' → '권역별 보상 분포'. 수치는 대시보드와 정합
  (활성 12,842 · 오늘 지급 8,214.3 · 지급률 98.6% · 부정 큐 15건).
  PRD §5.M4가 요구하는 1일 한도 게이지·지급지갑 잔고·자동중단 스위치 스트립과
  부정 탐지 큐 테이블(operator 액션: 부정 확정/해제)을 시안에 없더라도 추가.
- **M5** PRD의 M5(토크노믹스 시뮬레이터)와 달리 시안은 재무 현황 대시보드 — 시안을 따름
  (토크노믹스 시뮬레이터는 후속 배치 위치 결정 필요). 'DePIN 보상 수령(IoTeX)' 등 수익 항목
  → '데이터 상점 수취(RLUSD)' 등 자사 수익원으로 교체. 가상자산 = RLUSD·XRP·WLBN.
- **M6** 정산 방식 USDC/USDT → RLUSD(XRPL). 정산 ID·일자 연도 2025 → 2026.
  파트너명은 자사 생태계 데모 명칭(WeatherXM·D'CENT Pay 등)으로 교체.
- **M7** 내용 유지(채널·미디어·해시태그가 사업 문맥과 부합).
- **M8** 토큰 심볼 KWT → WLBN. WLBN은 XRPL 단일 발행이므로 '체인별 홀더 비중'
  (XRPL·Ethereum·BNB·Polygon·Base) → '지갑 유형별 홀더 구성'으로 대체.
  총 홀더 128,640 → 23,541, 집중도 Top10 32.6%·Top50 58.7%·지니 0.42로
  대시보드·M8 카드와 정합. 등급별 홀더 수 합계 = 총 홀더 수로 재계산.
- **공통** 시안 탑바의 '전체 체인' 셀렉트는 XRPL 단일 원장 사업과 상충 → 미적용.
  DEMO 배너 문구는 PRD §3 규정 문구 유지.

## 2026-08-13 · 라이브 없는 고도화 (B→C→D) + 도움말
- **도움말 시스템**: 전 메뉴 도움말 드로어(탑바 ?·페이지 제목 옆 ? 버튼). 내용은 비전문가 기준
  "이 화면은 무엇인가 / 지표 읽는 법 / 할 수 있는 일 / 함께 볼 화면" 구조.
- **B**: M3에 x402 결제 시연(4스텝 상태머신+터미널, busy 락·자동 스크롤·6초 내 — PRD DoD),
  M2에 조작 내성 계산기(슬라이더 실시간). 계산기 활성 지점 수는 M2 화면(128)과 정합
  (PRD 원안 987/1,000 게이지는 화면 시안 수치를 우선).
- **C**: /transparency(RLUSD 투명성 공개 시안 — 수취 지갑 플레이스홀더·누적 수취는 M5
  데이터 상점 YTD와 정합), /methodology(전 모듈 산식·VWI 파이프라인·데이터 출처).
  사이드바에는 넣지 않고 푸터·M2/M6·도움말에서 링크(운영 콘솔 IA 유지).
- **D**: M5 하단 WLBN 토크노믹스 시뮬레이터(PRD §5.M5 원안 산식, S₀=20M 가정치 라벨,
  시나리오 3개 localStorage 저장 — 라이브 전환 시 app_config로 이관),
  라이브 틱(업데이트 시간 실시간 카운트·상태 펄스), 모바일 대응(사이드바→상단 칩 내비).
