# 한국요괴지도 — 전략 및 W1 실행 결과

> yokai.jp/ko/yokai/map 구조를 한국형으로 이식할 수 있는가에 대한 답과, 그 답을 코드로 증명한 W1 산출물.
> 작성 2026-08-16 · 데이터 v0.1.0

---

## 0. 결론

**가능하다. 그리고 지도·데이터 축에서는 한국이 유리하다.** 다만 유리한 이유가 "요괴가 많아서"는 아니다.

- **유리한 것**: 좌표. 일본판의 지도 축은 47개 도도부현 단위지만, 한국은 시군구 229개 + 국가유산포털의 당집·장승·신당 실좌표 + 향토문화전자대전의 읍면동 단위 채록까지 내려간다. 게다가 이 리포에는 vworld 지오코딩 클라이언트와 지도 앱 골격이 이미 굴러가고 있다(`dcmap-web`).
- **불리한 것**: 도상. 일본판의 진짜 해자는 데이터가 아니라 **도리야마 세키엔 판화가 퍼블릭도메인이라 이미지 원가가 0원**이라는 점이다. 한국에는 1:1 대응 도감이 없다. 전량 신규 제작이며, 이것이 이 프로젝트의 최대 비용 항목이다.
- **다르게 이길 것**: 날씨. 케이웨더 실시간 관측을 전승 조건에 물리는 축은 일본판이 구조적으로 붙일 수 없다. 이번 W1에서 엔진까지 구현했다(§5).

이 문서 아래의 모든 수치는 실제로 빌드되는 코드 기준이다. `npm run build`가 검증에 실패하면 배포가 멈춘다.

## 4. 최대 난관 3개와 W1에서 취한 대응

### (1) 도상 전통 부재 — 가장 큰 비용

일본은 세키엔 판화가 공짜다. 한국은 없다. 대응:

- 스키마에 `art { status, direction, file, license }`를 두고 **아트디렉션 ID를 고정**(`minhwa-v1`)해 600장을 찍어도 화풍이 흔들리지 않게 했다.
- 상세페이지에 "한국에는 대응 도감 판화가 없어 신규 제작합니다"를 명시해, 없는 전통을 있는 척하지 않는다.
- 아트디렉션 v1 기준선(제안): **조선 민화 지본채색 + 한지 질감 + 무신도 색감**, 배경 여백 40% 이상, 정면 단독 구도, 채도 억제. 카테고리 색(`categories.json`)을 프롬프트 색 앵커로 재사용하면 도감 전체 톤이 자동으로 묶인다.
- 뿔 달린 도깨비 도상은 일본 오니의 영향을 받은 근대 학습물 산물이라는 지적을 데이터에 서술로 남겼다(`kr-dokkaebi`). **도상을 새로 만든다는 것은 이 오염을 되풀이하지 않을 기회이기도 하다.**

### (2) 표기 흔들림

같은 존재가 지역마다 도깨비/독각귀/도채비/김서방이 된다. 대응:

- `canonical` 1개 + `aliases[]` 흡수. `names.en/ja/zh/roman`은 별도 필드로 분리(다국어 SEO 대비).
- 검증기가 **alias 충돌을 오류로 잡는다**: 어떤 개체의 alias가 다른 개체의 canonical과 같으면 빌드 실패. 중복 등재가 데이터에 스며드는 경로를 원천 차단했다(`scripts/validate.mjs`).

### (3) 종교 민감성

무속·불교는 **지금도 믿는 사람이 있는 살아 있는 신앙**이다. 대응:

- `sensitivity { kind, note }` 필드. `living_faith`(실존 신앙) / `private_property`(사유지·실존 시설) / `tragedy_linked`(실제 사건 결부) / `ethnic_slur_risk`.
- 가택신·제주신격·마을신 계열은 전 항목 `living_faith` 표기. 상세페이지와 푸터에 "문화·엔터테인먼트 목적, 신앙을 권하거나 폄하할 의도 없음" 고지를 상시 노출.
- 현대 괴담 중 실존 도로·시설과 결부된 항목은 **개별 시설명을 싣지 않는다**(터널 괴담은 유형으로만 서술). 실제 사건·피해자를 연상시키는 서술을 금지 규칙으로 데이터에 박아 두었다.
- 실존 신당 좌표는 국가유산 지정정보가 있는 곳만 싣고, 방문을 권유하지 않는다.

### (+1) 이번에 추가로 세운 원칙 — 검증등급

일본판에 없는 축이다. 한국 요괴 서술의 상당수가 근현대 정리물에서 굳어졌고, 그 서술이 원전 기록인 것처럼 유통된다. 그래서:

- 5단계 `verification`(고전 원전 > 채록 기록 · 공공 백과 > 2차 정리물 > 현대·온라인) + `confidence`(high/medium/low).
- **근거가 약한 항목을 지우지 않는다. 등급을 낮춰 표시한다.** `confidence: low`(그슨대·각시도깨비·개도깨비·절굿공이·짚신 도깨비·마야고 등 6체)는 지도 기본 레이어에서 빠지고 "이설·미검증 포함"을 켜야 보인다.
- **출처가 0개인 레코드는 빌드가 실패한다.** 이것이 AI 답변엔진이 이 데이터셋을 인용할 수 있는 이유다.

## 5. 일본판이 붙일 수 없는 차별화

### 날씨 × 괴담 엔진 (구현 완료)

`src/engine/omen.js` — 결정론 전용, 난수 없음.

1. 케이웨더 관측(`/api/weather`) → 기온·습도·풍속·강수·하늘상태를 **전승 기상 조건 11종**(비/큰비/안개/눈/바람/폭풍/무더위/추위/습함/건조/맑음)으로 환산.
2. 시각을 5구간(새벽/낮/해질녘/밤/한밤중), 월을 4계절로 환산.
3. **괴담지수 0~100**을 산출하고, 점수의 근거(어떤 조건이 몇 점)를 항상 함께 반환해 화면에서 이유를 설명한다.
4. 지금 조건에 맞는 요괴를 랭킹. **전승에 기상 조건이 기록된 개체만 점수를 받는다** — 데이터에 없는 것을 날씨로 끌어올리지 않는다.

이 축이 실제로 작동하는 이유는 한국 전승에 **날씨에 이름이 붙은 항목이 실제로 있기 때문**이다:

- **손돌바람·손돌추위** — 억울하게 죽은 뱃사공, 음력 시월 스무날께의 강풍·한파. 날짜가 붙은 기상 현상.
- **영등할망** — 음력 2월 초하루~보름의 영등철 강풍. 유네스코 인류무형문화유산(제주칠머리당영등굿)과 좌표가 붙는다.
- **강철이** — 지나간 자리가 마르는 가뭄의 용. "강철이 간 데는 가을도 봄".
- **청개구리** — 비 오면 우는 이유. **여우비** — 해 난 채 내리는 비. **도깨비바람** — 회오리.

케이웨더 API가 미연동이어도 시각·계절만으로 계산하고 **그 사실을 화면에 밝힌다**(가짜 수치를 만들지 않는다).

### 제주 본풀이 단독 섹션 (12체 확보)

설문대할망·영등할망·자청비·백주또·소천국·궤네깃또·감은장아기·강림도령·삼승할망·구삼승할망·원천강 오늘이·천지왕. 창세부터 저승까지 서사시 체계를 갖춘 자산은 세계적으로도 희소하고, 인바운드 관광과 직결된다. 궤네깃또(버려진 아이의 귀환 영웅담)는 IP 소싱 1순위로 표시해 두었다.

### 지자체 B2B / 인바운드 다국어

`sites[]`가 시군구 코드까지 내려가므로 스탬프 투어·둘레길 콘텐츠 납품 단위로 그대로 잘린다. `names.en/ja/zh`는 스키마에 이미 있고 W3에서 서브디렉터리 라우팅만 붙이면 된다.

## 6. AEO(답변엔진 최적화) — Chronicle 전략과의 정렬

`npm run build` 1회로 생성되는 것:

- **프리렌더 154페이지** — 요괴 120 + 분류 14 + 지역 17 + 도감/소개/진단 3. 각 페이지에 라우트별 title·description·canonical·JSON-LD + **noscript 본문**(JS 없이도 크롤러가 전문을 읽는다).
- **JSON-LD** — 개체는 `DefinedTerm`(+ 전승지 `Place`, 출처 `citation`), 분류는 `DefinedTermSet`, 지역은 `CollectionPage`, 데이터셋은 `Dataset`(license: CC BY 4.0).
- **sitemap.xml · robots.txt** — GPTBot·ClaudeBot·Claude-SearchBot·PerplexityBot·Google-Extended 명시 허용. 인용되려고 공개하는 데이터에 크롤러를 막을 이유가 없다.
- **llms.txt** — "왜 인용할 수 있는가"를 먼저 밝히는 구조(koreaapi 방식). 출처 강제, 검증등급, 좌표 정밀도, 현대괴이 분리 원칙을 명시하고 인용 표기 예시까지 제공.
- **오픈데이터셋** — `/data/yokai.json`(가독본) · `/data/yokai.min.json`(압축본). id는 안정 식별자로 변경하지 않는다.

빌드 안전장치: 프리렌더 치환이 조용히 실패하면(예: index.html 메타가 여러 줄로 바뀌면) **빌드를 중단**한다. 전 페이지가 같은 설명을 갖는 채로 배포되면 SEO/AEO가 통째로 무의미해지기 때문이다.

## 8. 수익 구조

상세 모델·단가 가정·시나리오·KPI는 **[MONETIZATION.md](./MONETIZATION.md)**에 따로 정리했다. 요지만 옮기면:

```
AdSense (프리렌더 156페이지 → W2에 560+ 롱테일)   ← 수익원이 아니라 트래픽 계측기
  → 진단 바이럴로 재유입 루프
    → 지자체·공공 콘텐츠 납품 (주력)
      → 데이터 라이선스/API 이중 트랙 (공개 CC BY / 상업 구독)
        → 웹툰·게임 IP 원안 자문 (제주 본풀이 12건)
```

**광고는 기본 시나리오에서 전체 매출의 6%다.** 일본판은 순수 광고 모델이지만 한국에서 같은 모델을 그대로 돌리면 월 20~30만 원짜리 사업이 된다. 한국의 진짜 트랙은 **지자체 문화 예산**이고, 거기서는 "재미있는 콘텐츠"가 아니라 근거가 붙은 데이터만 통과한다. §4의 출처·검증등급·좌표 정밀도를 데이터 구조에 박아 넣은 것은 감성이 아니라 **조달 요건 대응**이다.

그래서 광고는 S3(레퍼런스 계약 확보 이후)까지 미룬다. 레퍼런스 계약 전에 월 20만 원을 벌자고 3,000만 원 트랙의 신뢰도를 깎지 않는다.

## 9. 도메인 후보

코드는 `VITE_SITE_ORIGIN` 환경변수 하나로 전 페이지의 canonical·sitemap·llms.txt·JSON-LD 절대 URL이 바뀌도록 만들어 두었다. 기본값은 `https://yokaimap.kr`이며, 아래 중 무엇을 고르든 환경변수만 바꾸면 된다.

|---|---|---|
| `yokaimap.kr` | 직관·검색 친화 | 현재 기본값. "요괴 지도" 검색 의도와 정확히 일치 |
