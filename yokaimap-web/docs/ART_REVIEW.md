# 도상 검수 체크리스트 (minhwa-v2)

> 왜색·중국풍은 이 프로젝트에서 **품질 문제가 아니라 존폐 리스크**다.
> 생성된 도상은 전부 이 체크리스트를 통과해야 하며, 통과 전에는 `art.status`를 `final`로 올리지 않는다.
> 한 장이라도 걸린 채 배포되면 그 한 장이 프로젝트 전체의 신뢰를 깎는다.

## 0. 검수 순서

1. **배제 항목 먼저 본다.** 좋아 보이는 그림이라도 §2·§3에 하나 걸리면 즉시 폐기·재생성한다.
2. 그다음 §1(한국성 앵커)이 실제로 보이는지 확인한다. "없지 않다"가 아니라 "보인다"여야 한다.
3. §4(기법·질감), §5(윤리)까지 통과하면 `art.status: drafted → final`.
4. 지역 신앙·특정 지역 소재(제주 본풀이, 마을신 등)는 가능하면 **지역 감수자 확인**을 한 단계 더 둔다.

---

## 1. 한국성 앵커 — 하나 이상 명확히 보여야 통과

- [ ] **복식**: 저고리 깃에 **동정(흰 깃)** 이 있는가. **옷고름**이 매여 있는가.
- [ ] 여성은 치마말기가 **가슴 위**에 있는가(허리 벨트가 아니다).
- [ ] 남성은 **갓·망건·상투**, 발목을 묶은 **바지**, 짚신/미투리인가.
- [ ] **건축**: 지붕 용마루가 완만한가, 창호가 **한지 격자문**인가, 온돌방 구조인가.
- [ ] **경물**: 적송(소나무)·모란·까치·화강암 능선·서낭당 돌무더기·오색천·장승·솟대 중 하나 이상.
- [ ] **기물**: 달항아리·놋그릇·소반·금줄·장독대 중 하나 이상(해당 컷에 한해).

## 2. 왜색 배제 — 하나라도 있으면 폐기

- [ ] **뿔 2개 + 호피 무늬 하의** → 일본 오니. **도깨비에 절대 금지.**
      (근대 학습물이 오니 도상을 들여와 한국 도깨비 이미지를 오염시킨 전례가 있다. 우리가 되풀이하지 않는다.)
- [ ] **가나보(금속 못 박힌 철퇴)** → 도깨비방망이는 **옹이 있는 나무 방망이**다.
- [ ] **오비**(허리에 두른 넓은 띠), 기모노·유카타 깃 여밈, 게타·다비.
- [ ] **도리이(붉은 문)**, 시메나와(금줄에 종이 시데), 일본식 석등롱.
- [ ] **장지문(쇼지)·다다미**.
- [ ] 지붕 처마 끝이 **크게 위로 솟은 곡선**(당파풍).
- [ ] **벚꽃** 모티프. → 소나무·모란·매화로 대체.
- [ ] 우키요에식 **굵은 검정 윤곽 + 인쇄 평면색**.
- [ ] 사무라이 상투(촌마게), 일본도.

## 3. 중국풍 배제 — 하나라도 있으면 폐기

- [ ] **오조룡(발톱 5개)** → 조선의 용은 통상 **사조(四爪)** 로 그렸다.
- [ ] **치파오**, 교령우임의 넓은 소매 한푸 + 허리 요대, 변발.
- [ ] **붉은 원통형 홍등롱**, 중국결(매듭 술).
- [ ] **년화(年畵)식 고채도 원색 + 금박** 남발.
- [ ] 태호석·중국식 정원 요소, 경극 분장, 중국 사찰 석사자.

## 4. 재료·기법

- [ ] 바탕이 **한지 결**로 보이는가(매끈한 디지털 면이 아니라).
- [ ] 색이 **아교 갠 석채의 무광**인가 — 광택·금박·네온이 아니다.
- [ ] 윤곽선이 **굵기가 고른 철선묘**인가(붓압 과장·스케치선 아님).
- [ ] 팔레트가 오방색 계열의 채도 억제 톤인가(`data/art/direction.json`의 `pigments`).
- [ ] 여백이 충분한가(도감 판 구도).

## 5. 윤리·표기

- [ ] **특정 실존 작가의 화풍을 모사하지 않았는가.**
- [ ] 실존 신앙 대상(무속·불교 신격)을 조롱하거나 희화화하지 않았는가.
- [ ] 현대 괴이 항목이 실제 사건·피해자·특정 시설을 연상시키지 않는가.
- [ ] 화면에 글자·서명·낙관·워터마크가 없는가.
- [ ] 상세페이지 캡션에 **AI 생성 도상**임이 표시되는가(`ArtPlate`가 자동 표기).

## 자주 나오는 실패와 처방

| 증상 | 원인 | 처방 |
|---|---|---|
| 인물이 기모노처럼 보임 | 앵커에 복식이 안 들어감 | `category_anchors`에 `costume_female/male` 추가 |
| 용이 중국 황실 용 | 발톱·수염 형태 | `art_hint`에 "four-clawed", 배제문에 "no five-clawed imperial dragon" |
| 도깨비에 뿔이 남 | `art_hint` 자체에 뿔 서술 | `art_hint`에서 뿔 제거 + "hornless" 명시 |
| 색이 형광·금박 | 팔레트 미적용 | 생성 요청에 `colors`/`background_color` 파라미터 전달 확인 |
| 배경이 일본식 신사 | 경물 앵커 부재 | `landscape` 앵커(서낭당·장승·솟대) 추가 |
| 여성 개체에 갓·바지 | 분류 앵커가 개체와 어긋남 | 개체에 `art_anchors` 지정(분류 기본값을 이긴다) |
| 불꽃·그림자 컷에 사람이 낌 | 앵커·수식어가 인물을 단정 | `art_anchors`에서 복식 제거 + `art_hint`에 "no figure" |

## 생성 운영 메모

- **실패는 대부분 내용 문제가 아니다.** 12건 동시 제출은 공급자 rate limit(429)에 걸려
  절반이 실패한다. **6건 단위로 제출한다.** 같은 프롬프트가 재시도에서 그대로 성공하면
  프롬프트를 고치지 말고 배치 크기를 줄일 것.
- **NSFW 오탐**이 있다. "stone mother goddess"(성모천왕), "bathing"(선녀)이 걸렸다.
  도감 도판이므로 서사를 잃지 않는 선에서 표현을 바꾼다 —
  "carved granite statue of an elderly goddess in Korean robes",
  "standing fully dressed at the edge of a mountain pool".
  인물 컷에는 `fully clothed`, 유혈 소재에는 `no gore and no blood`를 미리 넣어 둔다.
- 생성 결과 URL은 만료될 수 있다. 리포 반입은 `node scripts/fetch-art.mjs`로,
  CDN 접근이 되는 환경에서 되도록 빨리 실행한다.

## 통과 기록

검수 결과는 `data/art/jobs.json`의 각 항목에 남긴다.

```jsonc
{ "id": "kr-dokkaebi", "review": { "by": "검수자", "date": "2026-08-16", "result": "pass" } }
```

`result: reject`이면 `reason`에 걸린 체크 항목 번호를 적고 재생성한다.

빌드는 이 기록에서 `art.status`를 계산한다(`scripts/build-data.mjs`).
시드의 `art.status`를 손으로 올려도 무시된다 — 매니페스트에 없는 그림을
있다고 주장하는 레코드가 배포되는 경로를 막기 위해서다.

| 매니페스트 상태 | `art.status` | `art.file` | 화면 |
|---|---|---|---|
| `review.result: pass` | `final` | `/img/yokai/…png` | 도판 |
| 생성됨, 검수 전 | `generated` | `null` | 인장 폴백 |
| 없음 | `pending` | `null` | 인장 폴백 |
