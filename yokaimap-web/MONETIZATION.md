# 한국요괴지도 — 수익화 모델

> 작성 2026-08-16 · 데이터 v0.1.0 기준
> 이 문서의 모든 단가는 **검증 전 가정**이다. 근거와 검증 방법을 각 항목에 함께 적었다. 실측으로 바뀌면 버전을 올린다.

---

## 0. 한 줄 결론

**광고는 수익원이 아니라 트래픽 계측기다. 돈은 B2B에서 나온다. 그리고 B2B를 여는 열쇠는 콘텐츠 양이 아니라 출처·검증등급·좌표 정밀도다.**

일본판(yokai.jp)은 AdSense + 다국어 SEO의 순수 광고 모델이다. 한국에서 같은 모델을 그대로 돌리면 **월 20~30만 원짜리 사업**이 된다(§2 계산). 한국 시장의 진짜 트랙은 지자체 문화 예산과 공공 조달인데, 거기서는 "재미있는 콘텐츠"가 아니라 **근거가 붙은 데이터**만 통과한다. W1에서 출처 강제·검증등급·좌표 정밀도를 데이터 구조에 박아 넣은 것은 감성이 아니라 **조달 요건 대응**이다.

## 1. 수익 라인 5개

| # | 라인 | 성격 | 리드타임 | 단가 가정 | 확장성 |
|---|---|---|---|---|---|
| A | AdSense (롱테일 SEO) | 자동·소액 | 3~6개월 | RPM ₩1,000~3,000 | 트래픽 비례 |
| B | **지자체·공공 콘텐츠 납품** | 영업·고액 | 6~12개월 | 건당 ₩2,000만~5,000만 | 지역 수만큼 반복 |
| C | 데이터 라이선스 / API | 구독 | 9~18개월 | 연 ₩300만~1,200만 | 높음 |
| D | IP 소싱 (웹툰·게임) | 옵션 계약 | 12~24개월 | 옵션 ₩500만~2,000만 | 건별 |
| E | 굿즈·제휴·관광 연계 | 부수 | 6~12개월 | 마진율 20~35% | 낮음 |

### A. AdSense — 미끼이자 계측기

- **무엇이 팔리나**: 요괴 이름 검색(정보 탐색) → 상세페이지 체류 → 디스플레이 광고 임프레션.
- **전제**: W2에서 300체 + 시군구 페이지까지 확장하면 색인 대상 **약 560페이지**. 프리렌더·JSON-LD·llms.txt는 이미 완료(W1).
- **단가 가정 근거**: 한국어 문화/교양 카테고리 디스플레이 RPM은 통상 금융·부동산보다 크게 낮다. ₩1,500을 기본값으로 잡되 **실측 전까지 매출 계획에 넣지 않는다**.
- **검증 방법**: 게재 후 30일 실측 RPM. GSC 노출·CTR로 페이지당 유입 분포 확인.
- **주의**: 상세페이지에 광고를 과하게 넣으면 조달·기관 협업에서 신뢰도가 깎인다. **광고 슬롯은 도감/지역 목록과 진단 결과에만 두고, 개별 요괴 상세 본문 상단에는 넣지 않는다**(코드에도 그렇게 배치했다).

### B. 지자체·공공 콘텐츠 납품 — 주력

이것이 일본판이 못 하는 트랙이다.

- **무엇이 팔리나**
  1. **권역 요괴 콘텐츠 팩** — 시군구 단위 전승 정리 + 좌표 + 도상 + 안내판/리플릿 원고. 지역문화진흥·관광자원화 사업에 붙는다.
  2. **스탬프 투어 / 둘레길 연계** — `sites[]`가 시군구·읍면동까지 내려가므로 코스 설계가 그대로 나온다.
  3. **축제·전시 콘텐츠** — 제주 본풀이, 밀양 아랑, 삼척 해신당처럼 이미 지역 축제가 있는 곳부터.
  4. **디지털 아카이브 구축 용역** — 스키마·검증 파이프라인 자체를 납품.
- **왜 우리가 되나**: 조달 심사에서 항상 나오는 질문이 "이 서술의 근거가 무엇인가"다. 우리는 레코드마다 `sources[]`·`verification`·`confidence`·좌표 `precision`을 제시할 수 있고, **출처 없는 레코드는 빌드가 실패한다는 사실 자체를 근거로 제출할 수 있다.**
- **단가 가정 근거**: 지역 콘텐츠 개발 용역의 통상 규모대. 소규모 리플릿·안내 콘텐츠는 하단, 아카이브 구축은 상단.
- **검증 방법**: 나라장터·지자체 공고 3개월 모니터링으로 실제 발주 규모와 빈도를 확인한다. **이 검증이 이 문서에서 가장 먼저 해야 할 일이다.**
- **선행 조건**: 도상(§4 비용) + 실좌표 교체(국가유산포털) + 레퍼런스 1건. 레퍼런스가 없으면 첫 계약이 가장 어렵다 → **첫 건은 마진을 포기하고 레퍼런스를 산다.**

### C. 데이터 라이선스 / API — 이중 라이선스

**"CC BY로 다 공개하면서 어떻게 파는가"에 대한 답이 이 라인의 전부다.**

| | 공개 트랙 (CC BY 4.0) | 상업 트랙 (유료) |
|---|---|---|
| 대상 | 개인·연구·AI 답변엔진 인용 | 상업 서비스·앱·게임·미디어 |
| 제공 | `/data/yokai.json` 스냅샷 | API + 증분 업데이트 + SLA |
| 의무 | **출처 표기 필수** | 표기 면제(화이트라벨) 가능 |
| 가격 | 무료 | 연 구독 |

- 파는 것은 데이터 자체가 아니라 **최신성·정합성·좌표 정밀도·납품 포맷·유지보수·표기 면제**다. 스냅샷은 공짜여도 "매주 갱신되고 스키마가 깨지지 않는 것"은 공짜가 아니다.
- CC BY의 출처 표기 의무는 비용이 아니라 **유통 채널**이다. AI 답변엔진이 인용할 때마다 브랜드가 따라 나간다(llms.txt에 인용 표기 예시를 박아 둔 이유).
- KoreaAPI 라인에 `get_yokai(region|category|id)` / `get_omen_today(lat,lng)` 툴로 얹으면 별도 인프라 없이 확장된다.
- **검증 방법**: 공개 데이터셋의 외부 참조(백링크·AI 인용) 수를 6개월 추적. 참조가 안 붙으면 상업 트랙도 안 팔린다.

### D. IP 소싱 — 옵션 계약

- 제주 본풀이 12건은 **완결된 서사 구조**를 이미 갖고 있다. 특히 궤네깃또(버려진 아이의 귀환 영웅담), 자청비(남장 여성 영웅), 감은장아기("내 팔자는 내가 만든다"), 강림도령(저승 출장 수사).
- 판매 형태: 원안 사용 옵션 + 자문. **저작권을 파는 게 아니다**(전승은 공유재다). 파는 것은 **정리·고증·자문**이다. 이 구분을 계약서에 명확히 해야 분쟁이 없다.
- **검증 방법**: 웹툰·게임 스튜디오 3곳에 자료집 형태로 콜드 아웃리치 후 반응.

### E. 굿즈·제휴 — 후순위

도상 완성 이후에만 성립한다. 지자체 납품의 부속물(스탬프북·엽서)로 붙이면 별도 영업 없이 소화된다. **단독 라인으로 추진하지 않는다.**

## 2. 퍼널과 3 시나리오

### 퍼널

```
검색(요괴 이름·지역명) ─┐
AI 답변 인용 ──────────┼→ 상세페이지 ─→ 진단(체질진단) ─→ 공유 ─→ 재유입
지도/오늘의 괴담지수 ──┘        │
                                 └→ 지역 페이지 ─→ [B2B 리드 폼] ─→ 지자체·기업 문의
```

- 진단은 **광고 임프레션을 늘리는 장치이자 재유입 루프**다. 결과 URL이 답변을 그대로 담고 있어(`/quiz?a=01230123`) 서버 상태 없이 공유된다.
- B2B 리드는 **지역 페이지에서 잡는다.** 담당 공무원·기관이 자기 지역 이름으로 검색해 들어오는 경로가 가장 굵다.

### 12개월 시나리오 (월 기준, 12개월차)

| | 보수 | 기본 | 상승 |
|---|---|---|---|
| 색인 페이지 | 300 | 560 | 900 |
| 월 PV | 30,000 | 150,000 | 400,000 |
| A. 광고(RPM ₩1,500) | ₩45,000 | ₩225,000 | ₩600,000 |
| B. 지자체 납품 | 0건 | 1건 (₩3,000만/년) | 3건 (₩1억/년) |
| C. 데이터 라이선스 | 0 | 1건 (₩600만/년) | 3건 (₩2,000만/년) |
| D. IP 옵션 | 0 | 0 | 1건 (₩1,000만) |
| **연 환산 합계** | **약 ₩54만** | **약 ₩4,000만** | **약 ₩1억 4,000만** |

**읽는 법**: 광고는 세 시나리오 어디서도 의미 있는 비중이 아니다. 기본 시나리오에서 광고는 전체의 **6%**다. 사업의 성패는 **B 1건이 되느냐 마느냐**에 달려 있다. 따라서 리소스 배분도 그렇게 가야 한다.

## 3. 우선순위 시퀀싱 — 왜 광고가 먼저가 아닌가

| 단계 | 기간 | 할 일 | 이 단계의 유일한 성공 기준 |
|---|---|---|---|
| S1 | 지금~1개월 | **나라장터·지자체 공고 모니터링**으로 B 라인 단가·빈도 실측. 도상 아트디렉션 v1 확정 | 실제 발주 사례 5건 수집 |
| S2 | 1~3개월 | 도상 120장 + 국가유산포털 실좌표 교체 + 시드 300 확장 | 납품 가능한 완성도 |
| S3 | 3~4개월 | **레퍼런스 1건 확보**(마진 포기 가능) + AdSense 게재로 RPM 실측 | 계약서 1장 |
| S4 | 4~8개월 | 레퍼런스 기반 확산 영업 + 데이터 라이선스 상업 트랙 개설 | B 2건 / C 1건 |
| S5 | 8~12개월 | 다국어(인바운드) + IP 아웃리치 | 신규 채널 검증 |

광고를 S3까지 미루는 이유: **광고를 붙인 사이트는 기관 협업 미팅에서 신뢰도가 깎인다.** 레퍼런스 계약 전에 수익 ₩20만을 벌자고 ₩3,000만 트랙을 위험에 빠뜨리지 않는다.

## 4. 비용 구조

| 항목 | 규모 | 성격 |
|---|---|---|
| **도상 제작 120~600장** | 최대 항목 | AI 생성 + 아트디렉션 감수. 세키엔 판화가 공짜인 일본판과의 격차가 여기서 발생 |
| 데이터 확장·검증 | 지속 | 채록 원자료 대조. 검증등급을 올리는 작업이 곧 자산 가치 상승 |
| 인프라 | 소액 | Vercel + 정적 JSON. 서버 DB 없음 |
| 좌표 정밀화 | 중간 | 국가유산포털 지정정보 매칭(자동화 가능) |

**도상은 비용이지만 동시에 방어선이다.** 데이터는 CC BY로 복제 가능하지만, 통일된 아트디렉션으로 그려진 600장은 복제되지 않는다. 그래서 데이터는 열고 도상은 닫는다(도상 라이선스는 별도).

## 5. KPI 트리

```
북극성: 유료 계약 건수 (B+C+D)
├─ 선행지표 1: 지역 페이지 → 리드 폼 전환율        ← B2B 파이프라인
├─ 선행지표 2: 공개 데이터셋 외부 인용/백링크 수    ← C 라인 성립 여부
├─ 선행지표 3: 검증등급 primary_text·field_record 비율 ← 조달 통과력
├─ 선행지표 4: 실좌표(parcel/dong) 비율             ← 납품 완성도
└─ 보조지표: 월 PV, 진단 완료율, 공유율, AdSense RPM
```

현재값(v0.1.0): 실좌표 비율 = `precision`이 parcel/dong인 전승지 비중, 고신뢰 등급 비율 = primary_text 13 + field_record 37 = **50/120 (42%)**. 이 두 숫자를 W2 목표에 넣는다 — 실좌표 60%, 고신뢰 60%.

| 광고 의존 유혹 | 중간 | 광고 슬롯을 상세 본문 상단에 두지 않는다는 원칙을 코드에 고정 |

## 7. 코드에 반영된 것

이 문서의 결론은 문서로만 두지 않고 제품 표면에 반영했다.

- `src/business/BusinessPage.jsx` — B2B 랜딩(지자체 납품·데이터 라이선스·IP 소싱) + 리드 폼
- `api/lead.js` — 리드 수집. 저장소 미설정 시 접수 실패를 숨기지 않고 이메일 폴백을 안내한다
- `src/ui/AdSlot.jsx` — 광고 슬롯. `VITE_ADSENSE_CLIENT` 미설정이면 **아무것도 렌더하지 않는다**. 상세 본문 상단에는 배치하지 않는다
- 지역 페이지 하단에 B2B 진입 배너 — 담당자 유입 경로에 맞춘 배치
- `/about`의 데이터 이용 안내에 이중 라이선스(공개/상업) 명시
