# 히어로 배경 이미지

`/service` 랜딩 히어로 뒤에 깔리는 배경입니다.

## 파일을 넣는 방법

**파일을 넣고 다시 빌드하면 끝입니다.** 스위치를 만질 필요가 없습니다.

```
kcare-app/public/hero/home.webp
```

`pages/service.jsx` 의 `getStaticProps` 가 빌드할 때 이 파일이 있는지 확인해서
배경을 켜고 끕니다. Vercel 은 배포할 때마다 빌드하므로, 파일을 커밋해서
올리면 자동으로 적용됩니다.

파일이 없으면 배경 없이 지금의 깔끔한 모습 그대로 나오고, CSS 가 이미지를
아예 요청하지 않으므로 콘솔에 404 도 남지 않습니다.

## 규격

| 항목 | 값 |
|---|---|
| 비율 | 16:9 |
| 권장 크기 | 2688 × 1520 (원본) → 1920 × 1086 으로 줄여서 사용 |
| 형식 | WebP 우선, PNG 도 가능 (이름은 `home.webp` 유지) |
| 용량 | **250KB 이하** — 히어로가 이미지를 기다리면 첫인상이 늦어집니다 |
| 구도 | **왼쪽 절반은 비어 있어야 합니다** — 그 위에 제목이 올라갑니다 |

## 이미 적용된 안전장치

- 왼쪽에서 오른쪽으로 페이퍼색(#F1EFE8) 그라데이션을 덮어 글자 가독성을 지킵니다
- 모바일에서는 더 강하게 덮습니다 (좁은 화면에서는 글자가 이미지 위로 겹치므로)
- `prefers-reduced-motion` 과 무관 — 정적 이미지라 모션 이슈 없음
- CSP: `img-src 'self'` 이므로 이 폴더(자기 출처)의 파일만 뜹니다. 외부 CDN 주소는 차단됩니다
