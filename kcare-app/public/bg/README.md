# 남색 섹션 배경 (질감 텍스처)

`/service` 랜딩에서 **남색 섹션**(`Section tone="navy"`) 뒤에 깔리는 결입니다.
지금은 "저희가 하지 않는 것" 과 마무리 CTA, 두 곳에 들어갑니다.

히어로 배경은 여기가 아니라 `public/hero/` 입니다.

| 파일 | 크기 | 상태 |
|---|---|---|
| `marble.webp` | 23KB | **사용 중** — 대리석 결 |
| `leather.webp` | 65KB | 대안 — 가죽 그레인 |

둘 다 640px 흑백 타일이고 상하좌우가 이음매 없이 이어집니다.

## 바꾸는 방법

`styles/globals.css` 의 `.sec-navy::before` 에서 두 줄만 바꾸면 됩니다.
**결 굵기가 달라서 `background-size` 도 같이 바꿔야 합니다.**

| | `background-image` | `background-size` | `opacity` |
|---|---|---|---|
| 대리석 (지금) | `url("/bg/marble.webp")` | `640px 640px` | `.21` |
| 가죽 그레인 | `url("/bg/leather.webp")` | `320px 320px` | `.38` |

대리석을 320px 로 줄이면 맥이 잔금처럼 보이고, 가죽을 640px 로 키우면
알갱이가 얼룩처럼 보입니다. 짝을 지어 바꾸세요.

## 왜 영상이 아니라 텍스처인가

한때 이 자리에 배경 영상을 깔았다가 뺐습니다. 한 페이지에 영상이 셋이면
과부하입니다 — 디코딩이 계속 돌고 파일도 400KB 씩 붙습니다.
지금은 이 페이지의 `<video>` 는 히어로 하나뿐입니다.

## 왜 규칙적인 패턴이 아닌가

처음에는 CSS 만으로 점 격자를 그렸는데, **규칙적인 격자**라 반투명 카드
밑으로 비칠 때 줄이 어긋난 것처럼 보였습니다. 불규칙한 결은 카드 밑으로
비쳐도 "돌(가죽) 위에 반투명 판을 올린" 것으로 읽혀서 그 문제가 없습니다.

## 남색 톤을 유지하는 방법

텍스처는 **흑백**입니다. 남색 바탕에 `mix-blend-mode: soft-light` 로 얹으면
남색의 **명도만** 오르내리고 색상은 남색 그대로 남습니다.

## 다시 만드는 방법

```sh
pip install numpy pillow
python3 scripts/gen-marble.py      # kcare-app 디렉터리에서
python3 scripts/gen-leather.py
```

시드가 고정돼 있어 **몇 번을 돌려도 같은 파일**이 나옵니다.

원리는 각 스크립트 주석에 있습니다. 공통으로 **이음매가 없어야** 합니다 —
`background-repeat` 로 까는데 가장자리가 안 맞으면 화면에 격자 줄이 보입니다.
그래서 노이즈는 FFT 로 만들고(주기성이 수학적으로 보장됨), 셀룰러 노이즈는
거리 계산을 토러스로 감싸고, 마지막 블러도 가장자리를 감아서 겁니다.
두 스크립트 모두 끝에서 가장자리 차이를 내부 인접 화소 차이와 비교해
검증합니다 — **가장자리 ≈ 내부**여야 통과입니다.

대리석에서 특히 조심할 값 (자세한 것은 `scripts/gen-marble.py` 주석):

- 왜곡 노이즈의 `beta` — 낮으면 맥이 서리처럼 부슬부슬해지고, 높으면
  등고선처럼 나란해진다. **4.2~4.6** 이 흐르는 구간
- 왜곡 진폭 `amp` — 크면 띠가 부서져 화강암 얼룩이 된다. **3~4 라디안**

## 대비 실측

글자가 실제로 찍히는 자리만 측정한 최악값입니다 (대리석 기준).

| | 최저 대비 | 판정 |
|---|---|---|
| 데스크톱 1280 · 경계 섹션 | 5.91:1 | AA 이상 |
| 데스크톱 1280 · 마무리 | 7.68:1 | AAA |
| 모바일 390 · 경계 섹션 | 6.37:1 | AA 이상 |
| 모바일 390 · 마무리 | 7.65:1 | AAA |

`opacity` 를 올리거나 `background-size` 를 키우면 이 값이 내려갑니다.
만질 때 다시 재세요 (기준은 작은 글자 4.5:1 · 큰 글자 3.0:1).
