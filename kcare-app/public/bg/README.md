# 남색 섹션 배경 (가죽 그레인 텍스처)

`/service` 랜딩에서 **남색 섹션**(`Section tone="navy"`) 뒤에 깔리는 결입니다.
지금은 "저희가 하지 않는 것" 과 마무리 CTA, 두 곳에 들어갑니다.

히어로 배경은 여기가 아니라 `public/hero/` 입니다.

| 파일 | 크기 | 역할 |
|---|---|---|
| `leather.webp` | 65KB | 가죽 그레인 타일 (640px · 흑백 · 이음매 없음) |

## 왜 영상이 아니라 텍스처인가

한때 이 자리에 배경 영상을 깔았다가 뺐습니다. 한 페이지에 영상이 셋이면
과부하입니다 — 디코딩이 계속 돌고 파일도 400KB 씩 붙습니다.
지금은 이 페이지의 `<video>` 는 히어로 하나뿐입니다.

## 왜 점 격자가 아니라 가죽 그레인인가

처음에는 CSS 만으로 점 격자를 그렸는데, **규칙적인 격자**라 반투명 카드
밑으로 비칠 때 줄이 어긋난 것처럼 보였습니다. 불규칙한 결은 카드 밑으로
비쳐도 "가죽 위에 반투명 판을 올린" 것으로 읽혀서 그 문제가 없습니다.

## 남색 톤을 유지하는 방법

텍스처는 **흑백**입니다. 남색 바탕에 `mix-blend-mode: soft-light` 로 얹으면
남색의 **명도만** 오르내리고 색상은 남색 그대로 남습니다.

세부 값은 `styles/globals.css` 의 `.sec-navy` 에 있습니다:

| 값 | 지금 | 뜻 |
|---|---|---|
| `background-size` | `320px` | 640px 타일을 절반으로 → 고밀도 화면에서 2배 밀도로 찍혀 결이 안 뭉갠다. **키우면 결이 굵어진다** |
| `opacity` | `.38` | 결의 세기 |
| `mix-blend-mode` | `soft-light` | 남색을 지키는 핵심 |

## 다시 만드는 방법

```sh
pip install numpy pillow
python3 scripts/gen-leather.py     # kcare-app 디렉터리에서
```

시드가 고정돼 있어 **몇 번을 돌려도 같은 파일**이 나옵니다.

만드는 원리는 `scripts/gen-leather.py` 주석에 있습니다. 요약하면:

- 셀룰러(Worley) 노이즈 네 겹으로 가죽 셀을 만들고, 프랙탈 노이즈로 모공을 얹는다
- **이음매가 없어야 한다** — `background-repeat` 로 까는데 가장자리가 안 맞으면
  화면에 격자 줄이 보인다. 그래서 셀룰러는 거리 계산을 토러스로 감싸고,
  프랙탈은 FFT 로 만든다 (작은 난수 격자를 확대 보간하면 이음매가 남는다)
- 스크립트가 끝에서 가장자리 차이를 내부 인접 화소 차이와 비교해 검증한다.
  **가장자리 ≈ 내부**여야 통과다 (지금 14.5 vs 13.6 · 12.9 vs 12.9)
- 굵은 얼룩의 무게는 낮게 잡는다 — 넓은 면에 굵은 얼룩을 깔면 가죽이 아니라
  곰팡이 자국처럼 보인다. 무게는 잔 결과 모공 쪽에 둔다

## 대비 실측

글자가 실제로 찍히는 자리만 측정한 최악값입니다.

| | 최저 대비 | 판정 |
|---|---|---|
| 데스크톱 1280 · 경계 섹션 | 5.68:1 | AA 이상 |
| 데스크톱 1280 · 마무리 | 7.73:1 | AAA |
| 모바일 390 · 경계 섹션 | 6.32:1 | AA 이상 |
| 모바일 390 · 마무리 | 7.67:1 | AAA |

`opacity` 를 올리거나 `background-size` 를 키우면 이 값이 내려갑니다.
만질 때 다시 재세요 (기준은 작은 글자 4.5:1 · 큰 글자 3.0:1).
