# 로고

여기에 로고 파일을 넣으면 **글자 로고가 이미지 로고로 자동 교체**됩니다.
코드를 만질 필요가 없습니다.

## 넣는 방법

```
kcare-app/public/brand/logo.svg     ← 있으면 이걸 먼저 씀
kcare-app/public/brand/logo.webp    ← svg 가 없으면 이것
kcare-app/public/brand/logo.png     ← 둘 다 없으면 이것
```

파일을 넣고 다시 빌드하면 끝입니다. Vercel 은 배포할 때마다 빌드하므로
커밋해서 올리면 자동으로 적용됩니다.

`next.config.js` 가 빌드 시점에 위 세 파일을 순서대로 찾아
`NEXT_PUBLIC_BRAND_LOGO` 로 넘기고, `components/Logo.jsx` 가 그 값을 씁니다.

**파일이 없으면** 지금처럼 글자 로고(`K-CARE`)가 나옵니다. 없는 파일을
`<img>` 로 걸지 않으므로 깨진 이미지나 콘솔 404 가 생기지 않습니다.

## 규격

| 항목 | 값 |
|---|---|
| 형식 | **SVG 권장** (어떤 크기에서도 안 깨짐) · 안 되면 WebP/PNG |
| 배경 | **투명** — 흰 배경이 남아 있으면 남색 사이드바에서 흰 네모로 보입니다 |
| 여백 | 로고 주변 여백을 최대한 잘라내 주세요 (`height` 로만 크기를 맞춥니다) |
| 비율 | 가로형. 세로 대비 가로 3:1 ~ 6:1 정도 |
| 크기 | 래스터라면 세로 120px 이상 (고밀도 화면 대비) |
| 용량 | SVG 20KB · WebP 40KB 이하 |
| 색 | **단색 권장** — 아래 "어두운 배경" 참고 |

## 어두운 배경 (사이드바 · 데모 홈)

관제·경영 콘솔 사이드바와 데모 홈은 남색 배경입니다. 여기서는 로고를
`brightness(0) invert` 로 **흰색으로 반전**해서 씁니다.

- **단색 로고**면 이대로 잘 나옵니다 (지금 K-CARE 로고가 남색 단색이라 해당)
- **컬러 로고**를 쓰신다면 반전이 어색할 수 있습니다. 그럴 때는
  `logo-dark.svg` 를 따로 주시면 어두운 배경 전용으로 분기하겠습니다
  (지금은 그 분기가 없습니다)

## 쓰이는 곳

| 화면 | 위치 | 높이 | 배경 |
|---|---|---|---|
| `/service` | 상단바 | 22px | 밝음 |
| `/service` | 푸터 | 17px | 밝음 |
| `/` (데모 홈) | 제목 | 30px | 어두움 |
| `/dispatch` | 사이드바 | 20px | 어두움 |
| `/admin` | 사이드바 | 20px | 어두움 |

`BETA` 배지는 로고 옆에 별도 요소로 붙습니다 — 로고 파일 안에 넣지 마세요.

## 파비콘은 별도입니다

`public/favicon.svg` 는 아직 **임시 마크**입니다. 로고에서 심볼만 잘라낸
정사각 파일을 주시면 교체하겠습니다 (탭 아이콘은 아주 작게 나오므로
글자가 들어간 가로형 로고를 그대로 쓰면 안 읽힙니다).
