# 로고

지금 들어 있는 파일:

```
logo.svg        밝은 배경용 — 원본 2색 그대로 (12KB)
logo-dark.svg   어두운 배경용 — 진한 파랑→흰색, 밝은 파랑→연한 파랑 (12KB)
```

`../favicon.svg` 는 이 로고의 심볼(◁C)만 잘라 남색 라운드 사각에 올린 것입니다.

## 어떻게 만들었나

받은 원본은 흰 배경 JPEG(2728×712)이라 글자 둘레에 글로우와 링잉이 남아
있었습니다. 그대로 누끼를 따면 그 흐릿한 테두리까지 같이 딸려옵니다.
그래서 벡터로 떴습니다.

```
python3 scripts/gen-logo.py <원본.jpg>
```

1. 흰 배경을 알파로 되돌립니다 (`P = F·α + 255·(1−α)` 를 α 에 대해 풀이)
2. 언매팅한 색의 밝기로 **진한 파랑 / 밝은 파랑** 두 레이어로 나눕니다.
   경계 픽셀은 양쪽에서 동시에 자라게 해 중간에 놓습니다 — 한쪽만
   팽창시키면 경계가 그만큼 밀립니다
3. 레이어별로 `potrace` 로 벡터화한 뒤 색을 입혀 합칩니다

같은 원본을 넣으면 지금 파일과 **바이트 단위로 같은 결과**가 나옵니다.
원본 JPEG 은 저장소에 넣지 않았습니다 — 이 SVG 가 원본보다 깨끗해서
다시 뜰 일이 없습니다.

## 어두운 배경용을 따로 두는 이유

관제·경영 콘솔 사이드바와 데모 홈은 남색 배경입니다. 예전에는 밝은 배경용을
`brightness(0) invert` 로 흰색 반전해 썼는데, 그건 **단색 로고에만 맞는
처리**입니다. K-CARE 로고는 심볼이 진한 파랑 / 밝은 파랑 2색이라 반전하면
두 색이 같은 흰색이 되어 심볼이 한 덩어리로 뭉칩니다.

`logo-dark.svg` 가 있으면 그걸 쓰고, 없으면 예전처럼 반전합니다
(`components/Logo.jsx`).

## 쓰이는 곳

| 화면 | 위치 | 높이 | 배경 | 파일 |
|---|---|---|---|---|
| `/service` | 상단바 | 32px | 밝음 | `logo.svg` |
| `/service` | 푸터 | 26px | 밝음 | `logo.svg` |
| `/` (데모 홈) | 제목 | 42px | 어두움 | `logo-dark.svg` |
| `/dispatch` | 사이드바 | 30px | 어두움 | `logo-dark.svg` |
| `/admin` | 사이드바 | 30px | 어두움 | `logo-dark.svg` |

**30px 아래로는 쓰지 마세요.** 로고에 `Global Healthcare Concierge` 태그라인이
들어 있는데, 전체 높이의 약 11% 라 30px 이면 태그라인이 3px 입니다. 그 아래는
글자가 아니라 회색 얼룩으로 보입니다. 글자 로고를 쓰던 때보다 각 자리의 높이를
키운 것도 이 때문입니다 (상단바 22 → 32px).

`BETA` 배지는 로고 옆에 별도 요소로 붙습니다 — 로고 파일 안에 넣지 마세요.

## 다른 파일로 바꾸려면

파일을 덮어쓰고 다시 빌드하면 끝입니다. 코드는 안 만져도 됩니다.

```
logo.svg   →  logo.webp  →  logo.png        (있는 것 중 위에서부터)
logo-dark.svg → logo-dark.webp → logo-dark.png
```

`next.config.js` 가 빌드 시점에 이 순서로 찾아 `NEXT_PUBLIC_BRAND_LOGO` ·
`NEXT_PUBLIC_BRAND_LOGO_DARK` 로 넘기고, `components/Logo.jsx` 가 그 값을 씁니다.
둘 다 없으면 예전처럼 글자 로고(`K-CARE`)로 떨어집니다 — 없는 파일을 `<img>` 로
걸지 않으므로 깨진 이미지나 콘솔 404 가 생기지 않습니다.

| 항목 | 값 |
|---|---|
| 형식 | **SVG 권장** (어떤 크기에서도 안 깨짐) · 안 되면 WebP/PNG |
| 배경 | **투명** — 흰 배경이 남으면 남색 사이드바에서 흰 네모로 보입니다 |
| 여백 | 로고 주변 여백을 최대한 잘라내 주세요 (`height` 로만 크기를 맞춥니다) |
| 비율 | 가로형. 지금 파일은 3.87:1 |
| 크기 | 래스터라면 세로 120px 이상 (고밀도 화면 대비) |
| 용량 | SVG 20KB · WebP 40KB 이하 |
