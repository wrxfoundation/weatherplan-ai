# persona-interview — 인터뷰 추출 프로토콜

polysona interview 프로토콜의 적용판 (LilMGenius/polysona, MIT —
`../POLYSONA-ATTRIBUTION.md`). 진행 전 `references/`의 3개 기법 문서를 먼저 읽는다.

## 순서

1. **워밍업 = McAdams 내러티브** — 삶(또는 사업)의 챕터 제목, 고점·저점·전환점.
   표현은 인터뷰이의 원문 그대로 기록한다.
2. **가치 사다리 = 래더링(+MI+ACT)** — 표면 선호 → 도구 가치 → 종착 가치로 상승.
   종착 가치가 안정되면 멈춘다 — 몰아붙이지 않는다.
3. **은유 보존 = 클린 랭귀지** — 이미지 언어("안개", "엔진 과열")가 나오면 12질문
   템플릿으로 따라가고, 해석·라벨·해결책을 심지 않는다.
4. **모순은 `GAP:` 표기** — 이상적 자기 서술과 실제 반복 행동이 어긋나면 강제로 봉합하지
   말고 GAP으로 남긴다. 모순이 소재다.
5. **산출물** — ① 인터뷰 로그(날짜·기법·원문 인용 중심, append-only) ② 보이스 노트
   (레지스터, 선호/회피 표현, 반복 은유).

## 우리 원칙 (원본에 추가)

- 대외 사용 전 인터뷰이 동의와 인용 확인을 거친다.
- 개인 식별정보는 repo에 기입하지 않는다 (기존 PII 원칙).
- 추출 전용: 인터뷰 도중 콘텐츠 초안을 쓰지 않는다 — 추출이 끝난 뒤 별도 단계에서.
