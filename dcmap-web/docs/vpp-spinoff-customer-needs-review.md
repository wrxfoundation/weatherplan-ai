# 스핀오프 #3 (재생 예측·VPP 두뇌) — 수요처 현실성 검증 리뷰

작성: 2026-07-17 · 대상 문서: "SPIN-OFF HANDOFF — 재생에너지 예측·VPP 두뇌" (2026-07)
원칙: 검증(공개자료) / 추정(미검증) 구분 · 출처+날짜 상시 표기 — dcmap 정직성 원칙 그대로 적용.

## 0. 결론 요약 (TL;DR)

**원안(3배치 풀빌드로 "VPP 두뇌" 플랫폼을 세우는 계획)은 보류를 권고한다.**
수요처 검증 결과, 인수인계 문서의 수익 앵커(예측제도 정산 룰 엔진)는 **일몰이 예고된 제도**에 걸려 있고,
문서가 "차별점"으로 꼽은 지도·계통 레이어는 **수요처의 구매 기준이 아니다**.
수요처가 실제로 돈을 내는 기준은 단 하나 — **실측으로 증명된 예측 오차율(트랙레코드)** — 인데,
우리는 아직 이것이 0이다. 따라서 "플랫폼 먼저"가 아니라 **"트랙레코드 먼저"**로 순서를 뒤집는
축소 MVP(§4)를 제안한다. 폐기가 아니라 순서 교정이다.

---

## 1. 수요처별 검증 — 누가, 무엇에, 실제로 돈을 내는가

### ① 20MW 이상 발전사업자 (예측제도 직접 대상) — 원안의 주력 타깃

- **시장이 작다 (검증)**: 국내 태양광은 2022년 누적 12만 2,495개소로 압도적 다수가 소규모 분산형이다
  (한국에너지공단 재생에너지클라우드플랫폼). 예측제도 직접 대상인 20MW 이상 단일 자원은
  대부분 풍력·일부 대형 태양광으로 모수 자체가 적다.
- **정산금 상한이 낮다 (계산, 추정)**: 20MW 태양광, 이용률 15% 가정 시 연간 발전량 약 26GWh.
  오차율 4% 이하를 **항상** 달성해도 정산금 상한은 연 약 1억 원(4원/kWh). 예측 대행 수수료는
  그 일부(통상 정산금 셰어)이므로, 발전소 1곳당 우리가 가져갈 수 있는 매출은 연 수백~수천만 원 수준.
  이 단가로는 예측 모델·운영 인프라 투자 회수가 어렵다.
- **제도 자체가 일몰 예고 (검증)**: 전력 당국은 입찰제 전환 대비를 이유로 예측제도의 단계적 일몰을
  예고했고, 정산 기준도 강화(오차율 6%↓ 4원 → 4%↓ 4원)됐다 (전기신문 2025.2). 제도 도입(2021) 후
  평균 오차율은 8.3%→5.7%로 개선됐으나 개선세가 둔화되어 기준을 조인 것. **일몰 제도에 수익
  엔진을 앵커하면 제품 수명이 제도 수명에 종속된다.**

**판정: 니즈는 실재하나 시장이 작고 축소 중. 주력 타깃 부적합.**

### ② 소규모(1MW 이하) 발전사업자 — VPP 경유 대상

- 이들은 도구를 사지 않는다. **중개사업자를 고른다.** 예측·입찰·정산 대행은 중개사업자가
  정산금 셰어 모델로 사실상 무료 제공하는 것이 시장 관행 (해줌 등, 전기신문 중개사업자 시리즈).
- 즉 이 세그먼트에서 우리가 SaaS를 팔 자리는 없다. 팔려면 우리가 직접 중개사업자(등록·재정보증·
  365일 관제 운영)가 되어야 하는데, 이는 소프트웨어 스핀오프가 아니라 운영 사업 진출이다.

**판정: SaaS 수요처 아님.**

### ③ 중개사업자(VPP 운영사) — 예측을 "사는" 유일한 세그먼트

- 예측 수요는 진짜 있다. 그러나 **이미 공급자가 있고, 그 공급자가 시장 1위 운영사다 (검증)**:
  - 해줌: 국내 1호 중개사업자, 운영 자원 1GW+, KPX 혼합자원 예측 오차율 1위. 발전량 예측
    **API 상품**(D-1·H-1 입찰 특화, +72h)과 신규 중개사업자용 **'해줌V 올인원 솔루션'**(예측 알고리즘
    + 입찰·제어·정산 자동화 + 365일 관제 + 법규 대행)을 이미 판매 중 (인더스트리뉴스·헬로티).
    → **인수인계 문서가 만들자는 "VPP 두뇌"는 이미 상용화되어 팔리고 있는 상품이다.**
  - 식스티헤르츠: 태양광 예측 오차 3% 이내 실적의 VPP 소프트웨어 전문사.
  - 그 외 인코어드, KOMIPO 플랫폼, 현대건설 등 진입 다수.
- 이 시장의 구매 기준은 **실측 오차율 트랙레코드**다. 오차율 1%p가 곧 정산금이기 때문이다.
  트랙레코드 0인 신규 사업자의 예측을 살 이유가 없다 — 지도가 아무리 좋아도.

**판정: 유일하게 유효한 B2B 수요처. 단, 진입 조건이 '지도'가 아니라 '증명된 오차율'.**

### ④ 하나은행 (신탁·정산 돈흐름)

- 정산금 신탁 제도 자체는 검증(2026.1 전력시장운영규칙 개정)이나, 하나은행 연동은 인수인계
  문서 스스로 "협의 전 가정"으로 명시. 수요 검증 대상조차 아직 아님.

**판정: 가정 단계. 계획에서 표기 이상으로 반영 금지 (원안 문서와 동일 입장 유지).**

### ⑤ 해운·항공 웨더 라우팅 (#6)

- 원안대로 후순위 유지. DTN·StormGeo 대비 차별점("한국 항만 특화 국지예보")의 수요 검증도
  없으므로 이번 리뷰 범위에서 제외.

## 2. 원안의 전제 vs 확인된 현실

| 원안의 전제 | 확인된 현실 | 판정 |
|---|---|---|
| 정산 룰 엔진(4원/3원)이 수익 근거 | 제도 일몰 예고 + 기준 강화 (전기신문 2025.2) | ⚠ 앵커 부적합 |
| "경쟁자는 지도·계통 레이어가 없다"가 결정적 차별점 | 수요처 구매 기준은 실측 오차율. 지도는 구매 기준이 아님 | ✗ 차별점 아님 |
| 전국 재생발전소 예측 대행이 시장 | 예측 대행은 중개사업자가 정산금 셰어로 무료 제공하는 관행 | ✗ 유료 SaaS 자리 없음 |
| "VPP 두뇌"는 빈 자리 | 해줌 올인원 솔루션·예측 API가 동일 상품을 이미 판매 중 | ✗ 후발 진입 |
| — (원안에 부재) | 2026 재생에너지 입찰제 제주 시범 → 전국 확대. 예측 역량의 실수요는 입찰 대응으로 이동 중 | ✓ 진짜 기회 방향 |

원안 §8이 이미 "단일 예측 정확도만으론 차별 약함"이라 자인했는데, 실제로는 그 반대가 확인됐다:
**예측 정확도가 유일한 입장권이고, 지도·계통은 입장 후의 부가가치다.**

## 3. 우리가 진짜 가진 것 / 없는 것

- **있는 것 (검증)**: 케이웨더 기상 관측·수치예보 자산 · dcmap-web 재사용 컴포넌트(맵·계산기·룰 엔진·
  i18n·배포 파이프라인) · 발전허가·변전소여유·계통 데이터 레이어.
- **없는 것 (검증)**: 발전량 예측 모델 실측 트랙레코드(0) · 중개사업자 라이선스·재정보증·관제 운영 ·
  수요처 인터뷰 단 1건.
- 시사점: 우리의 현실적 포지션은 "VPP 두뇌 플랫폼 사업자"가 아니라 우선
  **"기상 기반 발전량 예측의 정확도를 증명하려는 데이터 사업자"**다. 증명 이후에야
  중개사업자 대상 B2B(예측 API/데이터 공급) 또는 제휴가 열린다.

## 4. 수정 제안 — "트랙레코드 먼저" 축소 MVP

원안 배치1(셸 복제·리스킨)부터 시작하는 대신, 다음 순서로 뒤집는다.

**Phase 0 — 그림자 예측 트랙레코드 (신규, 최우선 · 4~6주)**
- 공개 발전량 실적 데이터(전력거래소·재생에너지클라우드)로 대상 발전소 10~20곳을 선정,
  케이웨더 기상 데이터 기반 D-1 발전량 예측을 매일 산출·기록한다. **판매하지 않는다. 기록한다.**
- 산출물: 일자별 [예측 vs 실측 vs 오차율] 공개 대시보드 1페이지 (dcmap 컴포넌트 소재활용 — 풀 클론 불필요).
- 이것이 케이웨더 자산의 유일하게 반박 불가능한 증명이며, 이후 모든 영업의 근거 자료가 된다.
- 정직성 원칙 그대로: 오차율은 실측 누적치만 표기, 목표치·대표치 마케팅 금지.

**Phase 0과 병행 — 수요처 인터뷰 (신규 · 비용 0)**
- 중개사업자 5~10곳 대상: 예측을 자체 개발하는가 외부 구매하는가 / 구매 시 지불 구조(정산금 셰어율·
  API 단가) / 해줌·식스티헤르츠 대비 전환 조건 / 입찰제 전국 확대 대비 준비 상태.
- 판정 게이트: **"검증된 오차율 X% 이하면 갈아타겠다/추가 구매하겠다"는 답을 2곳 이상**에서 받지
  못하면 배치1 이후 개발 착수하지 않는다.

**Phase 1 (게이트 통과 시) — 원안 배치1·2 축소판**
- 정산 계산기는 만들되 **예측제도 단가를 하드코딩 앵커로 쓰지 않는다**: 제도 트래커(원안 §8 방침)에
  일몰 시나리오를 1급 변수로 넣고, **재생에너지 입찰제(제주 시범 → 2026 전국 확대) 대응 시뮬**을
  같은 룰 엔진 패턴으로 함께 설계한다. 제도가 사라져도 계산기가 살아남게.
- 맵·계통 레이어는 차별 "부가가치"로 유지하되 영업 전면에 세우지 않는다.

**Phase 2 (트랙레코드 + 수요 확인 후) — 원안 배치3 (VPP 포트폴리오·AI 해설)**

원안 대비 변경 요약: 배치1~3 "만들고 나서 판다" → **"증명하고, 물어보고, 통과하면 만든다."**
헤리티지 재활용 매핑(원안 §3·§4)은 유효하며 Phase 1부터 그대로 쓴다.

## 5. 트래킹 대상 (제도 트래커 등록 권고)

1. 예측제도 일몰 로드맵 — 단계·시점 공식화 여부 (전기신문 2025.2 예고 → 후속 고시 추적)
2. 재생에너지 입찰제 전국 확대 일정·정산 구조 (제주 시범: 실시간시장+예비력시장+입찰제)
3. 준중앙급전 시행 결과(2026 봄 3~5월) 및 상시화 여부
4. VPP 정산금 신탁 실무 운영 현황 (하나은행 각도의 전제 조건)
