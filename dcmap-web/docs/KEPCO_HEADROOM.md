# 변전소 접속가능용량(여유용량) 연동 — 조사 결과 & 설계 (2026-07-14)

목표: 5축 스코어의 최대 공백인 **전력축 '변전소 여유' 15점(현재 '데이터 대기')**을
변전소 단위 실데이터로 채운다. 현재는 시도 단위 연계가능용량(gridMw)만 사용 중.

## 2. 권장 경로 (2단계)

### 1단계 — 분산전원 연계정보 API (즉시 실행 가능)
1. 공공데이터포털에서 해당 API 활용신청 → 인증키 발급 (사용자 작업, LAW_GO_KR_OC와 동일 패턴)
2. `api/_proxy.js`에 `src=kepco` 위임 추가 (신규 서버리스 함수 0개 — 12개 상한 유지)
   - env: `KEPCO_DATA_KEY` (Vercel env 전용, 리포 커밋 금지)
3. 응답(변전소명·여유용량 MW)을 `SUBSTATION_POINTS`와 이름 매칭 → 좌표 부여
   - 매칭 실패분은 버리지 않고 '좌표 미매칭' 카운트로 노출(정직)
4. 클라이언트 캐시: localStorage 24h (일 단위 갱신 데이터)

### 2단계 — 사이버지점 DC용 조회 (런타임 검증 후)
- Vercel 런타임에서 200이면: 주기 스냅샷(주 1회, Watch 크론에 편승) → 정적 JSON 커밋 방식
- 403/봇차단이면: 1단계 데이터만 사용하고 라벨을 '분산전원 연계 기준 여유'로 유지

## 3. 제품 반영 지점

- `psia.js` — `sub`(변전소 거리 12) 요소에 **여유용량 보정** 추가: 거리 점수 × 여유계수
  (여유 0MW 변전소 인접은 무의미 — 距離만으로 과대평가 방지)
- `SitePanel` 5축 — 전력축 '변전소 여유 15점 (대기)' 슬롯을 실점수로 전환, basis에
  '한전 분산전원 연계정보(변전소별), 기준일' 명시
- 맵 변전소 레이어 — 툴팁에 여유 MW, 여유량 비례 마커 크기(선택)
- 정직성 규칙: ① 기준(신재생 연계)임을 항상 병기 ② 기준일 표기 ③ 미확보 변전소는 '대기' 유지

## 4. 사용자 액션 필요

- [ ] 공공데이터포털에서 「분산전원 연계정보」(또는 동등 변전소 여유용량) API 활용신청 → 인증키
- [ ] Vercel env `KEPCO_DATA_KEY` 등록
- 이후 구현(프록시 위임·매칭·UI)은 이쪽에서 진행

## 5. 리스크

- 신재생 연계 기준 ≠ DC 수전 기준 (방향이 다름: 발전 유입 vs 부하 인출). 참고 신호로는 유효하나
  절대 'DC 접속 가능'으로 단정 표기하지 않는다 — 라벨 규칙으로 강제.
- 한전 웹 조회는 구조 변경·차단이 잦음 → API 우선, 웹은 스냅샷 보조.
