## 우선 연동 제안 (임팩트 순)
1. **EPSIS** → 발전소 용량 실채움 + 자가발전 5점 (전력축)
2. **홍수위험지도 + SGIS + 재난안전** → 리스크축 15점 pending 대부분 해소
3. **국토부 실거래가(RTMS)** → 토지축 D4
4. **기상청 API허브** → 기상축 M3
5. **행정표준코드** → 코드 체인 안정화(전 축 파이프라인 신뢰도↑)

> 주의: 대부분 data.go.kr `apiKey`(보유) 또는 무인증. 샌드박스는 외부 아웃바운드 차단이라 스키마 확인·연동은 프로덕션에서. 각 연동은 기존 `api/*.js` 프록시 패턴(키 env·방어적 파싱·`{available:false}` 폴백)을 따른다.
