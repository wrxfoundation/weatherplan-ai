# 지가 트래킹 설계 노트 — 부지선정 단계의 땅값 인텔리전스

> 검증 완료(2026.07.10): KOSIS에서 DC 입지 시군구 38곳 전부의 **월간 지가변동률** 실조회 성공.
> 첫 스냅샷: `data/land_price_v0.json` (2026.05 시점).

|---|---|---|---|---|

## 왜 이게 해자인가 — "발표 전후의 지가 반응"

지가변동률 통계 자체는 소급 조회가 되지만, **명당의 차별화는 이벤트와의 결합**이다:
- D2(dc-events)가 착공·인허가·투자 발표를 시계열로 쌓고,
- 지가 스냅샷을 월간으로 병행 축적하면,
- "계통영향평가 통과 발표 → 인근 읍면동 지가 반응"의 **이벤트-지가 정렬 시계열**이 생긴다.
이 결합 데이터는 소급 복원이 어렵고(이벤트 타임스탬프가 우리 것), 부지선정 단계 고객("이 동네 지금 들어가도 되나")에게 직접 팔리는 인텔리전스다. 첫 스냅샷 시점(2026.05)이 베이스라인.

## 구현 현황 (v0)

- `data/land_price_v0.json` — 시설 입지 시군구 33 + 시도 5 스냅샷 (KOSIS 출처·시점 명기)
- `src/data/landPrice.js` — 시군구 키 조회(시도 폴백)
- 노출: 시설 카드·상세에 "지가변동률(월)" 셀, 지점 분석 패널에 인근(최근접 시설 시군구 기준) 값
- **점수화는 보류**: 토지축 지가 5점의 산식(변동률이 높으면 원가 리스크? 수요 신호? — 방향성 자체가 가중치 튜닝 대상)은 골든케이스 캘리브레이션 후

## 읍면동 승격 (v0.2 — 2026.07.11 완료)

- **소스**: KOSIS·한국부동산원 「지가변동률」 읍면동별 — orgId **408**, tblId **DT_31501N_010**, 월간, 전국 3,400여 구역
- **파이프라인**: `scripts/land_dong.mjs` — KOSIS 원본 덤프 → `data/land_price_dong_v0.json` (DC 입지 시군구 35곳 · 읍면동 539구역, 2026.05)
- **파싱 주의**: 이 테이블의 지역코드는 KAB 자체 체계(11 서울 … 27 제주 — 행정표준코드 아님)이고,
  덤프의 C1 코드가 순수 prefix 계층이 아니다(서울 강서구가 111504로 양천구 코드대에 끼어 있음 —
  도봉구·옹진군 동일 유형). 따라서 **문서 순서(깊이우선) 기반**으로 트리를 복원한다.
- **구가 있는 시**(수원·성남·안양·부천·안산·고양·용인·포항)는 산하 구의 읍면동까지 시 키로 흡수
- **교차검증**: 시군구 요약치 vs 기존 `land_price_v0.json`(DT_1YL20881E) — 불일치 0
- **노출**: 시설 상세 "입지 지가 펄스"(시군구 평균 + 동 최고/최저 HBar), 지점 분석 패널(동 단위 범위),
  대시보드 LAND PULSE(전 구역 최고/최저 하이라이트)
- **정직성 규칙**: 시설 좌표 대부분이 시군구 중심점이므로 특정 동과 시설을 결부하지 않는다(상세 페이지에 명시).
  필지 확인(geocode_level=parcel) 시설부터 해당 구역으로 정밀화.

## 용도지역별 (보류 — 기술 제약)

DT_PLCAHTUSE(org 408)는 다차원 objL 파라미터(지역×용도지역)가 필수인데 현 KOSIS MCP 툴이
objL을 지원하지 않아 조회 불가(err 20). KOSIS 오픈API 직접 호출(objL1/objL2 지정)로 우회 가능 —
D5 어댑터에서 공업/계획관리지역만 필터해 적재하는 것으로 이월.
