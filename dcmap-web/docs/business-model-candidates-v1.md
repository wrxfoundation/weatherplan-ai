## Tier 1 — 지불 구조가 이미 제도화된 판 (최우선 검증)

### 1. 기상감정·날씨 사실확인 자동화 ("날씨의 등기부등본") ★ 추천 1순위
- **상품**: 좌표+기간 입력 → 관측·보간 데이터 + 법적 증빙용 기상 리포트 자동 생성 (SaaS/API + 감정사 검수 하이브리드)
- **수요 증거 (검증)**: 기상감정사 제도가 법제화되어 있고(기상산업기술원), 손해보험 손해사정·
  교통사고/산재/자연재해 소송·건설 공기연장(EOT) 클레임에서 기상 증빙이 이미 유상 거래됨.
  정부24에 기상현상증명 민원이 존재하나 **관측지점만 커버** — 비관측지점 보간·감정이 민간 영역.
- **왜 우리**: 민간기상사업자 지위 + 자체 관측망(비관측지점 보간의 근거) + 리포트 자동화는
  기존 스택(dcmap 리포트 엔진 + Claude)으로 수 주 내 구축 가능. 수작업 감정 대비 단가·속도 파괴.
- **무료 대체**: 불가 — 법적 증빙의 구매기준은 데이터가 아니라 **공신력**.
- **검증 액션**: 손해사정법인·건설클레임 컨설팅(CCA류) 2~3곳 인터뷰 — 감정 1건 단가·연간 건수·리드타임 pain.

### 2. 실내공기질(IAQ) 컴플라이언스 구독 — 에어가드K 확장
- **상품**: 측정기 + 법정 기록·보존·보고 자동화 구독 (다중이용시설·어린이집·학교·요양시설)
- **수요 증거 (검증)**: 실내공기질관리법상 측정·기록·보존이 **법적 의무**. 측정대행업체 거짓측정
  문제가 불거져 **정부 보고 의무화 입법 추진** — 연1회 대행에서 상시·투명 측정으로 구조 이동 중.
- **왜 우리**: 케이웨더 공기측정기(에어가드K) 사업 실재 = 수요를 자사 매출로 이미 증명.
  Wellbian 자산 재사용. **실내는 기상청 무료 데이터가 존재하지 않음** — 이 세션 모든 kill의
  원인이던 '무료 대체' 리스크가 구조적으로 0인 유일한 후보.
- **리스크**: 센서 스타트업 경쟁, 하드웨어 마진. 단 구매기준이 '규제 신뢰'라 브랜드 우위.
- **검증 액션**: 기존 에어가드K 고객 중 다중이용시설 3곳 — 기록·보고 pain과 지불의사. 입법 경과 추적.

### 3. 금융권 기후 물리리스크 데이터 — dcmap의 금융 버전
- **상품**: 자산 좌표 포트폴리오 → 침수·태풍·폭염 노출 스코어·시계열 (KSSB 2호 물리위험
  공시 항목: "물리적 위험에 취약한 자산 금액·비율")
- **수요 증거 (검증)**: KSSB 기후공시 기준 확정, 1차 의무공시 2028(연결자산 30조↑ 코스피).
  한국은행·금감원이 **15개 금융사와 기후 스트레스테스트 공동 진행 중** — 지금 예산이 돈다.
- **왜 우리**: dcmap 엔진(point-in-polygon·좌표 스코어링)이 그대로 제품 코어. 글로벌 벤더
  (MSCI·S&P)는 비싸고 한국 국지 해상도 약함.
- **판매 경로**: 직판보다 회계법인·ESG 컨설팅에 데이터 공급(B2B2B) — 업스트림 패턴 정합.
- **검증 액션**: 회계법인 ESG팀 1~2곳 — "한국 자산 물리리스크 데이터를 지금 어디서 얼마에 사는가."

## Tier 2 — 수요 실재, 1차 인터뷰 필요 (기존 결론 승계)

### 4. 야외 이벤트·레저 decisioning (스윕 검토 1순위 유지)
- 구단·공연·테마파크·골프장. 본체 광고엔진과 동일 구조(트리거→매출행동) → 재사용률 최고.
- 검증 액션: 인터뷰 3곳 — "오판 1회 비용" 확인 (기존 결론 그대로).

### 5. 유통·FMCG 날씨 수요예측 데이터
- 일본 웨더뉴스가 증명한 모델(유통 발주·상품 수요 예측용 날씨 데이터 판매). 한국 편의점·FMCG의
  날씨 연동 발주 관행 실재. 본체(날씨 트리거 광고)와 같은 구매자군 → 크로스셀 라인.

## Tier 3 — 전략 옵션 (베팅성)

### 6. 건설 통합: 공기연장 클레임 증빙(과거) + 공정 기상 윈도우(미래)
- 스윕 2순위를 1번 후보에 번들 — 같은 건설사 구매자에게 "지나간 날씨는 클레임 증빙,
  다가올 날씨는 공정 판단" 단일 상품. 단독 진입보다 1번의 확장팩으로.

### 7. AI 에이전트용 검증 기상 데이터 (MCP)
- koreaapi 인프라 재사용 — provenance 붙은 날씨 사실 API의 기계 소비 버전(= 1번의 에이전트 채널).
  시장 미성숙이므로 단독 사업이 아니라 1번 구축 시 엔드포인트 하나로 병행 노출만.

## 권고 순서

**1번(기상감정 자동화)부터.** 근거: 수요가 제도·소송·보험으로 구조화되어 있고, 무료 대체가
원리적으로 불가(공신력이 구매기준)하며, 케이웨더 지위와 정확히 정합하고, 빌드가 기존 스택으로
가장 가볍다. 2번은 입법 경과와 동행, 3번은 인터뷰로 단가 확인 후.

공통 규율(유지): 각 후보 **실구매자 인터뷰 2~3곳 전 착수 금지**. 인터뷰 질문은 통일 —
"이 문제를 지금 무엇으로, 얼마 주고 해결하는가."
