# 법령 원문 연동 (law.go.kr DRF) — AI Q&A 정직성 강화

AI 어시스턴트 Q&A가 도메인 법령(분산에너지법·환경영향평가법·건축법·국토계획법·전기사업법·AIDC 특별법)을
언급하는 질문을 받으면, **법제처 국가법령정보센터에서 실제 조문 원문을 조회해 컨텍스트로 주입**합니다.
AI가 기억이 아니라 원문을 인용하게 하는 장치입니다.

## 활성화 (5분, 무료)

1. https://open.law.go.kr → 회원가입 → **OPEN API 신청** (무료, 즉시).
   - OC 값 = **마이페이지 → API인증키관리**의 "현재 API인증키(OC)" 값.
     (기본값은 이메일 ID 부분이지만 변경 가능 — 화면에 표시된 현재 값을 그대로 사용)
2. Vercel → Settings → Environment Variables:
   - Key: `LAW_GO_KR_OC` / Value: 위 API인증키(OC) 값
3. Redeploy. 끝.

## 동작 방식 (정직성)

- 공식 매뉴얼 방식 준수: **목록조회(lawSearch)로 법령일련번호(MST)·상세링크를 얻고 → 본문조회(lawService)** 로 조문을 가져옵니다(MST 우선, 법령ID 폴백).
- 질문에 "제23조"처럼 조문이 지정되면 **해당 조문 원문만** 조회(토큰 절약·정밀 인용).
- 응답에는 law.go.kr **원문 링크를 출처로 표기**하도록 지시합니다.
- 조회된 원문 컨텍스트에는 "원문에 있는 내용만 인용, 없으면 '원문 확인 필요'로 답하라"는 지시가 붙습니다.
- **미설정/조회 실패 시 조용히 생략** — 기존 Q&A 동작 그대로(성능 저하 없음, 5초 타임아웃).
- '한전 기본공급약관'은 법령이 아니라 약관이므로 대상 아님(정적 프롬프트가 담당).

## 대상 법령 (질문 키워드 매핑)

| 법령 | 트리거 키워드 |
|---|---|
| 분산에너지 활성화 특별법 | 분산에너지 · (전력)계통영향평가 |
| 환경영향평가법 | 환경영향평가 |
| 건축법 | 건축법 · 건축허가 · 사용승인 |
| 국토의 계획 및 이용에 관한 법률 | 국토계획법 · 용도지역 · 개발행위 |
| 전기사업법 | 전기사업 · 발전사업 허가 |
| AIDC 특별법(정식명 검색) | AIDC · 인공지능 데이터센터 |

주의: AIDC 특별법은 정식 법령명이 유동적이라 하드코딩하지 않고 **검색 결과 메타데이터만** 사용합니다.

## 검증

배포 후 AI 어시스턴트 Q&A 탭에서: "분산에너지법 제23조가 뭐야?" → 응답이 법제처 조회 원문 기준으로
답하는지, 서버 로그에 오류가 없는지 확인. 샌드박스에서는 law.go.kr이 프록시 차단이라 로컬 검증 불가
(Vercel 런타임에서 동작).
