# 전력 인허가 룰북 v0 — 데이터센터 수전 트랙 정량 룰

> **용도**: 스코어링 엔진 전력축(SPEC §5.2, 40점) 산식 근거 · D1(psia-tracker) 어댑터 상태 머신 정의 · L2 인텔리전스 브리프 템플릿 골격.
> **근거(전부 공개 소스)**: 분산에너지 활성화 특별법('24.6 시행) · 기후에너지환경부공고 제2025-139호('25.11.28, 전력계통영향평가 시범운영) · 한전 기본공급약관 제23조 및 시행세칙.
> **원칙**: 본 문서는 공개 규정에서 추출한 일반 룰만 담는다. 특정 부지·법인·좌표 등 내부 검토 정보는 포함하지 않는다(SPEC §0-1).
> ⚠️ 시범운영 기준이므로 **고시 정식 제정·약관 개정 시 수치가 변동**될 수 있다. `data/power_rules_v0.json`의 `valid_basis`로 버전 관리.

## 1. 용량 → 수전전압 트랙 결정 룰 (기본공급약관 제23조)

| 계약전력 | 수전전압 | 회선 구성 | 비고 |
|---|---|---|---|
| < 5,000 kW | 22.9kV 이하 | 1회선 | 예정통지 대상 아님 |
| 5,000 kW ~ 20 MW | 22.9kV | 상용 1회선 | 5,000kW 이상부터 예정통지 대상 |
| 20 ~ 40 MW | 22.9kV **또는** 154kV 협의 | 22.9kV 시 상용 2회선(+예비) | 22.9kV 1회선 한도 = 20MW |
| **> 40 MW** | **154kV 의무** | 협의 | 자체 수전설비(변전실) 투자 필수 |
| 초대형(수백 MW급) | 345kV 협의 | 협의 | 기술검토비 별도 구간 존재 |

**스코어링 시사점**
- `power_mw > 40` → 154kV 전제: 154kV+ 변전소 거리·전용선로 신설 비용이 지배 변수 (§5.2 "154kV+ 변전소 거리 15점"의 근거)
- `power_mw <= 40` → 22.9kV 옵션 유지: 배전망 여유(D3 headroom)가 지배 변수, 단 40MW가 확장 상한 — 증설 계획이 있으면 154kV 전제로 평가
- 40MW는 경계값: Powered Land 관점에서 "22.9kV로 갈 수 있는 최대 용량"이라는 시장 프리미엄 포인트

## 2. 대상·관문 룰

- **전기사용(수전)예정통지**: 계약전력 5,000kW 이상 대용량 고객. 비용·구속력 없음. 접수 문서가 계통영향평가 신청의 첨부 요건.
- **전력계통영향평가**: **10MW 이상** 시설 의무(분산에너지 활성화 특별법). 평가를 거쳐야 전기사용계약 체결 가능.
- **시범운영 특례**(공고 2025-139호): 고시 제정 전 임시 절차 — 한전 기술검토 결과 **"공급 가능" + "적정전압 유지"면 점수와 무관하게 심의회 상정**. 사실상 유일 관문 = 계통 물리 여건.
- **과부하율 > 100%** = 신규 공급 거절 사유. 과부하율·보강 난이도 수치는 기술검토 회신에 기재됨 → D3가 축적할 핵심 필드.

### 2-1. AIDC 특별법 (2026.5.7 국회 통과 · **2027년 2월 시행 예정**)

「인공지능 데이터센터 산업 진흥에 관한 특별법」이 인허가 게임의 룰을 바꾼다 (출처: 정책브리핑 korea.kr 2026.5.8):

- **인허가 통합 창구**: 국가AI전략위 심의·의결을 거쳐 과기정통부 단일 창구로 다수 인허가 일괄 처리
- **타임아웃제**: 일정 기한 경과 시 인허가 처리 간주 → 리드타임 상한이 생김
- **비수도권 면제**: 비수도권에 **일정 규모 이하** AIDC 신축·증축 또는 기존 DC의 AIDC 전환 시 **전력계통영향평가 면제** (규모 기준은 대통령령 위임 — 미제정)
- 부대시설(승강기·주차장·미술작품 등) 설치 기준 완화 (대통령령 위임)

**D1 상태 머신 영향**: 2027.2부터 비수도권·소규모 트랙은 S1~S5(평가 절차)를 건너뛰는 분기가 생긴다. 어댑터는 `psia_exempt` 플래그와 대통령령 기준(제정 시) 추적 필요.
**스코어링 영향**: §5.2 "계통영향평가 지역 리스크(수도권 감점/특화지역 가점)"의 정량 근거가 법률로 승격 — 비수도권 가점의 산식화 가능.

### 2-2. 정책 신호 (3대 메가프로젝트, 산업부 2026.6.29 발표)

- **345kV 계통 여유 변전소 정보 공개** 예정 → 공개 즉시 전력 레이어(substations.json)·D3의 공식 소스
- 비수도권 AIDC 계통영향평가 **신속 처리**, 지역별 전기요금제 + **AIDC 전용 요금제** 도입 계획
- AIDC 1단계 8.4GW(SK 5·GS 2.4·네이버 1) → 2035년 총 18.4GW 목표, 약 550조 투자 — 입지 확정 이벤트는 D2 추적 대상

## 3. 비용 룰 (심의회 상정까지, VAT 별도)

| 단계 | 항목 | 22.9kV | 154kV | 345kV |
|---|---|---|---|---|
| 예정통지 | 접수 | 무료 | 무료 | 무료 |
| 예정통지 | 공급방안 사전검토 수수료 | 35만 원 | 67만 원 | — |
| 평가 신청 | 기술검토비 | 100만 원 | 659만 원 | 988만 원 |
| 평가서 작성 | 회계법인·세무 확인(안정성·지방세 항목) | 수백만 원대(견적) | ← | ← |
| 계약 | 시설부담금(표준+거리 가산)·인입공사비·예비전력 요금 | 실비 — 선로 거리 비례 | ← | ← |

- 기술검토비는 신청 후 **20영업일 내 납부**, 미납 시 효력 상실, **결과 무관 환급 불가**.
- 시설부담금·인입공사비는 **변전소~부지 거리에 비례** → 변전소 거리 배점의 화폐적 근거.

| 계약 체결 기한 | 공급 승인 후 **1년 내** 미체결 시 반려 리스크 | 한전 허수수요 관리 강화 |

## 5. 평가서 구성 요건 (시범운영 기준)

1. 한전 기술검토 결과 인용(공급 가능 여부·과부하율·적정전압)
2. 사업 안정성 증빙 — 자기자본비율 등, **공인회계사/회계법인 확인 필수**
3. 지방 재정 기여도 — 예상 지방세, **세무사/회계법인 확인 필수**
4. 산업 활성화 효과 — 총사업비 × 한국은행 산업연관표 계수(부가가치·고용)
5. (선택·가점) 자가발전·ESS·xEMS 설치계획 + 이행확인서(별표15) — §5.2 "자가발전 인접 5점"과 연동되는 공식 가점 항목

## 6. D1(psia-tracker) 상태 머신

```
S0 예정통지 접수 → S1 계통영향평가 신청(시범운영) → S2 기술검토 중(≤90d)
→ S3 기술검토 회신(공급가능/불가·과부하율) → S4 평가서 제출(≤60d 심사)
→ S5 심의회 상정·의결 → S6 전기사용신청 → S7 최종공급방안·계약
실패 전이: S2→반려(기술검토비 미납 20영업일 초과) · S3→공급불가 · S7→반려(승인 후 1년 미계약)
```

- 추적 소스: 기후부 공고 게시판(공고·개정·회신 흐름), 사업자 공시·보도. **게시판은 이력 보존이 약해 소급 불가** → 주 1회 append-only 스냅샷(SPEC §5.3 D1의 존재 이유).
- 예비전력 계약 유형: 갑(상용과 동일 변전소) / 을(타 변전소) — 시설 이중화 수준의 프록시 필드.
