# SGIS 통계지리정보서비스 활용 연구 — 리스크축·수요 인구 레이어 (2026.07)

대상: `https://sgis.mods.go.kr/view/map/interactiveMap/publicDataView` (SGIS 인터랙티브 지도 · 공공데이터 뷰)

## SGIS가 무엇인가
통계청 **SGIS(통계지리정보서비스)**는 국가통계를 지도 위에 올려 보는 서비스다. `interactiveMap/publicDataView`는
공공데이터를 통계 경계·격자에 겹쳐 보는 **탐색/시각화 창구**이고, 프로그램 연동은 별도의
**SGIS 오픈API**(`sgis.kostat.go.kr/developer`)로 한다. 즉 mods.go.kr 뷰어는 "무엇이 있는지 눈으로 확인"하는 용도,
실제 흡수는 오픈API가 경로다.

## 제공 데이터 (명당 관점 핵심)
| SGIS 데이터 | 단위 | 명당 활용 |
|---|---|---|
| **인구·가구 통계** | 시도→시군구→읍면동→**집계구→격자(100m·1km)** | ★ 리스크축 "인구격자(민원 프록시)" — 부지 반경 내 거주 인구 밀도 |
| **사업체(전산업) 통계** | 동일 위계 | 수요·배후산업 컨텍스트(B2B 고객 근접성) |
| **주택 통계** | 동일 | 주거 밀집(민원 리스크) 보강 |
| **고령화·인구증감 통계주제도** | 시군구/읍면동 | 장기 인구 리스크(지역 소멸 vs 성장) — 입지 지속성 |
| **경계(행정/집계구) 폴리곤** | GeoJSON | 수도권/비수도권 자동 판정(현재 SitePanel 수동 토글 대체) |

## 오픈API 접근 방식
- 발급: `sgis.kostat.go.kr/developer` → **서비스 신청(consumer key/secret)** → `/OpenAPI3/auth/authentication`으로
  **accessToken** 발급(만료형) → 각 API 호출 시 토큰 전달.
- 주요 엔드포인트군: 통계주제도(`/OpenAPI3/themamap`), 인구·가구·주택·사업체(`/OpenAPI3/stats/population` 등),
  경계(`/OpenAPI3/boundary`), 지오코딩·주소, 활용지도.
- 격자 통계는 좌표(UTM-K/경위도)+반경 또는 격자ID로 조회 가능 → **임의 지점 클릭 반경 인구** 산출에 적합.

## 명당 통합 설계 (제안)
1. **`api/sgis.js` 프록시** — 기존 `api/*.js` 패턴. env: `SGIS_KEY`/`SGIS_SECRET`. 내부에서 accessToken 캐시(만료 관리),
   입력 `{lat,lng,radius}` → 격자 인구 합계·사업체수 반환. 실패 시 `{available:false}`.
2. **SitePanel(지점 분석) 연결** — scoreSite의 **리스크축 15점 중 "인구격자(민원 프록시)"** 항목을 pending→실점수로:
   반경 1~3km 거주 인구가 낮을수록 민원 리스크 낮음(가점), 사업체 밀도는 수요 근접(별도 표기). 배점 룰은 골든케이스 후 확정.
3. **수도권 자동 판정** — SGIS 경계 폴리곤으로 클릭 지점의 시도 자동 판정 → SitePanel 수동 토글 제거(전력축 지역 리스크 자동화).
4. **인사이트 보강** — 고령화·인구증감 주제도로 "비수도권 대형 DC의 인력 확보 리스크"(수도권 집중 인사이트) 정량화.

## 정직성 / 주의
- 토큰 만료·쿼터 관리를 프록시에서 처리(런타임 4.5s 타임아웃, 실패는 "연동 대기").
- 격자 인구는 **추정 통계**임을 UI에 명시. 배점 가중치는 임의 부여 금지(골든케이스 캘리브레이션 후).
- 샌드박스는 외부 아웃바운드 차단이라 토큰·스키마 확인은 프로덕션에서. 프록시 골격은 headroom/epsis와 동일하게 선(先)구현 가능.

## 우선순위
EPSIS(발전소 용량, 무인증) 다음 순번. SGIS는 **리스크축을 여는 가장 큰 단일 소스**(15점 중 인구격자 + 수도권 자동판정)라
스코어링 엔진 커버리지를 크게 끌어올린다 — 홍수위험지도·재난안전과 묶으면 리스크축 pending이 대부분 실점수화된다.
