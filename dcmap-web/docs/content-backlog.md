### A′. GW급 AIDC 입지 확정 추적 (D2 dc-events 어댑터 대상, 우선순위 최상)
- 3대 메가프로젝트 1단계 8.4GW의 구체 입지 미공개: **SK 5GW**(울산 기존 AIDC와의 관계 미확인) / **GS 2.4GW** / **네이버 1GW**(각 세종 확장 여부 미확인) / **SK 서남권 1GW**(솔라시도와의 동일성 미확인)
- 입지 확정 발표 시: 시드 신규 항목 추가 또는 기존 항목(kr-skt-ulsan-aidc·kr-solaseado-haenam·kr-naver-gak-sejong) 병합·보강 판단. **동일성 확인 전 임의 병합 금지.**
- AIDC 특별법 하위 대통령령(비수도권 면제 규모 기준) 제정 추적 → power_rules_v0.json `exemptions.threshold` 갱신
- **345kV 계통 여유 변전소 정보 공개(정부 예고)** → 공개 즉시 substations.json·D3 공식 소스로 흡수
