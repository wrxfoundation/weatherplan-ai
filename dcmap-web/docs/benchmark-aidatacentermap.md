# 벤치마크 노트 — aidatacentermap.org (2026.07 관찰)

> SPEC §0 벤치마크(LandGate·Gridcare·Paces·Acres) 외 신규 참조. Above Phone(프라이버시 기업)의
> 활동가 지향 미국 DC 맵. **명당과 데이터 구조는 동일하되 포지션은 정반대** — 유치·투자(B2B) vs 반대·감시(시민).

## 프로필

- 규모: DC 4,251 추적 (운영 1,963 / 계획 870 / 하이퍼스케일러 895), 총 전력 239GW 표기
- 레이어: 수자원 스트레스(유역별 단계 색칠) · 대수층 · 고압 송전선 · 에너지원(발전소·태양광·연료전지·ESS 780+)
- 마커 분류: **Unknown(용량 미공개) / Hyperscale(≥100MW 보고 용량) / Energy Source** — 상태가 아닌 "용량 공개 여부"가 1차 분류축
- 기능: 임의 지점 클릭 → 주변 전력·용수 임팩트 추정(LBNL 방법론, **? 버튼으로 산식 공개**), 크라우드소싱 제보(Contribute), 무료 리포트(리드 마그넷), 지역 활동가 그룹 연결(Action)
- 로드맵: Phase 1 미국+수자원(LIVE) → Phase 2 실시간 제보 반영 → **Phase 3 전 세계 맵**

## 명당에 주는 시사점

### 1. 시장 신호
- "한국판 0개"는 여전히 유효하나, **Phase 3(글로벌)가 로드맵에 명시** — 이들이 한국을 커버하기 전에 한국 데이터·SEO·시계열을 선점해야 하는 타이밍 근거가 하나 더 생김
- 반대 진영도 지도를 무기로 조직화한다 = 민원 리스크축(§5.2 리스크 15점)의 수요 측 실증. 명당의 리스크 스코어는 "이런 지도가 겨냥할 부지인가"를 정량화하는 셈

### 2. 즉시 이식한 것 (이 커밋)
- **하이퍼스케일 마커 강조**: 공개 용량 ≥100MW 시설은 마커 확대+강한 글로우 (분류 기준 차용, 시각 문법은 시안 유지)
- **패널 집계에 공개 전력 합계(MW)** 노출 — "Total Power" 카운터 대응

### 3. 백로그로 넘긴 것
- **산식 공개 UX**: 추정치 옆 ?버튼 → 방법론 노출. 명당 GPU 계산기·(M2)스코어에 동일 패턴 적용 — §8 "리포트 신뢰" 전략과 정합. 계산기는 이미 산식 텍스트 노출 중, 스코어링에서 정식화
- **용수 레이어**: 이들의 1차 레이어가 물이라는 점 주목 — 한국판은 K-water·유역 데이터로 가능. 서남권 팹·DC 동시 유치로 용수가 전력 다음 병목(§인프라 발표에도 용수 명시) → M3 기상 레이어와 함께 검토
- **제보(Contribute) 채널**: 시설 80+ 성장 루프. 단, 명당은 공개소스 온리 원칙상 제보를 "검증 큐"로 받아 needs_verify로 수록하는 설계 필요
- **임의 지점 클릭 → 간이 임팩트/적합도 티저**: L2 스코어링의 무료 훅으로 동일 UX 재해석 가능 (M2)

### 4. 반면교사
- 마커 대다수가 "Unknown — 용량 데이터 없음" = 크라우드소싱 데이터의 신뢰 문제 노출. 명당의 차별화는 needs_verify 배지·출처 명기·公식 발표 우선 원칙 — 유지할 것
- "요금 293% 급등 가능" 같은 강한 주장 — 명당은 출처 확정 수치만(§0-1). 신뢰가 B2B 단가의 기반
