## ① 감정서 표준 구조 — 항목별 설명과 우리 리포트 매핑

사례집 3개 시나리오가 공통으로 따르는 표준매뉴얼(2017) 감정서 구성:

1. **표지** — 업체명·대표자·기상감정사(실명)·계약명·발급일·발급 문구·직인.
2. **의뢰내용** — 감정대상 일시 / 감정대상 장소 / 기상감정 목적(분쟁 맥락 포함) / 의뢰인 주소·성명.
3. **조사내용**
   - 조사기간
   - 사전조사(감정 대상지역의 환경 — 지형·해발고도·풍상측 여부 등)
   - 현장조사(또는 수행하지 않은 사유·면담자)
   - 자료 분석(관측자료·일기도·레이더 등 사용 자료와 분석 방법)
4. **참고자료 및 출처** — 별첨 목록 열거(일기도, 예보문, 특보 현황, 위성·레이더 영상, 산출 근거 등).
5. **기상감정 결과 및 의견** — 종관 배경 → 관측 사실 → 산출 결과 → 인과 판단·의견(감정의 본체).
6. **관련 전문가 자문** — 해당사항 있을 경우 작성(3건 모두 '해당 없음').
7. **별첨자료** — 첨부 0~16 수준의 방대한 근거 자료(케이스마다 14~16종).

## ② 감정 분석 기법 인벤토리 — 웨더팩트 자동화 가능성 평가

사례집 3건에서 실제 사용된 기법과, 각 기법을 웨더팩트가 자동화할 수 있는지 평가.
평가 축: **가능**(관측·공표 자료의 기계적 대조) / **부분**(계산은 기계적이나 입력 확보·품질
판단에 사람 필요) / **감정사 영역**(해석·인과 판단 — 자동화 대상 아님).

| 기법 | 사례집 사용례 | 개요 | 자동화 평가 |
|---|---|---|---|
| **종관기상분석** | 3건 공통 — 지상·925/850/500/200hPa 일기도, 상당온위(+333K 기준), K지수(35 이상), 상·하층 제트 커플링, 등온위면, 하층제트 | 기압배치·수증기 유입·불안정으로 호우 발생 조건을 해석 | **감정사 영역** — 종합 해석과 인과 서술은 전문 판단. 자동화는 해당 시각 일기도·자료의 '수집·첨부' 보조까지만 |
| **레이더 강우강도 회귀** | 시나리오 1 — 주변 AWS 4지점의 10분 간격 레이더 강우강도 평균 vs 실측 60분 강수량으로 회귀식 산출 → 사건지점 레이더 평균을 회귀식에 대입(96.4mm/hr) | 레이더-지상관측 회귀로 무관측 지점 강수량 추정 | **부분** — 회귀 계산 자체는 기계적이나, 레이더 격자자료 접근·에코 품질 판단·지점 선정이 전제. 결과 채택 여부는 감정사 판단 |
| **PRISM 계열(K-PRISM·MK-PRISM) 거리·고도 가중 추정** | 시나리오 1 — 사건지점과 주변 AWS 간 거리·고도 가중(Fd=Fz=0.5), 사용 지점 2/3/4개 조합별 111.5 / 96.7 / 127.0mm/hr | 거리·고도(+사면방향·해양도) 가중으로 지점 강수량을 무관측 지점에 내삽 | **부분** — 거리·고도 가중 산식은 자동화 가능(다지점 AWS 입력 필수 — ③ 참조). 사면방향·해양도 가중치 설정과 지점 조합별 결과 해석(96.7 vs 127.0 중 무엇을 채택하나)은 감정사 판단 |
| **지형효과(산악 강제상승) 분석** | 시나리오 1(금정산 풍상측)·2(망경산 계곡 병목)·3(인경산 급경사) + 민감도 연구 인용(지형고도 상향 시 1시간최다 최대 25%·누적 +50mm 증가) | 풍상측·계곡·경사면 등 지형이 강수량을 증가시키는 효과를 정성·정량 평가 | **감정사 영역** — 지형-기류 상호작용 해석은 전문 판단. 자동화는 지점·대상지 고도차 등 수치 '표기' 보조까지만 |
| **극값·재현기간 대조** | 시나리오 1("100년에 한번" 강우강도, 1973년 이래 1시간 최다 2위)·시나리오 3(일강수량 극값 2위, 1시간최다 극값 경신) | 관측 이래 극값 순위·재현기간과 대조해 이례성 정량화 | **가능(조건부)** — 공표 극값 DB 확보 시 순위 대조는 기계적. 재현기간 '평가'는 감정사 검토 병기 |
| **특보·예보문 대조** | 3건 공통 — 첨부 4(당일 예보문)·첨부 5(특보 발효 현황), 특보 기준치와 실황 비교 | 사고 시점의 특보 발효·예보 내용을 근거로 첨부 | **가능** — §04 특보 이력으로 일부 구현. 예보문은 미구현(④) |
| **배수 기준 등 타 분야 공학 기준 대조** | 시나리오 1 — 국토해양부 건축기계설비 설계 기준(옥상면적 240㎡·배관 직경별 수용 강수량) | 기상 산출값을 공학 기준표와 결합해 인과 판단 | **감정사 영역**(+타 분야 전문가) — 기상 범위 밖 |

## ③ 결정적 갭 — AWS 관측망: 커버리지 등급 현실화의 1순위 과제

**사례집의 감정은 AWS 관측망 밀도 위에서만 성립한다.** 시나리오 1의 사건지점(부산 북구)
기준, 감정에 사용된 기상청 AWS는 다음과 같다(첨부 10, 가상 사례 내 수치):

| 지점 | 사건장소와의 거리 | 60분 강수량 |
|---|---|---|
| 북구 AWS | **4.1km** | 75.5mm |
| 동래 AWS | 6.3km | 40.0mm |
| 양산시 AWS | 8.0km | 60.0mm |
| 금정구 AWS | 9.8km | 80.5mm |

반경 10km 안에 4개 지점 — 이 밀도가 레이더 회귀식(4지점 실측이 회귀 입력)과 PRISM
추정(2~4지점 조합)의 **전제 조건**이다. 시나리오 2·3도 우암산 AWS·노은 AWS 등 AWS
실황이 감정의 축이다.

**현재 웨더팩트의 지점 DB는 `src/verify/stationsData.js`의 ASOS 73지점뿐이다.**
ASOS만으로는:

- 도시 밖에서 최근접 지점이 수십 km — `coverageGrade` A(<5km)는 사실상 희소하고
  B·C·D가 대부분. 사례집 수준(4.1km)의 근접 관측 근거를 제시할 수 없다.
- 레이더 회귀·PRISM류 **다지점 기법의 입력(반경 ~10km 다지점)** 자체가 확보 불가.

기상청 AWS는 전국 **약 500지점**(ASOS 대비 약 7배 밀도)이다. 따라서:

> **AWS ~500지점 확대가 커버리지 등급 현실화의 1순위 과제다.**
> ASOS 73지점 체제에서 커버리지 등급은 구조적으로 낮게 나올 수밖에 없고,
> AWS 확대 없이는 §02 관측 근거의 대표성도, ② 표의 '부분 자동화' 기법들도 진전이 없다.

### 로드맵 (verify-stations 파이프라인 확장)

1. **[구현됨] AWS 지점 목록 생성** — `STN_INF=AWS KMA_APIHUB_KEY=<키> node scripts/verify-stations.mjs`
   → `src/verify/awsStationsData.js` 생성(ASOS `stationsData.js`와 동일 스키마 + `kind:'AWS'`,
   기존 ASOS 로직 무변경). 안전장치: 한국 bbox + 최소 300지점 미달 시 미작성.
   엔드포인트(`stn_inf.php inf=AWS`)는 실행 검증 전 가정 — `docs/verify-stations-pipeline.md` 참조.
2. 매칭 엔진(`verifyEngine.js`)에 AWS 지점 채택 — 최근접 산출·커버리지 등급을 ASOS+AWS
   통합 기준으로 재계산, 리포트에 지점 종류(ASOS/AWS) 표기.
3. AWS 관측자료(시간·10분) API 연동 — §03 관측자료의 시간 해상도 상향
   (실패 시 `available:false(reason)` 계약 유지).
4. 다지점 거리·고도 가중 참고 산출(② PRISM 항목의 '기계적 부분'만) — 단, 산출값은
   '감정 전 단계 참고치'로만 표기하고 감정값처럼 제시하지 않는다.

## ④ 특보 이력·예보문은 표준 별첨이다

3개 시나리오 **모두** 「기상청 발표 당일 기상예보문」과 「호우특보 발효 현황」을 별첨으로
포함하며, 결과·의견 본문에서도 특보 발효 시각(예: 호우주의보 09:10 → 호우경보 13:00)과
특보 기준치(호우주의보: 3시간 60mm 또는 12시간 110mm / 호우경보: 3시간 90mm 또는
12시간 180mm 예상)를 근거로 인용한다.

- 특보 발효 이력: 웨더팩트 §04로 대응(available/reason 계약).
- **당일 예보문**: 미구현 — 표준 별첨이므로 백로그로 유지. 예보문 원문 API 확보 시
  §04에 병기하는 형태가 표준 구조에 부합한다.
